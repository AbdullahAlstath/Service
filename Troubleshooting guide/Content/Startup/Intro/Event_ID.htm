Understanding Event IDs: PC and COP

Module and Subunit IDs indicate the originator of a message.

Module IDs

The first three digits of the Event ID represent the Module ID and identify the type of Event.

Subunit ID

The second number set represents the Subunit ID, which specifies the subunit in which the event occurred. This further details the origin of the event.

Message Number

The last number set represents the Message Number, which identifies the specific event. For COP Events, the Message Numbers are documented in the module design description of the firmware. PC Events are defined in the file, pcevents.txt.

Both COP Events and PC Events are subject to localization. As past of the build process, these two files are converted into a Dot.Net assembly (eventmessages.dll), which contains all Event Messages as string resources. These string resources contain the Event ID in a period-separated format.
