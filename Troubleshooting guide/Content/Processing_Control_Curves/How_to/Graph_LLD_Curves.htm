How to Graph LLD Curves

  1. Open Excel application.
  2. Select the "Open" option from MS Office button, and navigate to the folder where the desired curve file is found.

  1. Under the “Files of type” section, from the drop menu select “All Files (*.*)”. Highlight “LLDValues_yyyy_mm_dd-#.curve” file, and click the “Open” button.

  2. Select “Delimited”, then click on “Next >” button.

  3. Select “Tab”, “Semicolon” delimiters and then click “Next >” button.

  4. Select "General", followed by “Finish” button.

  5. Highlight entire worksheet by clicking on the upper left corner, then click on the “Filter” button.

  6. Under the “Command Description” column, from the drop menu, select “Pipettor Aspirate Amplification PreLLD”.

  7. Scroll to the right until the “LLDHeight” column is encountered, and then highlight data.

  8. Select the "Insert" tab, click on "Scatter" button.

  9. Select the Type of graph as desired.

  10. Right click on the curve, and select “Move Chart".

  11. Select "New sheet” and name it as desired.

  12. Edit the graph as desired.

  13. To graph "Pipettor Aspirate Enzyme PreLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Aspirate Enzyme PreLLD ”.

  14. To graph "Pipettor Aspirate Probe PreLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Aspirate Probe PreLLD ”.

  15. To graph "Pipettor Aspirate Select PreLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Aspirate Select PreLLD ”.

  16. To graph "Pipettor Aspirate TCR PreLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Aspirate TCR PreLLD ”.

  17. To graph "Pipettor Sample Dispense PreLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Sample Dispense PreLLD ”.

  18. To graph "Pipettor Sample Dispense PostLLD curve", follow same steps 1-13, but in step 8, select “Pipettor Sample Dispense PostLLD ”.
