Technical Support

Terms and Definitions

  • Assay Name: String used to identify type of tests samples need to process.

    Found in CTB-00038 Table 3A - Assay (Tests) in the Assay Short Name column.

  • Analyte Name: String used to identify sample analyte.

    Found in CTB-00038 Table 4A – Analytes in the Analyte Name column.

  • Communication:

    • Bidirectional: LISLaboratory Information System. sends test orders to Panther. Panther sends results to LIS.

    • Unidirectional: Panther only sends results to LIS.

  • Cisco ASA (5505 or 5506): A firewall that protects the Panther from the customer’s network. Only allows communication to the customer’s LIS and Hologic for remote diagnostics.

  • Internet Protocol address (IP address): An address that identifies the network and host address assigned to a device.

    • IPv4: 32 bits address that uses octets of decimal numbers between 0-255.

    • IPv6: 64 bit address that uses 32 hexadecimal numbers. (Not used on Panther.)

  • Subnet: A network within a network, it requires subnet mask to define its location.

  • Subnet Mask: 32-bit number that defines which portion of an IPv4 address identifies the network address and which portion of the address defines the host address.

  • Transmission Control Protocol (TCP/IP): It allows computing devices and application devices to exchange messages over a network. In LIS, it is the connection to the LIS that uses an ethernet cable (RJ45) to connect to the LIS through the customer’s network.

  • Media Access Control (MAC): Unique address assigned to hardware.

  • Dynamic Host Configuration Protocol (DHCP): DHCP is used to automatically assign addresses and other configuration parameters to network hosts.

  • Network Interface Card (NIC): Also called a network adapter, connects a host to the network medium.

  • Hub: Central connecting point using logical bus topology.

  • Bridge: Device that connects two or more media segments on the same subnet; it filters traffic between both segments based on MAC address.

  • Switch: performs filtering based on MAC addresses and provides additional features not found in a bridge.

  • Router: Device that connects two or more network segments or subnets.

  • Firewall: Network security system that monitors and controls incoming and outgoing network traffic based on security rules.

  • Automatic Private IP Addressing (APIPA): Feature that allows a device to automatically assign itself an IP address on the 169.254.0.0 network when a DHCP server or manual configuration is unavailable.

  • DNS (Doman Name Server): used to map hostnames to IP addresses.

  • File (Interface Layer): The Panther sends results to a mapped drive on the customer’s network.

  • Gateway: Device that connects two networks together by sending and receiving protocols with different transmission.

  • LIMS/LIS: A software-based laboratory and information management system that offers a set of key features that support a modern laboratory’s operations.

    • LIMS: Laboratory Information Management System

    • LIS: Laboratory Information System

  • Logical Observation identifier Names and Codes (LOINC): code names and identifiers for lab tests for medical health records. Customers can find them from Pinnacle Health Group at:

    hologic@thepinnaclehealthgroup.com

  • Middleware: Translates communication between Panther and LIS.

  • Serial: A connection to the LIS that uses a serial cable (RS-232The standard used in the instrument and LIS Serial ports; it defines the electrical characteristics and timing of signals, the meaning of signals, and the physical size and pin out of connectors. – DB9) to create a direct connection from the Panther to another computer (LIS).

Basic Troubleshooting

What type of connection to the LIS – Serial, TCP/IP, or File – does the Panther have?

  1. Click Admin in the top menu.

  2. Click LIS Configuration.

  3. See what is selected in the Interface Layer field.

    Serial, TCP/IP, or File is selected.

How do I enable or disable the connection to the LIS?

  1. Click Admin in the top menu.

  2. Click LIS Configuration.

  3. To enable the connection to the LIS:

    1. Check the Enable LIS connection checkbox.

    2. Click Save at the bottom of the screen.

  4. To disable the connection to the LIS:

    1. Uncheck the Enable LIS connection checkbox.

    2. Click Save at the bottom of the screen.

Communication with LIS stopped working after a software upgrade or FSEField Service Engineer. service.

Ensure the connection to the LIS is enabled:

  1. Click Admin in the top menu.

  2. Click LIS Configuration.

  3. Check the Enable LIS connection checkbox.

  4. Click Save at the bottom of the screen.
