LIS Message Has Incorrect Structure

Error Code

272.000.00005: Structure of message received from LISLaboratory Information System. was incorrect.

Complaint Description

The structure or framing of the ASTMAmerican Society for Testing and Materials (ASTM) is an international standards organization that develops and publishes voluntary technical standards. records received by Panther is incorrect.

Compressed Test Order Structure Issue

When the LIS sends test orders in compressed format, all assays listed must have information in the same fields. If one test order has information that another does not, there will be a structure error.

Resolution:

  1. Open logs for instrument.

  2. Navigate to Export > Messages.

  3. Open the Messages Log Report pdf for applicable date.

  4. Get the timestamp of the error, Structure of message received from LIS was incorrect.

  5. Navigate to Output > Lis > Log.

  6. Open ASTM 1394A high-level protocol that is used to transfer information between Clinical Instruments and Computer Systems. log for applicable date.

  7. Navigate to the timestamp from the Messages Log Report.

  8. Review the messages from the LIS at the timestamp or right before the timestamp.

    If customer sends test orders in a compressed format, all test orders must send information in the same fields.

    In the example below, the first test order lists only the Assay Name (CT/GC). The second test order, however, lists the Assay Name and Analyte (M gen^MG).

  9. Instruct customer to update the test orders so they send information in the same fields, or not send in compressed format.

    Normally it is best to send only the Assay Name, and not specify any Analytes. If you do not specify the Analyte, the Panther will run all Analytes.

    The example below shows sending in an uncompressed format.

Test:

  1. Load sample rack with appropriate tests.

  2. If tests assign successfully, Panther now recognizes LIS test orders.

Header Delimiter Missing Character

The Header record lists the delimiters in field 2 [H2]. The delimiters the LIS sends must define all delimiter characters.

Resolution:

  1. Open logs for instrument.

  2. Navigate to Export > Messages.

  3. Open the Messages Log Report pdf for applicable date.

  4. Get the timestamp of the error, Structure of message received from LIS was incorrect.

  5. Navigate to Output > Lis > Log.

  6. Open ASTM 1394 log for applicable date.

  7. Navigate to the timestamp from the Messages Log Report.

  8. Review the messages from the LIS at the timestamp, or right before the timestamp.

  9. Confirm the delimiters the LIS is sending match the Panther’s delimiters.

    In the example below, the LIS’s Header Line is missing the “\” delimiter.

    In CTB-00038, LIS Delimiter Options (section 7.6) lists default delimiters for Panther.

  10. Instruct customer to update the LIS’s delimiters so they match Panther's delimiters, or update Panther’s delimiters to match the LIS.

    In the example below, the LIS adds the “\” delimiter to match the Panther’s list of delimiters.

Test:

  1. Load sample rack with appropriate tests.

  2. If tests assign successfully, Panther now recognizes LIS test orders.

Sequence Number Not Incrementing

Sequence numbers populate the second field in each record type. They increment in a way similar to outline format, using roman numerals, upper case letters, and numbers. When this field does not increment properly, the instrument will note structure incorrect.

Note: When ASTM files show no structural issues, request customer to look at the patient information record line. In most cases, the sequence number is not incrementing properly. The Panther removes the patient information record line from ASTM logs. We do not review these issues since these lines may contain possible patient information.

Resolution:

  1. Open logs for instrument.

  2. Navigate to Export > Messages.

  3. Open the Messages Log Report pdf for applicable date.

  4. Get the timestamp of the error, Structure of message received from LIS was incorrect.

  5. Navigate to Output > Lis > Log.

  6. Open ASTM 1394 log for applicable date.

  7. Navigate to the timestamp from the Messages Log Report.

  8. Review the messages from the LIS at the timestamp, or right before the timestamp.

    In the example below, LIS attempts to send two test order records on sequence number 1. Panther detects the incorrect formatting.

  9. TS reviews CTB-00038, ASTM Records (section 5.1), and notes sequence level for the test order record does not increment for multiple test orders.

    See image below.

    After required changes are made, the correct structure appears below.

    Panther now receives different test orders on two separate lines, 1 and 2.

Test:

  1. Load sample rack with appropriate tests.

  2. If tests assign successfully, Panther now recognizes LIS test orders.
