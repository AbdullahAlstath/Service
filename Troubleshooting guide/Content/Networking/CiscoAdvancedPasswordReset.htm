Cisco Advanced Password Reset

Error Code

No error code.

Complaint Description

When performing a password reset on the Cisco ASA 5506-X, the password either gets specified incorrectly (e.g. the designated password of gpservice has a typo), or another password gets specified, preventing the FSEField Service Engineer. from performing password resets.

Field Service

There are two saved configurations on an ASA:

  • startup-config, which is the configuration that is loaded onto the ASA after a power cycle,

    and

  • running-config, which is the configuration between when an ASA is powered on, and any changes a superuser makes (the delta, or Δ).

Reset the ASA

Reset the ASA reverts the running-config to the startup-config by power-cycling the ASA.

Resolution: Press the reset button on the back of the ASA.

Hold the reset button at the back of the ASA for five seconds. This causes the ASA to power-cycle.

Test: Retry Firewall Wizard.

If the ASA continues to display the password issue after power-cycle, it indicates that password is part of the startup-config, and must be reset via command-line interface.

Reset the Password via Command-Line

Note: For this procedure, access to ciscoasa# is required. If you are unable to get to this point (because the password is unknown), an ASA memory reset is required.

An ASA memory reset is not a field procedure. Order a new ASA and return the Firewall to the USTSESupport group for refurbishment.

Resolution: Reset the Password via Command-Line

To change the password via command-line:

  1. Using HyperTerminal or PuTTy, access ciscoasa#.
  2. From the ciscoasa# prompt, type the command ‘config t’, and press Enter. This will bring you to ciscoasa(config)#.
  3. From ciscoasa(config)#, type the command ‘enable password gpservice’. This command will change the password to gpservice. There is no expected output.
  4. From ciscoasa(config)#, type the command ‘copy run start’. This is short for copy running-config startup-config, and will save any changes from the current running-config to the startup-config.
  5. You will be prompted for a source filename, just press Enter.
  6. From ciscoasa(config)#, type the command ‘exit’. This will bring you to ciscoasa#.
  7. From ciscoasa#, type the command ‘exit’. This will bring you to ciscoasa>.

Validation:

From ciscoasa>, type the command ‘enable’. It will prompt for the password. Input the password as designated, and press Enter. This should bring you to ciscoasa#.

Test: Retry Firewall Wizard.
