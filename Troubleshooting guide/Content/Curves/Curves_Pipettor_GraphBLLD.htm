How to Graph BLLD Using Service Software

To graph Barometric Liquid Level Detect (BLLD) with service software:

  1. Start Service Software.

  2. Initialize Pipettors, Reagent Bay, and TCR carousel.

  3. Click the Pipettor tab, then click the LLD Right Arm tab.

  4. Important: Select bar under LLD at lower left.

  5. Important: Select Log under LLD at lower left.

  6. Enter the number of cycles to run Pipettor under LLD at lower left.

    Image below shows ten cycles.

  7. Enter TCR bottle number,1 - 8, TCR.

    Black arrow in image indicates TCR bottle 1.

  8. Load Sample tips in the tray(s) indicated under Disposable Tip Requirements at the lower right of the Pipettor tab.

    In this example, script is asking for 10 sample tips to be loaded in Tray1 and Drawer 1. Refer to image below.

    Each new Execute command on the left resets Pipettor to pick from Drawer 1, Tray 1, Position A1.

  9. Optional: Load TCR bottle with saline in selected TCR bottle position. Position 1 was selected in this case.

  10. Click Execute at lower left to start the script.

    Note: A dialog box prompts user if results are to be deleted.

    Click Yes to clear data in the red box.

    Click No to append new data to existing data.

    Either option writes data.

  11. The script launches. Sample Pipettor picks a sample tip, then applies Barometric Liquid Level Detect at TCR bottle position 1.

  12. When the script completes, it creates files in the following folder: C:\Panther\Panther Service Software\Log\.

    • Left/Right-LLD-Values = Record of sensor from z-start until trigger or z-max. Contains barometric and capacitive data.
    • Left/Right-LLD-ZPos = summary of level sense heights.

  13. Launch Excel application, then open Right-LLD-Values_TCR Carousel-Track1-Tube1.txt file.

    Note: To view *.txt or *.log extensions may require changing the file field to All Files (*.*). See red arrow in image below.

  14. Select Delimited under Original data type, then click Next >.

    Note: If Excel does not automatically launch the text import wizard, see Appendix A.

  15. In Text Import Wizard, check Semicolon under Delimiters. Tab is checked by default. Click Finish at lower right.

  16. If you clicked Next > in step 15, Step 3 of 3 in Text Import Wizard appears. Click Finish.

  17. Highlight data, starting with column AK.

    Tip: To select all data of interest, select AK1 at upper left, then press Ctrl + Shift + End. Refer to image below.

  18. Click Insert tab, then select desired type of graph.

  19. Right-click on the graph, then select Move Chart in the ribbon.

    Move Chart dialog appears.

  20. Name the new sheet as desired.

  21. Modify curve as desired.

Appendix A – Manually Launch Text to Columns Wizard

To launch Text to Columns wizard manually:

  1. Select Data tab in Excel.

  2. Select Column A.

    When selected, column has a green borders, and is partially grayed out. See step 2 below.

  3. Select Text to Columns in the ribbon.

 

Click the button at the top of the page to send feedback, comments, or change requests.
