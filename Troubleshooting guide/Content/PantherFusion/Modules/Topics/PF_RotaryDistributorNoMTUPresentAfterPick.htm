Rotary Distributor No MTU Present After Pick

Error Code

Dec Hex
1032.003.00049 0x00.0x00.0x01

Complaint Description

Rotary Distributor no MTU present after pick.

Technical Support

  • Rotary distributor and Linear distributor handoff may require re-teaching.
  1. Use diagnostic logs or View logs to find out the position. Rotary positions at T:\Technical Service\Fusion. Fusion Team\Fusion\Troubleshooting and Tips and below.
  2. Instrument will go into Panther Only mode, when possible, do a full shutdown restart.
  3. During initialization instrument will use Rotary distributor hook to unload MTUs (serves as test).
  4. If reset works try a small untested load for Fusion.
  5. If error repeats customer can use instruemt is Panther only mode. FSEField Service Engineer. dispatch needed.
  6. If it is a repeating error FSE dispatch recommended.

Troubleshooting: Perform HO test in service software. Watch LD to HO interaction, likely LD is too close to HO in x-direction causing interference between LD/HO.

Resolution: Teach LD, move LD farther away from HO in x-direction and reteach so hook will compensate for distance. This allows HO and LD to rotate without interference.
