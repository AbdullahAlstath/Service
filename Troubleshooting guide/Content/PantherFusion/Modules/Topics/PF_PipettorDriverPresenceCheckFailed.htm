Vial Presence Check Failed at Centrifuge Load for Fusion Pipettor Driver and Arm

Error Code

Dec Hex

1239.001.00163

N/A

Complaint Description

Pipettor Driver (Fusion Pipettor) Pipettor arm, vial presence check failed at centrifuge load. Fusion Pipettor Driver cap and vial pick retry delay error. Uncapped tube present in associated tube tray. Properly dispose of tray when processing has completed. (DCR flag)

Technical Support

  • Sensor failed at centrifuge load

  • Dropped vial, DITI issue

Have customer look for a dropped vial. If capped and accessible through the front, shutdown instrument, remove vial and put in waste. Also remove tube tray that instrument was picking from, replace with a full one.

Opening log files on viewlogs or Notepad+ you can find the error and the coordinate at the time of the error to find out which tube tray it was using if unclear.

Customer or FSEField Service Engineer. should clean the diti to help with this issue. Clean with alcohol wipe. Restart instrument, upon restart thermocyler and centrifuge positions will be checked and the vial will be unloaded if present.

Field Service

FSE should install new diti sleeve if not already done. (TB-01627) If sensor is faulty, FSE will replace sensor on load side. Only way to test it is running Fusion samples.

Fusion Coordinates:

Note: Picture with trays and TC positions at the end of the document.

Remember on Fusion side:

  • X axis is front to back.

  • Y axis is left to right.

Coordinates do not show in the messages, you have to find them with the time stamp in the diagnostics log report or health report, or use view logs.
