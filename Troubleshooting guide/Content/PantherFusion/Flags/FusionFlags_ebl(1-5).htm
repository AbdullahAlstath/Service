ebl(1-5)

Complaint Description:

Thermocycler EBL: Estimated baseline too low.

Symptom:

EBL# errors during assay processing.

ebl1 = FAM

ebl2 = HEX

ebl3 = ROX

ebl4 = Red647

ebl5 = Red677

Isolation:

Identify sample id with ebl3 error.

Method 1

Using logs:

From logs regex search ebl3:

2020-06-04 14:23:53,164|[SCTOM]|IAnalysis|DataReduction|Info|Normal|Adding ebl3 5011 to ResultID 68240

Using Curve Trend:

Note Curve Trend TCBankPos is 0-4.

    2020-06-04 14:23:53,164|[SCTOM]|IAnalysis|DataReduction|Info|Normal|Adding ebl3 5011 to ResultID 68240

Method 3

  1. From logs grab @DI files with ebl3 errors.

  2. Paste values into excel as text.

  3. Sort flag column (sw7.1 = column AY) for contains ebl3 errors.

  4. Can use filter again on bank-well column and specific wells should be clear (sw7.1 = column AI).

    Alternative filter methods:

    • Use pivot table.
    • Use excel function "Unique" to bank/well column.

Corrective Action:

  1. Establish baseline before cleaning thermocycler by performing all 3 thermocycler scans in service software.

    1. Run PantherMain Background, Background and PEEK.

    2. Save/record data.

    3. PEEK scan decay will determine if TC replacement is necessary.

    4. Note: Debris will typically:

      • No vial in well: read higher because light reflects off debris.
      • Vial in well: read lower as debris blocks the amplified product.

  2. Inspect using scope to take pictures and clean wells. Thermal bank should be removed to properly clean fiber heads. Often requires hard scrubbing with supplied optic cleaners.

  3. Perform scans again to verify cleaning was effective (repeat as needed).

In this case PEEK scan was more effective than Panther Background Main scan.

Residue around the edge of the fiber head.

TC bank needed to be removed to access the debris.
