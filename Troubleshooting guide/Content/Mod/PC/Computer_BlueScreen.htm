Blue Screen

Complaint Description:

Panther instrument freezes and presents Blue Screen.

If you are contacted regarding a Blue Screen failure, please perform or obtain the following:

  1. Ask the customer or service member to allow the memory dump to complete. This will be indicated by a numeric progress notification on the Blue Screen itself. If, after 10 minutes, no progress is observed, the PC can be rebooted.
  2. Inside the C:\Windows directory, obtain any MEMORY.DMP files that are present. They will be up to 16GB in size.
  3. Inside the C:\Windows\Minidump directory, obtain any other files with a .dmp extension.
  4. Obtain Panther logs.
  5. Obtain the Application and System categories of the Windows Event Logs.*

Gathering Windows Event Logs

  1. Open the Command Prompt.
  2. Type eventvwr and press Enter.
  3. Expand Windows Logs (left pane).
  4. Click Application, Security, Setup, System, or Forwarded Events depending on request.
  5. Click Save All Events As… (right pane).
  6. Name the file and save it to a directory you can access via PRO360 (or flash drive for FSEField Service Engineer.).
