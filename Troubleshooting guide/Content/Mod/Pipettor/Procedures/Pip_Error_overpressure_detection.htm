Complaint Description

  • Reagent Pipettor error (pump move cancelled due to overpressure detection) – PFR flag
  • Sample Pipettor error (pump move cancelled due to overpressure detection) – PFS flag

Technical Support

Sample Pipettor Error – pump move cancelled due to overpressure detection – associated with PFS flags

  • Likely the sample shield is not seated properly. Advise to replace shield.
  • Likely sample issue: viscous/mucoidal/precipitates/cotton pile.
  • If there are many PFS in a row. Graph aspiration/dispense curves and compare to controls.

Sample Pipettor Error – pump move cancelled due to overpressure detection – during MW cleaning

  • Likely the sample shield is not seated properly. Advise to replace shield and repeat MW cleaning.

Reagent Pipettor Error – pump move cancelled due to overpressure detection – associated with PFR flags

  • Ask which tips customer is using. This could be a tip issue (e.g.,Tecan tips, PN 30180117 issue 2021 – CTB-00842).
  • If tip issue, customer can continue to run.
  • If not tip issue, notify FSEField Service Engineer..
  • Prime or MW cleaning: do not test the reagent pipettor so it is risky to keep running. Likely service will be needed.

MTU ending in …884, triggered overpressure.

Aspiration pressure for …884,

TCR aspiration is usually not smooth like the other reagents.

TCR is suspension of magnetic beads which can clump together.

The aspiration can also be affected by tip damage, variation.

C-LLD traces from 10/19 – 11/16:

  • First measurement is always lower red arrow.

  • GT HPV trace doesn’t follow HPV trace.

  • Both of these issues suggest an alignment related issue.

    • Incorrect tcr teach tool ( I think this is the issue)

    • Something going on with tcr cup/tcr module

Sample dispense, looks mucoidal, so could drag on sample shield.

Resolution:

Evaluation 1

TCR bottle Cuff, sample pipettor/tcr teaching, or tcr carousel can be improved.

Evaluation 2

Hardware Failing

Example of noise during aspiration, indicating the plunger motor is wearing out. In this instance, it should not affect assay processing results.

Evaluation 3

Logs show: PFR flags

03/09/2023 20:17:36 Warning 000.014.00159 Reagent Pipettor error (pump move canceled due to overpressure detection)

Some things to check:

Make sure the new cLLD washers are installed properly, and gold leads are clean.

Perform a cLLD test on the Reagent pipettor as a baseline to any position other than the Elution Track. If good, proceed with the following:

Check teaching of the Reagent Pipettor to the Elution Track – make sure the tip is centered in the pack. If necessary, teach manually.

If initial cLLD test is bad – replace Reagent Pipettor.
