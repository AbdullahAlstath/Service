Incubator Carousel Error: Position at Home Pin

Error Codes:

Dec Hex

032.002.00081

033.002.00081

034.002.00081

0x20.0x02.0x51

0x21.0x02.0x51

0x22.0x02.0x51

Complaint Description:

Carousel Motor drive position is greater than the allowed error at the home pin.

Incubator 1 = High Temperature Incubator

Incubator 2 = Transition Incubator

Incubator 3 = AMP Incubator

Technical Support

Restart instrument to verify problem persists. Although this error can be intermittent, it is usually a sign of a problem, and will require an FSEField Service Engineer. dispatch..

Field Service

Door Home Sensor or Pin

  1. Using Service Software, verify that the door sensor outputs “Open”/”Close”.
  2. Visually inspect the Home Sensor for any residue.

Resolution:

  1. Clean the door sensor of any residue using a swab and alcohol.
  2. Replace the Door Home Sensor if deemed faulty.

Test:

Perform a 2 cycle Incubator System OQ.

Over-Torqued Door Fastener

Over-torqueing of the screw can warp the screw hole and push the door open. It may be intermittent or permanently read “Open”. Using Service Software, determine if the door sensor is properly reading.

Resolution:

  1. Reduce torque.
  2. Replace the door if warped beyond repair.

Test:

Perform a two-cycle Incubator System OQ.

Pulley or Belt Tension

  1. Confirm the pulleys are the correct ones and not faulty – refer to the Panther Parts List for the most current version of pulley.

  2. Verify belt tension is proper, and the belt is not faulty.

Resolution:

  1. Replace the pulleys.
  2. Re-tension the belt, or replace if faulty.

Test:

Perform a two-cycle Incubator System OQ.

Carousel Motor Encoder

  1. Check that the encoder cable is fully connected and not faulty.
  2. Make sure the encoder is not dirty.
  3. Encoder is faulty.

Resolution:

  1. Replace the encoder cable.
  2. If possible, clean the encoder using alcohol and a swab.
  3. Replace the encoder/motor.

Test:

Perform a two-cycle Incubator System OQ.

Carousel Motor

  1. Check the motor cable is fully connected and not faulty.
  2. Using Service Software move the carousel to multiple positions – make sure the motor is moving properly.

Resolution:

  1. Reseat or replace the motor cable.
  2. Replace the motor.

Test:

Perform a two-cycle Incubator System OQ.
