SW 7.1 – Instrument Response Delay / Sending Block

SW v7.1.5

Failure mode:

Sendblock failure due to instrument response delay.

Suggestion:

Correct BIOS and upgrade to XE3 (send block failure mode of USB communication failure or USB configuration).

Note: This issue is resolved in Software Version 7.2.
