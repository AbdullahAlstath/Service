Disable RTFs Through Remote Diagnostics

Error Code

Dec Location

N/A

 

Complaint Description

Unable to run the Panther system due to a Real Time Flourometer fault.

Technical Support

Warning: Never perform any electromechanical operations while connected remotely to the Panther System.

  • SecureLink only applies to Panther Systems (Panther, Panther Fusion, or Panther Plus) running on System software v7.2 and above. Remote support is limited to agents with access to account asset information within the Salesforce CRM application.

  • Agents will only be able to access the customer’s system when it is in an idle or error state, and not while the system is processing a run.

  • It is against HIPAA rules to match patient identification with patient results.

  • Transfer of log files shall occur within the Hologic network: that is, with in-house login on support workstation, or remotely through VPN.

  • Agent shall not modify or delete files via remote connection.

  • Support users are not allowed to change or alter Panther software or firmware configurations, settings, or parameters.

  • Agent shall terminate the remote session when troubleshooting is finished, either by closing out the session or the software completely.

Procedure

  1. Ask the customer to start the SecureLink gatekeeper service on the Panther by going to Messages tab, and clicking Remote Diagnostics.

  2. Search for Panther Serial Number within Salesforce.

    Note: Google Chrome is the preferred web browser.

  3. From Asset level or Case level, click SecureLink.

  4. Log into SecureLink with Single Sign On.

  5. Click Connect.

  6. A pop-up window prompts user to click Connect using SecureLink connection manager.

  7. A download appears to launch.securelinkcm.

  8. Click on it. Another window reports SecureLink Connection Manager starting.

  9. A new window with Connection Form Information opens.

  10. Enter Reason for Connection.

  11. Enter Person Who Authorized Access (customer contact).

  12. Click Submit.

  13. System prompts to use Administrator Privileges. Click OK.

  14. There will be two options – Desktop Sharing or File Transfer (Read / Write).

  15. Click Desktop Sharing.

  16. Now agent has control over the customer’s Panther computer, and is able to: (1) navigate to different screens; (2) perform the Send Logs function.

    Warning: Never perform any electromechanical operations while connected remotely to the Panther System.

  17. Log into Service Software, and disable the RTFs as shown.
