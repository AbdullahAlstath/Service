SW 7.1 - Fusion-Samples Not Turning Green When Adding Test Orders

MKS: 2045725, 2078738, 2078766

Issue

The operator wanted to re-process a specimen which had been flagged with a VVFS. They unloaded the rack and reloaded it to re-process the specimen. At this time, the front-end MTU had not yet completed the handoff to Fusion. The system allowed them to add an additional test order to the specimen, which is okay if the front-end is not set to be invalidated. Thus, both PCR test orders were invalidated by the system. They also experienced an anomaly within the UI which looks to be the original reported issue.

They reloaded the rack and the system SW incorrectly allowed them to add an additional PCR test order to the specimen which was set to be invalidated.

The UI also experienced a defect regarding display of the test order in the rack details screen. The additional test order added was considered a replicate. When a replicate is created against a front-end that has already been pipetted, IC will copy the pipetting time from the front-end. UI sees that that pipetting time is from before when the sample was loaded and excludes it intentionally. Basic steps to reproduce below.

Load a sample and let it begin processing a PCR test order.

Unload and reload the rack.

Add an additional PCR test order, the sample display will remain white.

The system did not unschedule/remove the back-end tests when the front-end was invalidated. This is a downstream effect of defect 1 and does not need to be identified in the logs. Mainly we feel this shouldn’t be done as it is a waste of consumables.

Workaround

If the customer would like to re-process specimens which have been flagged during front-end processing, they must wait for the containing MTU to complete front-end processing. Unfortunately, there is no notification to the operator when this occurs so we recommend that they wait until the invalid PCR test order has completed processing.

Resolution

All defects will be fixed in a future software version. No target yet.
