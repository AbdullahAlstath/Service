Troubleshooting with Service Software

This topic describes commands, data, and options available in Panther's Service Software.

  • When using Service Software Tool, Universal fluid usage is not tracked.

  • Recommendations:

    Use a different set of Universal Fluids when priming and/or dispensing during Service Software Tool usage. Load original Universal Fluids when returning Panther Instrument to customer.

    or

    Use customer’s current loaded Universal Fluids when priming and/or dispensing during Service Software Tool usage BUT load a new set of Universal Fluids when returning Panther instrument to customer.

  • Service software – firmware version and sensors should be able to be read without initializing the module.

Service Software FSE Shield Login

After the PC has booted up, the PANTHER Main Shield appears. Touch the screen, or press any key to stop the instrument from starting operators’ mode.

  1. Press Shift + F10.

    The FSE Password Login dialog box appears.

  2. Enter the following password:

    !G9x53rvic3y

    Where x = the last digit of the day, and y = the last digit of the month.

  3. Click OK.

    The PANTHER FSE Shield appears.

Login Level: Defaults to gpservice. If instructed, select super.

Login Name: Enter your name. Entry is used to populate any reports created during the current session.

Password: Must match login level.

Each tab has a Main and a Parameter subtab. Some tabs also have Move, Sub-Module, Teach, and Error Memory subtabs:

Main – Main control for that module:

Linear Distributor – Move Tab

  1. Distributor Single Movement to – Single click will move the Linear Distributor to that location. Double clicking will make the Linear Distributor load or unload an MTU.

  2. Next MTU Action – Displays LD MTU presence state to determine what the distributor will do with the single movement command (Pick/ Place). Pick: indicates empty LD. Place: indicates MTU present. Unknown: LD is not initialized. Next MTU action changes depending on current state. If MTU is present in LD, it will place. If no MTU is in LD, it will pick.

  3. Luminometer – [Open] [Close] Opens or Closes the Luminometer door.

  4. Input Queue – [Unlock Drawer] Unlocks MTU drawer. [Push MTU] Advances MTU pusher.

  5. Output Queue – Dispose MTU - Aspirate and dispose of all MTUs in the Output Queue. (vacuum pump needs to be turned on for the aspiration to work).

  6. Distributor Repetition Movement - Available Positions – All the positions the distributor can move to.

  7. Movement List – Lists positions in the order that the distributor will move to. Action indicates – shows if position will be performed once or twice (this column will be blank, x or xx).

  8. Add Pos. – [>>] moves highlighted selection from available positions to the movement list.

  9. Action

    [None] Will perform only x/z/theta action. No hook movement, e.g., no picking or placing.

    [Once X] – Will perform the Next MTU Action once per cycle.Twice XX – Will perform the Next MTU Action twice.

    [Twice XX] – Will perform two Next MTU Actions. For example, if action is set to “XX” and there MTU is present in LD, next MTU Action indicating ‘place’ upon execute, the LD will place MTU in position, then pick MTU back in LD.

  10. Item – [Up][Down] Moves the Delete – Removes selected position from the list.highlighted position in movement list up or down [Delete] removes selected position from the list.

  11. MTU Barcode – Checkbox enables scanning MTU barcode.

  12. Execute – Starts the cycle and will move the distributor to all of the selected positions in the movement list repetitively until stopped or cancelled. Clear List clears all positions from the Movement List.

7. Magnetic Washer – Main Tab – Move

Basics

Mixer Start – Turns the mixer on.

Mixer Stop – Turns the mixer off.

Mixer Home – Moves the mixer to the home position.

MTU Dispense – Moves MTU to the Dispense position (under injectors).

Magnet Work – Moves magnet to the work position.

Magnet Home – Moves magnet to the home position.

Aspirate Home – Moves aspirators to the home position.

Pick Up – Make sure MTU is present. Automatically the MTU is moved to the tip pick position, then the aspirators descend and pick the tiplets.

Eject – Make sure MTU is NOT present. Automatically the aspirators descend to the eject tip position to strip the tiplets.

Aspirate – Moves aspirators to aspirate fluid from MTU, then they move to the home position.

Move Aspirate to Volume Position – Move aspirators to the height selected based on µL.

NOTE: Max value is 5000.

Without Tips – height will be based on aspirator tubes only.

With Tips – height will be based on aspirator tubes and tiplets picked.
