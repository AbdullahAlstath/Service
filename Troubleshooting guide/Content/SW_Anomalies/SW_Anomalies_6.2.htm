1340912 APV APV flags occur when the TCR was mixed too long before assay processing. The instrument registers this extra mixing time in the output logs under SRS-EEH-1461. The SRS-EEH-1461 The APV flags seen in the related complaints trigger when a TCR Carousel reagent (e.g. TCR, TER, FCR, FER) mixes for a longer time than expected. The incorrect flagging is related to maintenance tasks as follows: disruption of the scheduled TCR mix cycle due to the Replace Mag Wash Cleaning Solution maintenance task causes the next mix to occur to be a 90-second mix when the expected duration by the APV was 45 seconds. Therefore, the actual mix time is above the expected mix time of the TCR Carousel reagents that were loaded and will lead to APV flagging when used to perform an assay.

Corrected in SW 6.2.5.1 (CTB-00507) Workaround in CTB-00578

Operator workaround: Based on additional investigation, the previously provided workaround instructions, that were provided to help prevent APV flags from occurring in the next run have been revised to reduce customer effort.

First, any need to perform reagent loading/unloading prior to assay processing can be avoided by performing the Replace Mag Wash Cleaning Solution task at a time when no reagents are loaded. Reagents can either be unloaded before performing this task or this task can be completed at a time when reagents need to be unloaded (e.g., before or after a PC Reboot maintenance task is performed).

However, if a Replace Mag Wash Cleaning Solution maintenance task was performed while reagents were loaded, the operator may help prevent APV flags from occurring in the next run by performing any non-maintenance activity that unlocks the TCR Door prior to initiating assay processing. The TCR door can be opened by:

• Unloading any reagent kit

• Loading or reloading any reagent kit.

Per Panther Operator’s manual, a new set of controls/calibrators is required when a reagent kit is removed and then reloaded on the system, therefore, this workaround may require that new controls/calibrators be loaded.
