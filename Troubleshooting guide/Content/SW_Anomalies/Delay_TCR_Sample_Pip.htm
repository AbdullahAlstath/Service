SW 7.1 - Sample Pipetting Slower Than Expected

MKS 2133932

Issue:

When starting assay processing, a condition exists when one of the UF kits is invalid. An invalid kit is either an expired or empty kit. The system will report that it is in the Ready state as there is still a valid UF kit on board. When AP is started, the system must introduce an LPM (Leading Prime MTU) to prime both MW stations. Even though the kit is invalid, the system allows it to be scheduled for prime even though it is invalid. However, because the fluid kit is invalid, a secondary check stops it from being used for priming. Leading to the condition where a MW station cannot be used for AP and thus results in a 10 minute MTU introduction cycle.

Systems which are not configured for OTF fluids will only experience the defect during AP. It will not occur at initial startup of the instrument because the Prime task requires both kits to be valid. It can occur when the system has completed an AP session and moves to the Ready state. In this case, the defect will occur if AP is started with an invalid kit or a kit moves to invalid during AP and an LPM is required. An LPM would be needed by the system if the current assay being processed switches between TMA, Fusion, or RT.

Systems which are configured for OTF fluids may also experience a defect relating to the system continuously transitioning from AP to Ready (MKS# 2047987). It has the same root cause but, a different user experience. However, systems configured for OTF fluids can experience the defect during AP if a kit moves to invalid during AP and an LPM is required.

Affected:

7.1.5.4

Fix Implemented:

7.2

Workaround:

The customer must check the UF status when in the Ready state. If one of the kits shows as invalid, it must be replaced. This will bring the system back to the Setup state and require a Prime of the system in order to continue to AP. For systems that are configured for OTF fluids, the customer should ensure that they attempt to replace the kit as soon as it becomes empty if they are running assays of different types (TMA, Fusion, or RT).
