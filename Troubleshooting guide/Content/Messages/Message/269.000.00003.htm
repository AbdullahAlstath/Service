Computer lost communication with the COP (Communication and Organization Processor).

Make sure the USB cable connection between PC and COP is tight.
  1. Power down PC and Panther Instrument.
  2. Unplug all USB cables from the back of the PC and put into another port (If you know which cable is the COP cable then only that one needs to be relocate on the Motherboard/back of the Panther PC).
  3. Turn ON Panther instrument, and then the PC.
  4. Go to windows Explorer/Control Panel/Device Manager/Port (COM & LPT).
  5. Check to see if COM3 is active (Panther GUIGraphical User Interface – allows users to interact with the software using images, graphical icons, and visual indicators rather than text commands.) if so complete. If not, repeat procedure and plug into different USB port on PC.
  6. Launch GUI.
