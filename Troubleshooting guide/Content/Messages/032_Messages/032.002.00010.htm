Incubator Target Not Reached Since Motor Is Not Moving

High Temperature Incubator – COP System Message

Error Codes

This topic consolidates information for three error codes, one for each Incubator Carousel Drive.

Complaint Description

Target for Incubator Carousel Drive not reached, since motor is not moving.

  • Incubator 1 = High Temperature Incubator.
  • Incubator 2 = Transition Temperature Incubator.
  • Incubator 3 = Amplification Incubator.

Technical Support

Mandatory Dispatch: Classify all Incubator Target Not Reached errors as Severity 2. Troubleshoot error as normal. Inform customers FSEField Service Engineer. will contact them to set up service. Customer can continue to process samples if instrument restart is successful.

Restart the instrument to verify problem persists. Although this error can be intermittent, it is usually a sign of a problem, and will require an FSE service call.

Field Service

Poor Home Pin or Door Interaction

Using Service Software verify the interaction between the home sensor and the home pin – the sensor output should correctly read “Open” or “Close”.

Resolution

  1. Install door clip per Panther System Service Manual.

    Note: Screws were cut into all Panthers above Serial #00919 – Incubators with a screw do not require installation of door clips. If Panther SN is above #00919, ensure screw is present and secure.

  2. Verify that the interaction between the home pin and the home sensor is optimal; the home pin should be reasonably centered in the home sensor; the home pin should not contact the home sensor during carousel movement.

Test

  1. Initialize the Incubator.

  2. Perform a two-cycle Incubator System OQ.

Home Pin Sensor Faulty or Dirty

Resolution

Using a swab and alcohol, clean the door sensor of any residue that may affect the optical door sensor.

Test

  1. Using Service software, verify the sensor output as “Open” and “Close”.

  2. Perform a two-cycle Incubator System OQ.

Faulty Pulley or Belt

Check pulley and belt for damage.

Check belt tension.

Resolution

  1. Replace pulley and/or belt.

  2. Re-tension the belt.

Test

Perform a two-cycle Incubator System OQ.

Carousel Motor Faulty

Resolution

Replace Carousel motor.

Test

Perform a two-cycle Incubator System OQ.

Encoder Cable or Connection Faulty

Check the motor encoder cable and connection at the Incubator Carousel Drive main PCB for damage.

Resolution

  1. Replace the encoder cable.

  2. Replace the Incubator main PCB.

Test

Perform a two-cycle Incubator System OQ.

Motor Cable or Connection Faulty

Check the cable and connection at the Incubator main PCB for damage.

RESOLUTION:

  1. Replace the motor cable.

  2. Replace the Incubator main PCB.

TEST:

Perform a two-cycle Incubator System OQ.
