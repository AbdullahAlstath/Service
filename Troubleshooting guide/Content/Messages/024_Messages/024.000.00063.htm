Cooling Module Error - Cooling liquid too cold

Error Code

Dec Hex

024.000.00063

0x18.0x00.0x3F

Complaint Description

Cooling module error - Cooling liquid too cold.

Technical Support

Laboratory Temperature

Verify the laboratory is within ambient temperature (15-30 ˚C)

Resolution

Set Laboratory temperature between 15 - 30 ˚C, and let instrument warm up or cool down.

Cooling Module Sub-assembly

From Panther Temperature Screen, Make sure that both Reagent(15.5-22.0 ˚C) and Sample Bays (15.5-22.5 ˚C) are within temperature ranges, also check that cooling module temperature does not drop below 3.5 ˚C.

Resolution

Re-start instrument and computer. If Reagent or Sample bay do not get within temperature range, dispatch FSEField Service Engineer..

Field Service

Laboratory Temperature

Verify the laboratory is within ambient temperature (15-30 ˚C)

Resolution

Cooling Module Sub-assembly

Resolution

Reagent or Sample Bay Out of Temperature Range

Verify both Reagent (15.5-22.0 ˚C) and Sample Bays (15.5-22.5 ˚C) are within temperature ranges.

Resolution

Reference Event Ids for Reagent and Sample bay troubleshooting.

Not Enough Coolant in Reservoir

  1. Verify the cooling module reservoir is full
  2. Make sure that there are no loose fittings, leaks, or kinks

Resolution

  1. Add Coolant
  2. Fix any leaks or kinks

Cooling Module pump

Verify the cooling module pump is running

Resolution

Replace coolant pump.

Cooling Module Thermistor (Broken or stuck at high temperature)

  1. Verify the thermistor is connected

  2. Check for thermistor broken wire

Resolution

Replace thermistor.

Peltiers

Note: A good peltier should feel warm to the touch

  1. Using Service Software, compare seebeck voltages. All should read about the same, but the one pair that read close to 0 volts is most likely the culprit.
  2. Using a multimeter and set to ohms [(+) lead to red peltier wire and (-) lead to black peltier wire], should display around negative 1.5 ohms on a good peltier (Bad peltier in the Megaohms). Then, placing the palm of your hand on the black bracket should cause the resistance reading to go more negative (on a bad peltier, the reading does nott change). Once the hand palm is removed, eventually the multimeter should go back to original ohm reading.

Resolution

Replace peltiers.

PCB

  1. Check for loose connections
  2. Check for burnt components or sign of old spills, dry fluid.

Resolution

  1. Re-seat any loose connections.
  2. Replace PCB.
  3. If problem persists, replace chiller ramp module.
