112.001.00046

Reagent Bay – COP System Message

Description

Reagent Bay barcode scanner error (Scanner takes too long to switch off laser diode).

Tier 1

Possible Root Cause Isolation Procedure Technical Support/Customer Action Reference

Communications Error

Re-start instrument and software.

  1. Shut down instrument power. Re-boot the PC. Turn on instrument power, wait 20 seconds, start the Panther Main software.
  2. Dispatch FSEField Service Engineer. if error persists.
  

FSE
