018.004.00129

Distributor Hook – COP System Message

Complaint Description

Distributor hook motor lost some steps. Position X.

The Distributor hook drive motor lost some steps during a pick or lace of an MTU at position X. This error is non-fatal, so the instrument was able to recover. However, it indicates an issue at position X.

Technical Support

Possible Root Cause Isolation Procedure Service Action  
  • See FSEField Service Engineer. section.

  • This error does not show up on the GUIGraphical User Interface – allows users to interact with the software using images, graphical icons, and visual indicators rather than text commands.. It is hidden, and is not fatal. It does show up in the Health Report. If this error is seen, the FSE in charge of the instrument should be made aware of it, so that it can be addressed on the next service call.
  • Collect Advanced Sendlogs so that the FSE can determine where the "lost some steps" error occurred.

Field Service

Possible Root Cause Isolation Procedure Service Action Reference
  • Sticky door (if hook step loss occurs at an Incubator or at a Load Station).
  • Check the Incubator and Load Station for sticking doors. Manually move the doors open and closed and observe for sticking.
  1. Clean the door bearings to remove the tendency to stick.
  2. In Service Software, repeatedly re-teach and test the MTU picking and placing to verify the fix.
  3. Perform a System Operational Qualification procedure.

 
  • Module position mounting screws have loosened (especially at the Input Queue).
  1. Inspect the mounting screws to determine if any are loose.
  2. If the Input Queue has moved because of operator use, inspect the ball detent for proper lubrication and adjustment.
  1. Re-teach the linear distributor to the input queue following the procedure in the PANTHER Service Manual.
  2. Use a straight hex driver (not a ball end) to properly torque the input queue mounting screws to ensure that the screws don’t become loose.
  3. Lubricate and adjust the ball detent to reduce the amount of force required to open and close the input queue.
  4. Run a system Operational Qualification.
  5. Close the service drawer, install the injectior, start the PANTHER UI and prime the instrument to test the Linear Distributor MTU picking from the input queue.
  • GP11-243-FSN System Input Queue Detent Mechanism Adjustment
  • Loose Theta motor causing poor auto-teaching or excessive Distributor head movement during a pick or place MTU operation.
  1. Inspect the Theta drive meshing.
  2. The Distributor head should not have excessive play in the Theta direction due to gear backlash.
  1. Adjust the Theta drive meshing.
  2. Re-teach the Distributor to all modules after adjusting the Theta drive. Most likely all modules have been taught incorrectly.
  • PANTHER System Service Manual Distributor Alignment and Teaching
  • Loose hook causing poor auto-teaching and excessive movement during MTU picking and placement. Or, hook not square with Distributor head.
  1. Inspect the hook for squareness with the Distributor head.
  1. Re-square the hook.
  2. Re-teach the Distributor to all modules.
  3. Perform a System Level Operational Qualification.
  • Linear Distributor Hook Leveling Instructions
  • PANTHER System Service Manual System Level Operational Qualification
  • Distributor teaching.
  1. Prepare the PANTHER instrument for service.
  2. Review the logs using view log (procedure) for Linear Distributor messages indicating 'lost steps' or 'lost some steps' at the suspected position and at other positions. 'lost some steps' will not be a fatal message.
  3. Check Linear Distributor teaching at the affected positions. (procedure indicating thorough method of checking teaching, with a marked MTU)
  4. Check MTU placements of affected modules in Service Software.
  1. Inspect the Linear Distributor for a loose hook, loose drive motors or loose belts.
  2. Re-teach the Linear Distributor to the affected module, paying close attention to how the hook touches the teach pin. (procedure) If there are problems teaching, refer to the Trouble Shooting Guide section 017.000.00032 Teach Sensor Active Before Starting Teach Movement or section 017.001.00032Teach Sensor Not Reached".
  3. Retest MTU picking and placing at the load station through service software. Run a system operational qualification."
  • PANTHER System Service Manual Distributor Alignment and Teaching Procedure
  • Warped MTU carriage or slot (all positions).
  1. Inspect the position and Distributor head for signs of white dust created by MTU scraping.
  2. Inspect picking and placing into the position repeatedly to determine if the MTU placement is rough.
  • Replace the module with the affected position.
