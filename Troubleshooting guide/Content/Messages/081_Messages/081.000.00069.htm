081.000.00069

Output Queue – COP System Message

Description

The MTU presence sensor in the Output Queue detects a MTU after loading process.

Technical Support

Possible Root Cause Isolation Procedure Technical Support / Customer Action Reference

Dirty MTU Presence Sensor.
  1. Request Logs.
  2. Check Logs/Error Codes.

Dispatch an FSEField Service Engineer..

N/A

Field Service

Possible Root Cause Isolation Procedure Service Action Reference
  • Build up on the Output Queue Injectors due to injector overspray of bleach/buffer.
  1. Check the Output Queue injectors for dry fluid build-up.
  1. Clean the Output Queue Dispense Injectors. (Build-up may cause injectors to spray fluid that eventually might get to the MTU.)
  2. Clean the MTU Presence Sensor.
  3. Replace the Output Queue Peri Pump Tubing if it is degraded.
  4. Make sure the Bleach and Deactivation Bottle bleed holes are not occluded.
  5. Make sure there are no holes/leaks in the Bleach and Deactivation Bottle tubings and fittings.
  • PANTHER System Service Manual—Output Queue Injector Removal and Replacement
  • Output Queue Injectors Cleaning Procedure
  • Dirty MTU presence sensor.
  1. Using service software, check to see if the MTU presence sensor is reading properly.
  1. Clean the MTU presence sensor.
  2. Clean the output Queue injector.
  • PANTHER System Service Manual—Output Queue Injector Removal and Replacement and Output Queue MTU Presence Sensor Calibration
  • Output Queue Injectors Cleaning Procedure
  • Faulty MTU presence sensor.
  1. Using service software, check to see if the MTU presence sensor is reading properly.
  1. Replace the MTU presence sensor.
  • PANTHER System Service Manual—Output Queue MTU Presence Sensor Removal and Replacement and Output Queue MTU Presence Sensor Calibration
