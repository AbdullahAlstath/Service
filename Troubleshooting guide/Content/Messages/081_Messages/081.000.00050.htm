081.000.00050

Output Queue – COP System Message

Description

Actuator reinitialized.

Technical Support

Possible Root Cause Isolation Procedure Technical Support / Customer Action Reference

Jammed Output Queue.
  1. Open the Waste Drawer and listen for dropped MTUs.
  2. If the jam cannot be isolated to the Solid Waste bin, and the instrument cannot be restarted, dispatch an FSEField Service Engineer..
  1. Did MTUs fall when the waste drawer was opened? If yes:
  2. It is most likely a jam due to improper placement of the Solid Waste Bag or Solid Waste Cover.
  3. Have the customer look at the Solid Waste Bin:
  4. Does it appear that there was a build up of MTUs either from waste bag or the waste cover? If yes:

  5. Was the waste cover installed correctly?

  6. Was the waste bag installed correctly?

Output Queue Waste Chute Jam Locations (PPT)

Jammed Output Queue.

Look at the Output Queue cover, is it crooked and/or not fully seated (pushed down)?

Properly seat the cover.

  

Field Service

Possible Root Cause Isolation Procedure Service Action Reference

Waste Cover improperly installed, causing a backup of MTUs into the Output Queue.

Look at the Waste Cover. Is it installed correctly (pushed back and down fully)?

If the Waste Cover is not installed correctly, instruct the PANTHER users how to properly install the Waste Cover.

Panther User Manual

Output Queue Waste Chute Jam Locations (PPT)

Waste Bag improperly installed, causing a backup of MTUs into the Output Queue.

Look at the Waste Bag. Is it installed flush against the walls of the Waste Bin, so there are no folds for MTUs to get caught on and back up.

If the Waste Bag is not installed correctly, instruct the PANTHER user how to properly install the Waste Cover.

Panther User Manual

Output Queue Waste Chute Jam Locations (PPT)

Output Queue cover on crooked or loose.

Look at the cover, is it crooked and/or not fully pushed down?

Properly seat the cover.

  

MTU caught on drooping COP-LD cable (or other cable).

Look under the service drawer. Are there any drooping cables that the MTUs could get caught on?

Properly secure any loose cables.

Output Queue Waste Chute Jam Locations (PPT)

MTU is caught on the MTU eject chute.

Is the jam in the waste chute? This is easiest to see from the left service drawer, with the waste drawer pulled out, look up underneath the Output Queue Is the Service drawer fully closed?

  • If NO, close and latch it.
  • If Yes, Is there a lip from the MTU chute that the MTUs can get caught on?
    • If Yes, see GP11-236-FSN Output Queue Chute Modification.

Ensure Service Drawer is fully closed and latched.

Refer to GP11-236-FSN document.
