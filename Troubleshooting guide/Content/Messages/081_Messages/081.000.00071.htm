Output Queue Actuator Suffered Step Loss or Stalled

Error Code

Dec Hex

081.000.00071

 0x51.0.00.0x0047

Complaint Description

Output queue actuator suffered step loss or stalled.

MDD recognizes the error h47 as

Waste slot blocked (Steploss stacker > MTU width)

Technical Support

Possible root cause

Jammed MTU.

TS troubleshooting

  • Reset instrument.

  • While instrument is off, have customer open the right panel and look at the output queue for any jammed or crooked MTU. It is not recommended for TS to advise customer to correct the jam. Always contact FSEField Service Engineer. first.

  • Open the Waste Drawer and listen for dropped MTUs.

  • Ask the customer to look at the Solid Waste and check the bag is flush against the walls and cover is seated properly. Correct if needed.

  • If instrument reset passes, perform a prime and MW cleaning to test the output queue. If all passes, recommend to run.

  • If the instrument doesn't pass initialization, dispatch FSE.

Field Service

MTU Jam

Possible Cause of Jam due to misrouted COP cable.

RESOLUTION:

Properly secure any loose cables.

TEST:

Look under the Service Drawer.

Check for any drooping cables on which MTUs could be caught.

MTU is stuck on the rails

MTU is stuck on the output queue rails as they may be dirty bent or have sharp edges.

Resolution

  1. Verify that the instrument is level.
  2. Verify that the vacuum is not excessively noisy or vibrating.
  3. Check to see if the rails are too close.
  4. Clean the rails.

Test

Check to see if there is a crooked MTU under the Output Queue aspirators.

MTU caught on the MTU eject chute

Resolution

Ensure the Service Drawer is fully closed and latched.

Test

  1. Check to see if the jam is in the waste chute. This is easiest ot see from the left Service Drawer, with the Waste Drawer pulled out. Look up underneath the Output Queue.
  2. Using Service Software, check to see if the drawer reads as fully closed.
  3. If No, close and latch the drawer.
  4. If Yes, check to see if there is a lip from the MTU chute on which MTUs can get caught.

Faulty Motor Drive

Movement of the drive is blocked or stalled by stray tubing, loose screws, loose belts, or worn out motors.

Resolution

Replace any faulty parts.

Test

If there is no MTU jam, look for any loose screws, belts, or worn out motors.
