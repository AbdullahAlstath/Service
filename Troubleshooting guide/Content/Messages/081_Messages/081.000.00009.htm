081.000.00009

Output Queue – COP System Message

Description

Position reached several retries.

Technical Support

Possible Root Cause Isolation Procedure

Technical Support

Customer Action

 Reference

Jammed Output Queue.
  1. Open the Waste Drawer and listen for dropped MTUs.
  2. If the jam cannot be isolated to the Solid Waste bin, and the instrument cannot be restarted, dispatch an FSEField Service Engineer..
  1. Did MTUs fall when the waste drawer was opened?
    • If yes, most likely a jam due to improper placement of the Solid Waste Bag or Solid Waste cover.
  2. Have the customer look at the Solid Waste Bin:
    • Does it appear that there as a build up of MTUs either from the waste bag or the waste cover? if yes:
      • Was the waste cover installed correctly?
      • Was the waste bag installed correctly?

Output Queue Waste Chute Jam Locations (PPT)

Jammed Output Queue.

Look at the Output Queue cover to see if it is crooked or improperly seated.
    Properly seat the cover.
