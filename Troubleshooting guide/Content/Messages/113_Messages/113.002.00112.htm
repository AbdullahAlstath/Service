113.002.00112

TCR Carousel – COP System Message

Description

TCR Carousel mixer step loss or stall.

Technical Support

Possible Root Cause Isolation Procedure Technical Support / Customer Action Reference

Obstructions that would prevent the TCR Carousel from moving properly.
  1. If there a stray object preventing the mixer from turning? look for tips, loose springs, etc.
  2. Is the TCR mixer coming in contact with the incubator lid?
  3. Any other obstructions below the TCR mixer?
  4. Any obstructions on the top?

Remove the obstruction if one is found.

N/A

Field Service

Possible Root Cause Isolation Procedure Service Action Reference
  • Obstructions that would prevent the TCR Carousel from moving properly.
  1. If there a stray object preventing the mixer from turning? look for tips, loose spring, etc.
  2. Is the TCR mixer coming in contact with the incubator lid?
  3. Is there a loose cable that is preventing the TCR mixer movement?
  4. any other obstructions below the TCR mixer?
  5. Any obstructions on the top?
  • Remove the obstruction if one is found.

N/A
  • Loose/broken TCR mixer home sensor, and/or missing TCR mixer home flag.
  • Look at the TCR mixer home sensor and TCR mixer home flag, ensure they are intact and functioning.
  • Fix, replace, or tighten the broken or missing part.
  • PANTHER System Service Manual—TCR Carousel Home Sensor Removal and Replacement
  • The TCR Carousel belt is tensioned incorrectly.
  • Feel the belt to see if it is too tight or too loose.
  • Retension the TCR Carousel belt.
  • PANTHER System Service Manual—TCR Carousel Motor Removal and Replacement
  • TCR fluid has been spilled onto the mixer, most likely into one (or all) of the bearings.
  • Are there any noticeable spills in or around the bearings?
  1. Attempt to clean spilled TCR with water.
  2. If this does not work, replace the TCR mixer. Do not take the TCR mixer apart—a jig is required to correctly re-assemble it.
  • PANTHER System Service Manual—TCR Carousel Module Removal and Replacement
  • TCR mixer motor is burned out.
  1. With the power to the instrument off, attempt to move the TCR mixer.
  2. If it is difficult to move the mixer, the motor needs to be replaced.
  1. Replace the TCR Carousel Motor.
  2. If this does not work, replace the mixer. Do not take the mixer apart -a jig is needed to correctly assemble it.
  • PANTHER System Service Manual—TCR Carousel Motor Removal and Replacement
  • PANTHER System Service Manual—TCR Carousel Module Removal and Replacement
