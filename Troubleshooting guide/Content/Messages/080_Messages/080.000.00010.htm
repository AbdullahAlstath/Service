Input Queue Pack Drive Motor Suffered Step Loss

Error Code

Dec Hex

080.000.00010

 

Complaint Description

Input Queue pack drive motor suffered step loss or stalled

Technical Support

Check Input Queue

  • Check if MTUs are placed in front of the pusher.
  • Check for jammed MTUs or obstructions in the queue.
  • Make sure only 25 MTUs are loaded in the queue.
  • Remove incorrectly seated MTUs or obstructions.

Next Steps

  • Restart the instrument.
  • Perform a prime and/or MW clean to test the Input Queue.
  • Review case history for previous Input Queue errors. Notify FSEField Service Engineer. if there were recent cases.
  • Instruct customer to monitor.

Field Service

Bad MTUs

Resolution

  1. If possible, take a photograph of the state of the MTUs.
  2. Remove the MTUs by hand, taking care not to spill tiplets.
  3. Inspect MTUs for any abnormalities.
  4. If the MTU is suspect as defective note the LOT number of the MTU’s contact Tech Support to open a complaint and return the suspect bad MTU’s for further investigation.

Test

Make sure other MTU Lot numbers are able to process thru the input queue successfully

Stray Tiplet

A stray tiplet fell between the rails, preventing the pusher mechanism from fully retracting.

Resolution

Remove the stray tiplet.

Test

  1. Open the MTU Input Queue.
  2. Look between the rails for any stray tiplets that may be preventing the pusher mechanism from fully actuating.

Misaligned MTU Input Queue Rails

RESOLUTION:

Use the alignment tool to properly align the rails per the Panther Service Manual.

TEST:

  1. Open the MTU Input Queue.
  2. Slide several MTUs back and forth across the rails. The MTUs should slide smoothly.
  3. Also, use the Rail Alignment Tool to check the rail alignment.

Damaged Cable

A stray tiplet fell between the rails, preventing the pusher mechanism from fully retracting

RESOLUTION:

Repair or replace damaged cable

TEST:

Visually inspect for damaged cable. Insure the cable is not pinched in the service drawer.

Dirty packing sensor, misaligned, or faulty packing sensor

RESOLUTION:

  1. Clean the packing optical sensor.
  2. Tighten the 3 posts and screws that secure the PCB.
  3. Replace the Slave PCB.

TEST:

  1. Open the MTU Input Queue and inspect the optical sensor behind the white packing button. Note whether it is dirty. Using Service Software, push the packing button and see if the state changes.
  2. Open the MTU Input Queue and inspect the 3 posts that hold the PCB which contains the packing optical sensor. The posts should be screwed on tight. The screws that secure the PCB should be tight.
  3. Using Service Software, pack some MTUs. If the module packs MTUs correctly, yet the system still reports a packing error, it is likely due to a faulty packing sensor.

Faulty Encoder

RESOLUTION:

Replace the Encoder or the Module

TEST:

Using Service Software, pack some MTUs.

If the motor does not stop and keeps pushing for an excessive amount of time, it is likely due to a faulty encoder

Faulty Motor or Drive Mechanism

RESOLUTION:

Replace the Motor, Belt, or the Module

TEST:

Using Service Software, initialize the module.

Note whether the MTU pusher moves. If it does not move, it is likely due to a faulty motor or drive belt.

Also check for debris, such as tiplets.
