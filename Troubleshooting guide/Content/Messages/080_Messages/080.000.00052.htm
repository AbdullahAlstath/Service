080.000.00052

MTU Input Queue – COP System Message

Description

Input Queue MTU packing error.

Technical Support

Possible Root Cause Isolation Procedure Technical Support / Customer Action Reference

Bad MTUs (mis-packed MTUs)
  1. Open the MTU Input Queue drawer and visually inspect the state of the MTUs.
  1. If possible, take a photograph of the state of the MTUs.
  2. Remove the MTUs by hand, taking care not to spill tiplets.
  3. Inspect MTUs for any abnormalities.
  4. If the problem persists, dispatch an FSEField Service Engineer..
  • PANTHER System Operator's Manual—Load MTUs

Field Service

Possible Root Cause Isolation Procedure Service Action Reference
  • Bad MTUs (mis-packed MTUs)
  1. Open the MTU Input Queue drawer and visually inspect the state of the MTUs.
  1. If possible, take a photograph of the state of the MTUs.
  2. Remove the MTUs by hand, taking care not to spill tiplets.
  3. Inspect MTUs for any abnormalities.
  4. If the problem persists, dispatch an FSE.
  • PANTHER System Operator's Manual—Load MTUs
  • Loose connection.
  1. Make sure all connections are tight.
  1. Re-seat connections.

N/A
  • Misaligned rails.
  1. Open the MTU Input Queue.
  2. Slide several MTUs back and forth across the rails. The MTUs should slide smoothly.
  3. Also, use the Rail Alignment Tool to check the rail alignment.
  1. Align the rails with the Rail Alignment Tool.

N/A
  • Dirty packing sensor, misaligned, or faulty packing sensor.
  1. Open the MTU Input Queue and inspect the optical sensor behind the white packing button. Note whether it is dirty. Using Service Software, push the packing button and see if the state changes.
  2. Open the MTU Input Queue and inspect the 3 posts that hold the PCB which contains the packing optical sensor. The posts should be screwed on tight. The screws that secure the PCB should be tight.
  3. Using Service Software, pack some MTUs. If the module packs MTUs correctly, yet the system still reports a packing error, it is likely due to a faulty packing sensor.
  1. Clean the packing optical sensor.
  2. Tighten the 3 posts and screws that secure the PCB.
  3. Replace the Slave PCB.
  • PANTHER System Service Manual—MTU Input Queue Slave PCB Removal and Replacement
  • Faulty encoder.
  1. Using Service Software, pack some MTUs.
  2. If the motor does not stop and keeps pushing for an excessive amount of time, it is likely due to a faulty encoder.
  1. Replace the encoder or the module.
  • PANTHER System Service Manual—MTU Input Queue Module Removal and Replacement
  • Faulty motor or drive mechanism.
  1. Using Service Software, initialize the module.
  2. Note whether the MTU pusher moves. If it does not move, it is likely due to a faulty motor or drive belt.
  3. Also check for debris, such as tiplets.
  1. Replace the motor, belt, or module.
  • PANTHER System Service Manual—MTU Input Queue Module Removal and Replacement
