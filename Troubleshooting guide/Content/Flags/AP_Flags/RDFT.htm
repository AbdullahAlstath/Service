RDFT – RDV Failure TCR

Assay Processing Flag

Complaint Description

RDV Failure TCR – RDV indicated a failure during dispense of TCR Reagent. There is an RDV Error Type message associated with each dispense failure – either 2, 64, 128, or a sum of any of these (for example, Error Type 192 means Error Type 64 and Error Type 128 both occurred).

  • Error Type 2 – Maximum pressure threshold exceeded.
  • Error Type 64 – Minimum mean pressure threshold not met.
  • Error Type 128 – Minimum pressure down time threshold not met.

Tier 1

Possible Root Cause Isolation Procedure Technical Support/Customer Action Reference

Precipitate in TCR due to TCR storage below room temperature (refrigerator)

Verify that TCR Reagent is properly stored when not on the instrument.

Check to be sure the customer stores the reagent properly, according to product package insert.

N/A

Foam reagent (typically Error Type 128)

Visually check for bubbles in the bottle.

Pop the bubble.

N/A

Pipettor tips damaged/wrong type (typically Error Type 2)
  1. Visually verify damage to Pipettor tips.
  2. Determine where the obstruction occurs (typically at the Reagent Bay lid).
  3. Verify that tips are not the wrong type.
  1. Re-teach the Pipettor.
  2. Fix hardware obstruction (reseat the Reagent Bay lid and reinitialize the instrument).
  3. Use correct tips (1 mL Eppendorf capacitive with filter).
  • Curve: Normal Aspiration @ Aspiration TCR
  • Curve: Sample Tip Missing Filter @ Aspiration TCR
  • Curve: Normal Dispense @ Dispense TCR
  • Curve: Sample Tip Missing Filter @ Dispense TCR

Pipettor tips lack filters (intermittent but persistent Error Type 64)
  • Visually verify that Pipettor tips have white filters.
  1. Use correct tips.
  • Curve: Normal Aspiration @ Aspiration TCR
  • Curve: Sample Tip Missing Filter @ Aspiration TCR
  • Curve: Normal Dispense @ Dispense TCR
  • Curve: Sample Tip Missing Filter @ Dispense TCR

Fluid viscosity (can be any of the above three Error Types)
  1. Compare dispense pressure against a good dispense curve (unflagged dispense event).
  2. Check the reagent for uniformity.
  1. Check to see if the reagent is expired.
  2. Check to be sure the reagent type matches the assay.
  3. Check to be sure the customer properly reconstituted the reagent.

N/A
