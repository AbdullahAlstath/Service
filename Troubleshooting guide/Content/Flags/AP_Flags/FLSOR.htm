FLSOR – Fluorometer Has an Off-Target Error

Assay Processing Flag: FLSOR

Complaint Description

AMP incubator

Flag: FLSOR

FLSOR flag affects all assays, as it is difficult to decouple firmware on/off target check during assay processing.

Technical Support

Auto Dispatch FLSOR (fluorometer has an off-target error) as a Severity 2. Dispatch as a Severity 1 if customer only runs Real-Time assay. Perform troubleshooting as normal. If instrument restart is successful, customer may process TMA and Fusion assay samples. Inform customers not to run Real-Time assays until service is provided.

Troubleshooting:

  • Restart the instrument.

Field Service

Log Review

Keyword: Off-Target | On -Target

2019-12-12

23:14:05,101|[ProcessEvent]|SpecialInformationHandling|ProcessManagement|Info|Error|Off-Target measurement problem started for Rtf2 channel 5

Rtf2 channel 5 = RTF 677, 5th LED having issues.

From logs, determine if range exceeds high or low end...

filter for >>> CommandID=0x99 >>> ignore other commands (e.g. 0xa6)!

2019-12-16

13:32:09,701|[ProcessEvent]|SpecialInformationHandling|ProcessManagement|Info|Normal|Received target data: RTFTargetDataEvent - Device=Incubator3 CommandID=0x99 Severity=Message EventID=0x0 original sender=0x22 time=107541 RTF=RTF2 selectedChannel=0 LED=3 MessageID=4603 Result=249

RTF = RTF2 // RTF = fluorometer installed RTF1,2,3,4,5,6

selectedChannel=0 // measurement location on target or off target, 0 = off target, 1 = RTF 1 on target, 2 = RTF 2 on target, etc.

LED=3 // led is tube# or channel in array.

MessageID=4603 //ignore

Result=249 //fluorometer reading

Off target values should coincide with nominal ranges during install.

Upload to EFT.

If FW values match, then proceed to ssw:

  1. Initialize RTFs and perform single RTF measure test. e.g. this is same measurment to verify RTF is within range when installing RTFs.

  2. If 1 is okay, verify if target/off target slot error by introducing MTU into Amp incubator.

    • Move slot 1 to door position.
    • Pick MTU from IQ and place in AMP incubator (use MTU sensor to verify mtu picked and placed).
    • Move slot 1 to RTF# in question.
    • Perform read and check measurements. check behavior is as expected note: MTU doesn't fluoresce for all fluorometers.

  3. DO NOT FLIP/INVERT - AMP incubator in the event debris landed on the fluorometer. Remove fluorometer and inspect for debris.

    • If debris found, attempt to capture and return debris to San Diego. Run ssw check again.
    • If no debris found, likely RTF failure. Also return to San Diego.
