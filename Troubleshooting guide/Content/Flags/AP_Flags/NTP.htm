Technical Support

No Tips Available

Resolution

  1. Add tips.
  2. Check to see if the state changes from Empty to Full in the PANTHER System GUIGraphical User Interface – allows users to interact with the software using images, graphical icons, and visual indicators rather than text commands..
  3. Verify that the Customer defined the tip tray load pattern correctly through the PANTHER GUI.

Test

Visually verify the tips are present.

Tip Tray is Improperly Seated

Resolution

Reseat the tray.

Test

Visually verify the tray is properly seated.

Incorrect Tip Types

Resolution

Replace the tips with the correct tip type.

Test

Verify the tips conform to the tip standards outlined in the PANTHER System Operator's Manual.

Tip Drawer Is Not Closing Properly

Resolution

Align the tip drawer and close the locking mechanism.

Test

  1. Visually verify that the trip drawer closes and locks properly.
  2. Verify that the drawer close and lock states display properly.

Teaching – Tip Alignment

Resolution

Re-teach the pipettor.

Test

  1. Using the Service software, pick four random tips with each pipettor arm from the same tray.
  2. Verify the tip tray doesn't move more than 1 mm.

DiTi Sensor

Resolution

Replace the pipettor arm if the sensor is defective.

Test

Move manually move the DiTi sleeve up and down and verify the status changes in the Service software.
