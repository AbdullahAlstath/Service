HB – Luminometer High Background

Error Code

Dec Hex

098.000.00xxx

  

Complaint Description

High Background (HB) flags are caused when the reading before the Auto Detects are dispensed (aka Dark Count) is too high.

Technical Support

Check Bleach and Wash Connections in the Universal Fluids Drawer

Check if the Bleach and Wash fluid connectors were swapped in the Universal Fluids Drawer.

If swapped, correct the line orientation and force three full primes.

Review Logs

Review Results Reports for patterns in the run or reagent prep related issues such as probe gradient.

Review logs for the Dark Count values.

  1. Open the FlashCurve file in CurveTrends.
  2. Scroll sideways to the Dark Count column.

  3. Review the Dark Count values.
    1. General Values:
      1. Normal: 100-500
      2. Borderline: 600-900
      3. High: 1000+
    2. Upper Limit for HB flags:
      1. AC2: 1000
      2. HPV: 1200
      3. HPV GT: 1500
  4. If Dark Count values are high, notify FSEs.

Next Steps

Review cases history for previous High Background errors. Notify FSEField Service Engineer. is there were recent cases.

Instruct customer to monitor.

Field Service

Injector Light Leak

Using Service Software perform a 2 second Dark Count check with the shutter closed then with shutter open (an MTU should be present in the lumo in any position 1-5 for this test). If the dark count is only high >500) with the shuttler open then a light leak is the problem. This could be at the injector (most likely) or in the lumo case. Look for damage or gaps in the black sleeve over the injector. Look for cracks in the injector.

Resolution:

Replace injector.

Test:

In SSW perform the 2 second Dark Count with and without an MTU.

Monitor customer runs.

Bad PMT

Using Service Software perform a 2 second Dark Count check with the shutter closed then with shutter open (an MTU should be present in the lumo in any position 1-5 for this test). If the dark count is high with and without an MTU present, even with the shutter closed, then it is a bad PMT.

Resolution:

Replace the PMT.

Test:

In SSW perform the 2 second Dark Count with and without an MTU.

Monitor customer runs.

Luminometer Casing Light Leak

Using Service Software perform a 2 second Dark Count check with the shutter closed then with shutter open (an MTU should be present in the lumo in any position 1-5 for this test). If the dark count is only high >500) with the shuttler open then a light leak is the problem. If the injector is not the source of the light leak, look for loose or cracked casing parts, such as the lid not being secured or a crack in the lid.

Resolution:

Secure loose casing.

Replace the Luminometer.

Test:

In Service Software, perform the two-second Dark Count with and without an MTU.

Monitor customer runs.
