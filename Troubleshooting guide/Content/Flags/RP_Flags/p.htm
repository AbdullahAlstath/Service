Description

The Software has reported an assay processing error.

This Flag is generic and not related to any specific fault mode. The “p” flag will be displayed on the Results report to notify the user that the software has flagged and/or invalidated one or more results in the report.

The trouble shooting approach for “p” flags should include a further review of any additional reported flags or logs review. See examples below.

Example 1

The instrument is unable to validate the Positive Calibrators due to a Channel error most likely due to an RTF failure. The instrument assigns a cce and then p flag. Subsequently controls are invalidated for the same reason (x flag) and thus the rest of the run is invalidated each result assigned f flag, x flag, and p flag.

In the logs:

04/01/2022 16:50:56 (01 09:50:56) [E] (Warning , Low ) [TestOrderManagement] cce flag assigned to Calibrator ID 462431447715012405712 for BV assay in rack 717-04. [261.000.00018]

04/01/2022 16:50:56 (01 09:50:56) [D] (Warning , Low ) [TestOrderManagement] p Flag assigned to SID 462431447715012405712 for BV assay in rack 717-04. [261.000.00020]

Resolution:

Troubleshoot the cce Flag.

For this example, cce flag was generated in the FAM channel, where some Controls were fluorescing unexpectedly.

Example 2

A “p” flag is assigned to a single result in the results report of a CV/TV run. No other results are flagged and no other errors are logged otherwise the run was valid.

04/01/2022 17:55:58 (01 10:55:58) [E] (Warning , Low ) [TestOrderManagement] Invalidated Sample ID 12358872 for CV/TV assay in rack 046-06 due to p flag. Sample will need to be retested. [261.000.00016]

Resolution:

For this example, the internal control did not fluoresce in the RTF. Troubleshooting should focus on the reagent prep process.
