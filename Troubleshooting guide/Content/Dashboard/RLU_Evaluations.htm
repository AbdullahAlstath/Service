RLU Evaluations

RLU Evaluations are conducted in following four modules:

  • Flash-Check

  • System-Check

  • HPV-PQ

  • AC2-PQ

  • FLASHCHECK

The Flashcheck Reagent is intended for use in performing Quality Control verification of the Auto Detect fluid pumps and injectors in the PANTHER Luminometers as part of new instrument Manufacturing and existing instrument Service/Maintenance procedures. The PANTHER Luminometers are self-contained microprocessor based instruments that measure Relative Light Unit (RLU) values and report raw data for further analysis. The software in these instruments allow protocol programming, perform quality control calibration, acquire RLU values and monitor various sensors to warn the user of possible invalid conditions. The instruments contain pumps and injectors that dispense detection reagents (Auto Detect Reagents) that create chemiluminescent reactions. The Flashcheck Reagent is a chemiluminescent oligonucleotide complex dissolved in an acidic buffered detergent-based solution. Flash Check shall be developed as a system check to measure the performance of High Count and Chiron Luminometers to ensure that assay results are consistent within an instrument and from instrument to instrument.

Flashcheck is a chemiluminescent formulation that generates a signal on PANTHER instruments by sequential mixing with a hydrogen peroxide reagent (Auto Detect 1) and a sodium hydroxide reagent (Auto Detect 2).

The Flash Check software module is responsible for displaying the results of a Flashcheck Assay reagent test(s). The results of these tests consist of measuring luminescence from 4 PANTHER MTU (Multi Tube Unit) x 5 replicates totaling 20 replicate samples. Each replicate luminescence measurement consists of 200, 10–msec RLU (Relative Light Unit) sample measurements from the Luminometers found in each of the 4 MTUs of the PANTHER RT Incubator. The 200 sample measurements are then converted into fifty intervals containing 40-msec RLU values by summing every four cells and storing the values. From there, average and variant statistical values are calculated to determine acceptance criteria. The system shall also indicate whether there are outliers or no outliers.

  • SYSCHCK

The System Check software module is responsible for verifying that PANTHER luminometer is in compliance with performance validity and acceptance criteria defined in the Software Requirements Specification document. The software will run several statistical evaluations with the Syscheck Assay of 12 replicates. The result report displays the test demographics along with the user input data. It also includes a calculated calibration factor with a listing of all the test-orders Raw RLU and Calibrated RLU values. The last page of the report displays additional calculated statistical results such as “Average Calibrated RLU”, “Standard Deviation”, “Covariance”, “Dark Counts” among others. The software module follows a similar processing methodology as the FlashCheck module.
