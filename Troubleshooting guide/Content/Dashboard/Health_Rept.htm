Health Reports

Health reports consist of a series of sub reports. The date and time range you specify for the report determines its content. Each health report type contains a specific set of sub reports. Health reports consist of the following grouped sections:

  • Report header – contains information that identifies the site, report run date and time, and report title.
  • Report body – contains sub reports that make up the overall report.
  • Page footers – contain the report date range, page numbers, and instrument serial number.
  • Health Reports populated with the Dashboard Application:
  • Panther Health Report

The Panther health report summarizes test order activity, flagged test orders, events, and diagnostic information for a specified date range. This report is created if greater than 32 hours has elapsed from the previously generated report.

A health report summarizing test order activity, flagged test orders, events, and detailed diagnostic information for a date/ time range derived from selected work lists. It is intended for use by Manufacturing for diagnosing saline test runs.

  • How to Run a Health Report
  1. Select report – Choose a report from this drop-down list.
  2. Select report date – Choose the date to run the report for.
  3. Preview – Click Preview on the left side of the screen to generate the report. The report appears on the right side of the screen.

Click these buttons during or after you run a report:

Command Symbol Effect

Stop

Stops the report from generating.

Refresh

Starts the report generation from scratch.

First Page

Jumps to the first page of the report.

Previous Page

Jumps to the first previous page of the report.

Page Field

Displays the current page the report is on; can edit the field with a different page number.

Next Page

Jumps to the next page of the report.

Last Page

Jumps to the last page of the report.

Print

Prints the export.

Page Setup

Select the paper size, orientation and margins.

Export

Exports to Acorbat (PDF) file.

Zoom

Enlarges or reduces the display view on the right screen.
  • Health Report Sections
Health Report Section Description

Software Version(s)

System History with the software installation dates and software version numbers.

Firmware Version(s)

System History with the firmware installation dates and firmware version numbers.

Installed Assays(s)

The Installed Assays(s) version numbers and their installation dates.

System Statistics

Statistics of the Instrument: Uptime, Number of Restarts and Number of Fatal Errors that occurred since the previously generated report.

Assay Test Order Count

Assay types that ran on the instrument and the total number of assays executed over the duration of the report.

Rate of Invalids

Statistics of the Instrument: Number of Tests, Number of Invalids and Rate of Invalids that occurred since the previously generated report.

Total Test Orders with Flags

The number of test orders attempted on the system with the percentage of samples flagged during the interval of the report generated.

Test Orders with Single Flags

The number of test orders released with a single flag and the corresponding percentage.

Test Orders with Multiple Flags

Number of times this specific confirmation of flags occurred over the time interval of the report generated.

Flags By Module

The number of flags that occurred per instrument module.

Notable Events

A Subset of events that occurs during the instrument activity and message log events filtered for instrument critical events. I.E. Prime, Hardware Failures, Non Fatal Hardware Events and Issues.
  • Color codes
  • Message – Green text
  • Warning – Orange text
  • Critical – Red text
  • Fatal – Red background with black text
