PRO360° Connectivity Tester Feature

The PRO360° Connectivity module has additional functions that allow the FSEField Service Engineer. to:

  • View the Network Interface Card (NIC) configuration settings.
  • Test TCP/IP address and port connectivity. It is used to ensure LISLaboratory Information System. connectivity has been configured properly.
  • Determine if DNS resolution occurs properly.
  • Ensure EFT connectivity exists. EFT connectivity is needed for RSL.
  • Perform a basic test to ensure that the Panther NIC has been configured correctly.
  • PRO360° Connectivity Tester

The PRO360° Connectivity module displays information of any RDXM server configuration as network addresses are tested. When this test is run, it produces a status result of each connection by executing a network request to each address that is listed. Overall, this module enables:

  • Viewing the Network Interface Card (NIC) configuration settings.
  • Testing TCP/IP address and port connectivity. It is used to ensure LIS connectivity has been configured properly.
  • Determines if the DNS resolution occurrs properly.
  • Ensures EFT connectivity exists. EFT connnectivity is needed for RSL.
  • Performs a basic test to ensure that the Panther instrument NIC has been configured correctly.

  • Network Connectivity Tester

The Network Connectivity Tester module is used to determine if a network route exists, if a server is accepting network connections, and optionally if DNS can be resolved. For example, this tester can be used to verify that the LIS is accessible and accepting connection to the LIS Host. Another use of this tester is to determine if the Panther has the ability to access the RDxM servers.

  • Network Connectivity Tester – Columns

Test Name

Displays network connection result.

IP or Hot Name

Enter the network address or a DNS name to test.

TCP/IP Port Number

Enter the port number to test.

If you enter a DNS name, tester tries to resolve the address. Then using this address, tester tries to establish a network connection to the address over the port number entered.

If you enter an IP address, tester tries to establish a network connection to the address over the port number entered
