LIS Monitor

The LISLaboratory Information System. Log File monitoring software module provides the technician the ability to view LIS log messages as they are being created by PANTHER from the LIS system. This tool exposes any possible malformed messages that may cause invalid or erroneous data that PANTHER may not be able to handle properly. After turning on the LIS logging features located on the PANTHER system LIS Configuration screen, the LIS Monitor will display all LIS / ASTMAmerican Society for Testing and Materials (ASTM) is an international standards organization that develops and publishes voluntary technical standards. traffic. This allows the FSEField Service Engineer. to determine if connectivity has been properly configured and allows the FSE to work with the LIS Vendor on the ASTM message formats.

Use the log file monitor to view two different types of transport message files: RS232 and TCP/IP. Typically one of the two transports will be set up by the technician but never both at the same time. The output display of the monitor shows the last 500 or less messages that were received by PANTHER and will ignore any older messages. The monitor adds new messages received and removes older messages from the 500 message buffer to ensure that the buffer limit is never exceeded.

The top view displays any TCP messages, while the bottom view displays any RS232 messages. A green monitoring button, File Monitor On turns the monitor on or off. It uses the FileWatcher event service, to minimize system CPU overhead when monitor is not in use.

Table below lists buttons in LIS monitor:

LIS Monitor Buttons Description

Load Logs

Load LIS log messages created by Panther from the LIS system.

File Monitor Off

Turns the monitor on or off.

Clear Logs

Removes displayed logs.
