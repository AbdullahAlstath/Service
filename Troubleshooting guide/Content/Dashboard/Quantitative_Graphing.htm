Quantitative Graphing

The Quantitative Analysis software module provides the technician a view into the general pressure or command curve data over a designated range of time. This curve data is similar to the curve data reported by the Graphing module. The result plots, however, are a composite of curve data over the designated time range.

The software retrieves the curve data from the database in incremental requests and provides a continuous plotted update as the data is retrieved. The plotting report controls automatic scaling of the output as new data arrives until the final data retrieval and update is completed for that user’s designated time range. After you enter a specific WorklistID or selectable date range, additional filter criteria become available.

This additional filter criteria selection helps build the final query for the successive curve type requests. Some of these selections are listed below. Note that the selections depend on the workflow defined in the executed assay. Specifically, the values are presented depending on what the instrument has executed.

AC2 PQ

The AC2 PQ (Aptima Combo CT/GC Assays Performance Qualification) module is responsible for validating and verifying the luminescence acceptance criteria for proper PANTHER system operation. The software module processes the luminescence data similarly to the SysCheck and FlashCheck modules, in that statistical calculations are performed to verify compliance to the requirement specifications. The AC2 PQ module retrieves a specific population of panels (Panel A – Panel E) information from the database, based on a user selected run. The module then calculates acceptance criteria according to the following conditions:

APTIMA COMBO 2 Assay Acceptance Criteria
Target Excepted CT Result Expected GC Result RLU Specification % CV Allowable Variance
Panel A Negative Negative < 30,000 N/A 0/10
Panel B Positive Negative > 500,000 < 25 0/5
Panel C Negative Positive > 500,000 < 25 0/5
Panel D Positive Positive > 1,000,000 < 25 0/5
Panel E Positive Negative > 100,000 FIO 2/20

Allowable invalid reactions per assay run for APTIMA COMBO 2 Assay:

  • 1 – VVFS or VVFT
  • 1 – Cap Pierce Failure if caused by a double foil
  • Up to 2 Equivocal Panel E results (> 25,000 RLU)
  • Verify % CV and Average RLU of Panel B / Panel C ratio between 0.5 < Ratio < 2.0 for all valid results.

The output report displays the results of the calculations and whether there is an overall pass or fail of the complete test based upon the allowable invalid reactions.

The HPV PQ module retrieves a specific population of 40 panels (Panel A) information from the database, based on a user selected run. The module then calculates acceptance criteria according to the following conditions:

APTIMA HPV Assay Acceptance Criteria
Target Excepted Result N Expected Result Allowable Variance RLU Specification Analyte RLU Allowable Variance
Panel A Negative 40 0/40 ≤ 30,000 1/40

Allowable invalid reactions per assay run for APTIMA HPV Assay:

  • 1 – VVFS or VVFT
  • 1 – Cap Pierce Failure if caused by a double foil
  • Up to 1 Panel A > 30,000 RLU with a negative result
