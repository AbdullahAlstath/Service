Packing, Relocation and Idle Time

If relocation of the Panther system requires the system to be crated (for example, if it will be shipped by air or truck to a new location), the following must be completed.

Parts and Materials Required

  • Cordless drill with Phillips screw bits
  • 2 mm hex key
  • Proper PPE
  • Absorbent pads
  • DI water
  • Plastic bags
  • Zip ties
  • Bubble wrap
  • Panther system crate with packing material
  • Accessory Kit crate with packing material
  • Marketing Kit crate with packing material

The following parts are required prior to installation of the system at a new performance or clinical evaluation site:

  • Waste DWR, Waste Bottle Assy
  • Waste DWR, Vacuum Filter Assy
  • Deactivation Pump, Tubing Set
  • Sample Bay, Cover
  • Performance Qualification Kit (if required)

Time Required

  • 6 hours

Procedure

  If the system was used for marketing evaluation or clinical trials studies, dispose of the following items before packing the system per the local disposal requirements:
  • Waste DWR, Waste Bottle Assy
  • Waste DWR, Vacuum Filter Assy
  • Deactivation Pump, Tubing Set
  • Sample Bay, Cover
  1. Performance Qualification (if required)
  2. If moving the system to a new location (shipping), returning to OEM, or the System will sit idle more than 4 weeks, then perform the following:
    1. Replace all the universal fluids with DI Water, except Oil, and prime the system twice.
    2. Once complete, empty all bottles and prime the system twice with air.
    3. Remove and replace the MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. waste bag and empty all liquid waste.
  3. Packing Preparation
  4. Disposal of system components outlined in the following sections (if required)
    • Packing the Accessory Kit
    • Packing the Marketing Kit Crate
    • Crating the Panther System
    • Procurement of system components discarded during system removal (if required)
    • Installation of new components during system installation (if required)
