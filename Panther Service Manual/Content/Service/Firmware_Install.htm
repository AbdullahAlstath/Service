Run Instrument Setup (Loading Firmware)

Time Required

  • Up to 1 hour

The following Instrument Setup for Firmware procedures on specific System SW can be found below:

  • Instrument Setup for Firmware v5.3.2.7 and lower (System SW v5.3.3.0 and below)

  • Instrument Setup for Firmware v6.2 (System SW v6.2)

  • Instrument Setup for Firmware v7.1 and above (System SW v7 and above)

Note: If any hardware upgrades are required (i.e. RTFs, etc), install the upgrades first, then run Firmware.

Note: Screen shots are for reference ONLY.

Instrument Setup for Firmware v5.3.2.7 and lower (System SW v5.3.3.0 and below)

  1. From the FSE Shield, Click on the Instrument Setup icon.

    A yellow-highlighted Active X warning may appear near the top of the page.

  2. Right-click on the yellow-highlighted prompt.

  3. Select the Allow Blocked Content option.

    A security warning dialog box appears.

  4. Click Yes.

    The main Panther Instrument Setup page appears.

  5. Click the Select Ini File button.

    An Open dialog box appears.

  6. Select Parameter.ini and click Open.
  7. Click Read all parameters Upgrade Firmware Set all normal parameters to default Overwrite parameter from Ini-File.

  8. Click Yes.

    A Downloading Active message appears. The firmware upgrade can take up to 1 hour.

    When installing new modules or PCBs the following message may appear.

    A Firmware Upgrade successfully Finished dialog box appears.

  9. Click OK.
  10. If downloading firmware on a ATLAS (ROKA/IEH) System, please follow TB-01307 and update all incubator parameters per the TB.
  11. Make sure to update X-Axis parameters if changed prior to downloading firmware, TB-02024.
  12. If this is an installation, continue to Pipettor Teaching.

Instrument Setup for Firmware v6.2 (System SW v6.2)

Run Instrument Setup (Panther)

  1. From the FSE Shield, ensure no other programs are running.
  2. Click Instrument Setup on the Panther Fusion shield.
  3. Click Select XML File.
  4. In the Explorer window, select the appropriate firmware XML file.
    Refer to the applicable Technical Bulletin (TB) for your installation.
  5. Click Full Instrument Setup.
    The script will automatically update firmware and parameters on Panther modules.
    This process will take 15–50 minutes.

    Note: A prompt may appear during this process stating that a new COP PCB may have been installed and asking whether or not to continue. Select Yes if this message appears. This should have no effect on the firmware upload if new modules have been installed.

  6. Click OK when the script confirms that firmware has been uploaded successfully.
    Verify that there are no issues in the instrument setup run report that appears and then close the report.
    If firmware is not uploaded successfully, suspend this procedure and troubleshoot.

Run Instrument Setup (Fusion)

  1. With the Instrument Setup program still open, click Select XML File.
  2. In the Explorer window, select the appropriate firmware XML file.
    Refer to the applicable Technical Bulletin (TB) for your installation.
  3. Click Full Instrument Setup. The script will automatically update firmware and parameters on Fusion modules.
    This process can take 15-30 minutes.

    Note: A prompt may appear during this process stating that a new COP PCB may have been installed and asking whether or not to continue.
    Select Yes if this message appears. This should have no effect on the firmware upload if new modules have been installed.

  4. Click OK when the script confirms that firmware has been uploaded successfully.
    Verify that there are no issues in the instrument setup run report that appears and then close the report.
    If firmware is not uploaded successfully, suspend this procedure and troubleshoot.
  5. If downloading firmware on a ATLAS (ROKA/IEH) System, please follow TB-01307 and update all incubator parameters per the TB.
  6. Make sure to update X-Axis parameters if changed prior to downloading firmware, TB-02024.
  7. If this is an installation, continue to Pipettor Teaching.

Instrument Setup for Firmware v7.1 and above (System SW v7 and above)

  1. From the FSE Shield Click on Instrument Setup.
  2. The following Instrument Setup Splash Screen will appear.



    Note: Screenshots are for reference only.

    Note: If Panther Fusion, ensure all 8 Sidecar COP's dip switches are facing down.

  3. Select the options that apply in each of the following sections.
    1. Instrument Department
      1. If the instrument is Panther, select only Panther.
      2. If the instrument is a Panther Fusion, select both Panther and Fusion.

    2. Optional Modules
      1. Select the type of Pipettor installed for both the Panther and the Fusion (if applicable).

        Note: APP = Air Pipettor Pump, BLDC = Brushless DC Pipettor.

      2. Select the RTFs installed. RTF1, RTF3, and RTF5 are used for HIV, HCV, and HBV. RTF2 is used for BV, CV/TV, and SARS/FLU Multiplex.
      3. Select all applicable Panther Plus Upgrades.
    3. Developer Options (Fusion only)

      4. Note: This section will default to unchecked, but the options will automatically be selected when Fusion is selected, or if Fusion and Continuous Access Waste and UF are selected earlier in the procedure.

      1. When Fusion is selected, the required options will be automatically selected. Verify the correct settings by checking Developer Options.
      2. For a standard Panther Fusion, verify MRSA Lysing HW and TCR Target capture reagent—An assay-specific reagent added as part of specimen pipetting. Mixer 21 Positions are checked.

      3. For Panther Fusion Plus, verify Rotary: MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Parking Slots is checked.

  4. When all settings are set, select Start.

  5. From the new screen click the Select XML File button.

  6. If a Panther Fusion, from the Pop Up Window, ensure both xml files are visible.
    If both xml files are not visible, STOP and EXIT.
    Launch instrument setup again and re-configure the Splash Screen correctly.


  7. For Panther ONLY Systems select IS_Config_Panther and proceed to Step 9.

  8. For PantherFusion Systems:
    1. First Select IS_Config_Panther
    2. Successful run Instrument Setup, by completing Step 8-10 below
    3. Return to Step 4 and Select IS_Config_Sidecar.xml.
    4. Proceed to Step 9 and complete the rest of this procedure.
  9. Click on Full Instrument Setup.

  10. The Firmware Update will begin.

  11. When installing new modules or PCBs the following message may appear. Select OK to continue.

  12. Once finished, click OK, then Click STOP and CLOSE.

  13. If downloading firmware on a ATLAS (ROKA/IEH) System, please follow TB-01307 and update all incubator parameters per the TB.
  14. Make sure to update X-Axis parameters if changed prior to downloading firmware, TB-02024.
  15. For an installation, continue to Panels and Canopy Installation.
