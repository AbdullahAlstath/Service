Network Printing – M653 LaserJet

The HP Color LaserJet Enterprise M653 can be installed as a network printer.

Note: The M653 does not have an auto switching power supply.

The M653 is only available with a 100-127V power supply.

Refer to the Site Assessment for the appropriate models and their Part Numbers


The M653 can only be used with Image v6.0.13 and higher, which limits the installation of the network printer to System SW v7.1 and higher.

  • Requirements and Configurations
  • Unboxing and Physically Connecting the HP LaserJet M653
  • Configuring the Firewall to Use a Network Printer (if applicable)

Requirements and Configurations

There are two options to connect the M653 to the network.

Option 1: Connecting the M653 to a Customer Network

With this option, the printer is on the customer network. Panthers behind any Hologic-managed Cisco firewalls and customer-owned workstations are permitted to send print jobs to this network printer. This method requires:

  • A customer provided IP address, either:
    • Static: IP address + Subnet Mask + Default Gateway combination

      OR
    • DHCP: IP address only (if MAC address is required, refer to the MAC address steps)
  • Hologic-managed Cisco firewall must be configured to allow Panther printer data traffic to customer IP address.

Option 1 can be used irrespective of a Hologic-provided 24-port Cisco switch present on the Panther network.

Option 2: Connecting the M653 to the Panther Network

With this option, only Panthers directly connected to the Cisco switch can print to this network printer. Any Panthers outside of this switch and firewall will be unable to send print jobs to this network printer.

The only hardware requirement is the Cisco switch. Necessary configuration steps (below) consist of configuring the IP address of the M653 and configuring the printer on both FSE Shield Login and in Panther Software.

Option 2 allows for multiple network printers to be connected and installed on the same switch.

Unboxing and Physically Connecting the HP LaserJet M653

Note: Laser printers have higher power requirements.

Never connect the printer if the printer voltage doesn’t match the outlet voltage.

Never connect the network printer to the instrument UPS or UPS circuit.

  1. Unbox the network printer.
  2. Verify the voltage of the M653 model and plug into a power source.
  3. Connect the M653 to the desired network.
    1. For customer network, use a CAT-5e ethernet cable to connect the printer to the customer wall port.
    2. For Panther network, use a CAT-5e cable the Panther network, connect a CAT-5e to connect the printer to any port of the Cisco switch.

Configure the Firewall to use a Network Printer (if applicable)

Note:

There are two possibilities for networking the printer.

Option 1 is to network through the customer network.
An IP Address for the printer will be required from the customer.

Option 2 is to network within the Hologic network.
If Option 2 is needed, select NO when asked if the network printer will be used outside the firewall.

If the customer does not want the network printer on the customer’s network, there is the option for the printer to be connected to the switch.

Configure the IP address of the network printer to be 172.23.1.99,
subnet 255.255.255.0 and Gateway of 172.23.1.1

  1. Configure the Cisco 5505 or 5506-X using the latest Firewall Wizard version (minimum Firewall Wizard 6.0.1).
    • Panther System Software determines firewall version requirements for other features, such as RSL and SecureLink.
  2. When prompted for Network Printer, select Yes.
  3. Input the IP address of the network printer as directed in the Site Assessment.

For additional information, see the section titled Network Printer in Programming the Firewall.

Configuring the IP Address of the M653

  1. From the Home screen on the Printer control panel, open the Settings menu.
  2. Navigate to Networking > Ethernet > TCP/IP > IPV4 SETTINGS > Conƭig Method.

  3. Select Manual, and then press OK.
  4. Open the Manual Settings menu.
  5. Select the IP Address option.
  6. Using the on-screen keyboard, input the IP address, and then press OK. Repeat this step for the Subnet Mask and Default Gateway if needed.

    Note:
    If the network printer is directly connected to the customer network, input the given IP/Subnet Mask/Gateway from the Site Assessment.

    If the printer is directly connected to the Panther switch network, use the following addresses:

    IP Address: 172.23.1.99
    Subnet Mask: 255.255.255.0
    Gateway: 172.23.1.1

  7. Upon completion, click the Back arrow.

Determining the MAC Address of the M653 (if applicable)

Note: This section is required if the customer requires the printer MAC address to provide an IP address.

  1. From the home screen of the printer, select the Info icon at the top-right corner.
  2. Within the info page, select Ethernet.
  3. Within the Ethernet section, scroll down and the MAC Address is displayed.

Configuring the M653 via FSE Shield Software Login (Windows)

  1. From Panther Shield select Command Prompt.
  2. Type the command "start control" and press Enter. The Control Panel will appear.
  3. From Control Panel, select Devices and Printers.
  4. Within Device and Printers, select Add a printer.
  5. Select The printer that I want isn’t listed.
  6. Select Add a printer using a TCP/IP address or hostname and select Next.

  7. Input the IP address of the network printer. listed in the Site Assessment Form.
    If the Printer will be connected directly to switch device with the other Panthers (not connected to customer network), use 172.23.1.99.
    The Port name section will auto-populate.
    Uncheck the “Query the printer and automatically select the driver to use” box then select Next.

  8. In the Manufacturer pane, select HP.
    In the Printers pane, select HP Color LaserJet M652 M653 PCL-6 (V4).
    Select Next.

    Note: If driver does not appear, verify the correct Panther Image is being used.

  9. Select Use the driver that is currently installed (recommended) and select Next.
  10. When prompted, input a printer name (preferably the name of the lab) and select Next.
  11. Allow printer to install and select Next.
  12. On the Printer Sharing page select Do not share this printer radio button. Select Next.
  13. Verify a print job can be sent by clicking Print a test page. After ensuring the test page prints, select Finish.

Configuring the M653 within Panther Software

  1. Within Panther Main, navigate to Admin > System Configuration > Printer Management.
  2. Select the text box titled Default Printer Name.
  3. When the dialog box appears, select the name of the printer that was used in the procedure for adding the printer in FSE Shield Software Login/Windows.
  4. Select OK.
  5. Verify Panther SW print capability by test printing a report (e.g. Maintenance Log or Result Report).
