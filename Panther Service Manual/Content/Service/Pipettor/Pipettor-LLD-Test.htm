Pipettor cLLD & bLLD Test Procedure

Parts and Materials Required

  • Consumables (MTUs and Disposable Tips)
  • Tap water
  • Manual pipettor (from customer site, to measure tap water)

Time Required

  • 30 minutes

Procedure

Screenshots are for reference only. Your screen may vary.

First complete the cLLD Capacitive liquid level detection test, then repeat the procedure selecting bLLD.
cLLD tests the capacitive circuit. bLLD will show wear in the piston drive.
For information on bLLD vs cLLD, read Barometric vs Capacitive Liquid Level Detection

SAMPLE PIPETTOR

  1. Power on the Panther System and PC.
  2. Start Service Software.
  3. Setup a cLLD AND bLLD Test on the Sample Pipettor (Right Arm).
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. Fill each tube of an MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. with approximately 200 µL of tap water.
      (If available use a manual pipettor from customer site for accuracy)
    2. Insert the MTU into the Sample Dispense Slot.
      (Insert manually or use Service Software and the Service Queue.)
    3. Load 1 full tip tray in the left Tip Drawer, Position 1 (back left).
  4. Click on the Pipettor tab and select Main.
  5. Select Pipettor from the dropdown and click Initialize.

  6. Perform the cLLD AND bLLD test on the Sample Pipettor (Right Arm).
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. On the Pipettor tab select LLD Right Arm.
    2. In the S. Load section, double-click each square (1-5) to add all 5 tubes to the Coord. List.
    3. In the LLD section, enter “6” cycles.
    4. For a cLLD test, select the cap. bubble and check Log
    5. For a bLLD test, select the bar. bubble and check Log
    6. Click Execute. (Click OK in the “Delete Results?” window.)
    7. To pass, the Delta Z values must be less than 30.
      Save each passing test report (C:\Panther\Panther Service Software\Log\Reports\LLD).
      If the test does not pass, refer to Step 7.

  7. If the cLLD test on the Pipettor does not pass, try the following:

    1. Clean the Pipettor's gold leads
    2. Gently squeeze the leads together (fingers only) to improve contact with the DiTi.
    3. Turn off instrument and inspect the three Pipettor Pump motor screws for tightness
      (Pump motor at the top of the pipettor, requires 1.5 mm hex driver).
      Ensure instrument is off, as there is a possibility of shorting the board when accessing the screws.

  8. Re-run the cLLD test. If the test still does not pass, replace the pipettor.
    Make sure to perform the Z-Motor Mesh Tool Procedure when replacing the pipettor.
  9. Run the Pipettor Pressure Integrity Test and attach the report to the UCR.
    Remember that any value above 0.33 is now accepted as a passing test for the Pipettor Pressure Integrity.

REAGENT PIPETTOR

  1. Power on the Panther System and PC.
  2. Start Service Software.
  3. Setup a cLLD AND bLLD Test on the Left Arm.
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. Fill one empty reagent Enzyme bottle (100 test kit) with approximately 1 mL of tap water.
      (If available use a manual pipettor from customer site for accuracy)
      An Enzyme bottle from an FSE Flashcheck kit can be used.
    2. Place the Enzyme bottle in the Enzyme slot of a reagent rack and slide into Lane 1 of the Reagent Bay.
    3. Load 1 full tip tray in the left Tip Drawer, Position 1 (back left).
      At least 30 tips are required.
  4. From the Pipettor tab select Main.
  5. Select Pipettor from the dropdown and click Initialize.

  6. From the dropdown, select Reagent Module and click Initialize.
  7. Perform the cLLD AND bLLD test on the Reagent Pipettor (Left Arm).
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. On the Pipettor tab select LLD Left Arm.
    2. In the Reagent section, double-click the Lane 1, Position 2 square to add the bottle to the Coord. List.
    3. In the LLD section, enter “30” cycles.
    4. For a cLLD test, select the cap. bubble and check Log
    5. For a bLLD test, select the bar. bubble and check Log
    6. Then click Execute. (Click OK in the “Delete Results?” window.)
    7. To pass, the Delta Z values must be less than 30.
      Save each passing test report (C:\Panther\Panther Service Software\Log\Reports\LLD).
      If the test does not pass, refer to Step 8.

  8. If the cLLD test on the Pipettor does not pass, try the following:

    1. Clean the Pipettor's gold leads
    2. Gently squeeze the leads together (fingers only) to improve contact with the DiTi.
    3. Turn off instrument and inspect the three Pipettor Pump motor screws for tightness
      (Pump motor at the top of the pipettor, requires 1.5 mm hex driver).
      Ensure instrument is off, as there is a possibility of shorting the board when accessing the screws.

  9. Re-run the cLLD test. If the test still does not pass, replace the pipettor.
    Make sure to perform the Z-Motor Mesh Tool Procedure when replacing the pipettor.
  10. Run the Pipettor Pressure Integrity Test and attach the report to the UCR.
    Remember that any value above 0.33 is now accepted as a passing test for the Pipettor Pressure Integrity.

FUSION PIPETTOR

  1. Power on the instrument and PC.
  2. Start Service Software.
  3. Setup a cLLD AND bLLD Test on the Panther Fusion Pipettor.
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. Insert a Reconstitution Buffer Fluid pack in one of the four positions available.
  4. Click on the SC-Pipettor tab and Select Main.
  5. Select SC Pipettor from the dropdown and click Initialize.

  6. Perform the cLLD AND bLLD test on the SC Pipettor (Front Arm).
    First complete the cLLD test, then repeat the procedure selecting bLLD.
    1. On the SC-Pipettor tab select LLD Reagent Pipettor.
    2. Under PCR Recon Standard double click the position where the Reconstitution Buffer bottle was previously inserted.
    3. In the LLD section, enter “30” cycles and select “prepierce (1x)”.
    4. For a cLLD test, select the cap and check Log
    5. For a bLLD test, select the bar and check Log
    6. Click Execute. (Click OK on the “Delete Results?” window that appears.)
    7. To pass, the Delta Z values must be less than 30.
      Save each passing test report (C:\Panther\Panther Service Software\Log\Reports\LLD).
      If the test does not pass, refer to Step 7.

  7. If the cLLD test on the Pipettor does not pass, try the following:

    1. Clean the Pipettor's gold leads
    2. Gently squeeze the leads together (fingers only) to improve contact with the DiTi.
    3. Turn off instrument and inspect the three Pipettor Pump motor screws for tightness
      (Pump motor at the top of the pipettor, requires 1.5 mm hex driver).
      Ensure instrument is off, as there is a possibility of shorting the board when accessing the screws.

  8. Re-run the cLLD test. If the test still does not pass, replace the pipettor.
    Make sure to perform the Z-Motor Mesh Tool Procedure when replacing the pipettor.
  9. Run the Pipettor Pressure Integrity Test and attach the report to the UCR.
    Remember that any value above 0.33 is now accepted as a passing test for the Pipettor Pressure Integrity.
