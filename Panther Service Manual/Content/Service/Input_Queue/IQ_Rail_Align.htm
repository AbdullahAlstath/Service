Input Queue MTU Rail Alignment Procedure

What is Affected

This procedure applies to the following parts.

  • Section 1: Adjusting Part, MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. INPUT Q, MODULE
  • Section 2: Adjusting Part, MTU INPUT Q, MODULE
    • [Cut in to Panther Serial Number 1264 and higher]

Parts and Materials Required

  • Proper PPE
  • Input Queue Rail Alignment Tool
  • 2 mm Hex Key

Time Required

  • 15 Minutes

Procedure

Section 1: Adjusting 902880, MTU Input Q, Module

  1. Put on proper PPE.
  2. Shut down the Panther System and PC.
  3. Open the Input Queue drawer and remove all MTUs from the module.

  4. Place the Input Queue Rail Alignment Tool on the Input Queue's rail.
  5. Slide the Input Queue Rail Alignment Tool along the length of the rails.
    Note—If the Input Queue Rail Alignment Tool does not slide freely along the rails, the rails will need alignment.
  6. Locate and loosen the 4 screws that hold the left Input Queue rail.

  7. Pull the left rail as far towards the front of the system as possible.
  8. Tighten the 4 screws that were loosened in step 6.
  9. Place the Input Queue Rail Alignment Tool on the rails near the front of the Input Queue.
    Note—Properly spaced and aligned input queue rails will allow the tool to fall under its own weight. If the tool cannot slide to the bottom under its own weight, then the rails are misaligned at the front of the Input Queue.

  10. Loosen screws 2, 3, and 4 with a 2mm hex key if the Input Queue Rail Alignment Tool gets stuck near the front of the Input Queue. Do not loosen screw 1.

  11. With the screws loosened place the Alignment Tool on the rails near the front of the module. The tool should now slide easily onto the rails. Gently squeeze the rails together to set them against the tool as shown below.

  12. Tighten the screws that were loosened in step 10 with the Input Queue Rail Alignment Tool still on the rails.

  13. Re-check the alignment of the rails. The tool should now slide freely along the rails.
  14. Place the Input Queue Rail Alignment Tool on the rails near the rear of the Input Queue.
    Note—Properly spaced and aligned Input Queue rails will allow the tool to fall under its own weight. If the tool cannot slide to the bottom under its own weight then the rails are misaligned at the rear of the Input Queue.

  15. Loosen screws 1, 2, and 3 with a 2 mm hex key if the Input Queue Rail Alignment Tool gets stuck near the rear of the Input Queue. Do not loosen screw 4.
    Note—The Mid Bay drawer may need to be opened in order to access screw 1. Remove the Luminometer inject before opening the Mid Bay drawer.

  16. With the screws loosened, place the Input Queue Rail Alignment Tool on the rails near the rear of the module.
  17. Slide the tool on the rails to ensure the rails are aligned.
  18. Tighten the screws loosened in Step 15.
  19. Re-check the alignment of the rails by sliding the Input Queue Rail Alignment Tool on the rails.
  20. If after adjusting the rails, the Input Queue Rail Alignment Tool still does not slide freely along the rails, the rails may have been formed incrorrectly.
  21. Using the Input Queue Rail Alignment Tool as a guide, try to determine if the rails bow inward or outward as shown below.

  22. After determining the direction of the bowing, use the Input Queue Rail Alignment Tool to apply firm pressure to the rail that is bowed.
    Note—The Input Queue Rail Alignment Tool can be used to apply leverage to the rail to be bent.
  23. Test the alignment by sliding the Input Alignment Tool along the rails.

  24. Replace the module if none of the above steps results in satisfactorily aligned Input Queue rails.

Section 2: Adjusting MME-02193, MTU Input Q, Module

  1. Put on proper PPE.
  2. Shut down the Panther System and PC.
  3. Open the Input Queue drawer and remove all MTUs from the module.
  4. Place the Input Queue Rail Alignment Tool on the Input Queue's rail.
    Note—If the Input Queue Rail Alignment Tool does not slide freely along the rails, the rails will need alignment.
  5. Located the 8 screws that are shown below.

  6. Loosen all 8 screws.
  7. Pull the rails as far towards the front of the system as possible and re-tighten the screws.
  8. Place the Input Queue Rail Alignment Tool on the rails near the front of the Input Queue.
    Note—Properly spaced and aligned input queue rails will allow the tool to fall under its own weight. If the tool cannot slide to the bottom under its own weight, then the rails are misaligned at the front of the Input Queue.

  9. Place the Input Queue Rail Alignment Tool on the rails near the back of the Input Queue.
    Note—Properly spaced and aligned input queue rails will allow the tool to fall under its own weight. If the tool cannot slide to the bottom under its own weight, then the rails are misaligned at the rear of the Input Queue.

  10. Loosen screws 2, 3, 4, 6,7, and 8 with a 2 mm hex key if the Input Queue Rail Alignment Tool gets stuck near the front of the Input Queue.
    Note—The image below shows a green square surrounding the screws that need to be loosened to align the front of the Input Queue. Do not loosen screw 1 and 5.

  11. Loosen screws 1, 2, 3, 5, 6, and 7 with a 2 mm hex key if the Input Queue Rail Alignment Tool gets stuck near the rear of the Input Queue.
    Note—The image below shows a green square surrounding the screws that need to be loosened to align the rear of the Input Queue. Do not loosen screw 4 and 8.

  12. With the screws loosened place the Alignment Tool on the rails near the location where it previously would become stuck (front or rear). The tool should now slide onto the rails without resistance.
  13. Gently squeeze the rails together to set them against the Input Queue Rail Alignment Tool as seen below.

  14. With the tool still on the rails in the misaligned location, tighten the screws that were previously loosened.
  15. Re-check the alignment of the rails using the Input Queue Rail Alignment Tool.
  16. If after adjusting the rails, the Input Queue Rail Alignment Tool does not slide freely along the rails, the rails may have been formed incorrectly.
  17. Use the Input Queue Rail Alignment Tool as a guide and determine if the rails bow inward or outward as shown below.

  18. After determining the direction of the bowing, use the Input Queue Rail Alignment to apply firm pressure to the rail that is bowed.
    Note—The Input Queue Rail Alignment Tool can be used to apply leverage to the rail to be bent.
  19. Test the alignment by sliding the Input Queue Rail Alignment Tool along the rails.

  20. If none of the above steps results in satisfactorily aligned Input Queue rails, replace the module.

Verification

  1. Use the Input Queue Rail Alignment Tool to check the alignment of the rails.
    1. Place the Input Queue Rail Alignment Tool on the rails.
    2. The Alignment Tool should slide freely along the length of the rails and not bind.
  2. Use MTUs to check the alignment of the rails.
    1. Obtain 5 MTUs.
    2. Verify the MTUs are not warped, damaged, or defective.
    3. Look closely at the spacing between the MTU tubes. MTUs that have significantly uneven spacing between the MTU tubes should be reported and not used.
      Note—The image below shows an MTU with uneven spacing.

    4. Place the MTUs at the front of the Input Queue.
    5. Slowly push the group of MTUs with your finger back and forth along the rails.
    6. Observe how the MTUs slide the rails.
    7. MTUs should slide freely and not bind, tip, or rotate.

  3. Power on the Panther System and PC.
  4. Log in to Panther Service Software.
  5. Re-check the Input Queue to Distributor alignment.
    Note—If necessary re-align the Input Queue to the Distributor and re-teach all positions.
  6. Run a 5 MTU System OQ and include the report as part of the Service Report.
