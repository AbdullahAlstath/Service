Real-Time Fluorometer (RTF) Installation

Purpose

This procedure provides instructions to install Real-Time Fluorometers (RTFs) on Amplification Incubators. RTFs allow systems to run real-time assays such as BV, CV/TV, HSV, HIV-1, HBV, and HCV.

Parts and Materials Required

  • Proper PPE
  • FSE Tool Kit
  • (12) AMP INC Foam Plastic Rivet
  • (8) M3x6 SHC screws (included with each Fluorometer Assembly)
  • (1) Panther Fluorometer Assembly, 677 (Required for BV, CV/TV Assay Procedures required to prepare and perform a specific test. In the context of this document, assay refers exclusively to a Hologic test, such as Aptima Combo or Ultrio.)
  • Panther Fluorometer Installation Kit
    • (1) Panther Fluorometer Assembly, FAM
    • (1) Panther Fluorometer Assembly, HEX
    • (1) Panther Fluorometer Assembly, ROX
    • (1) Cable, Panther Fluorometer
  •  (1) RTF Alignment Tool
  Note—The RTFs can be ordered as kit or individually.

Time Required

  • 60 minutes including Alignment Procedure

Procedure

Part A: RTF Hardware Installation

WARNING—The AMP incubator contains amplicon and is a post AMP (dirty) module. Ensure safe lab practices are observed during this procedure and always wear PPE. Change gloves often, bleach tools after interaction with the Amp Incubator and always bleach tools after every service.
WARNING—MTUs may be present in module.
Remove all MTUs to avoid contamination.
  1. Power on the Panther System and PC.
  2. Start Panther Main and allow the system to initialize.
    Note—If initialization fails and MTUs are not cleared by the system, refer to Unloading Undeactivated MTUs from the Panther
  3. Check to make sure all MTUs are cleared from the system.
  4. Shutdown Panther Main, and power down the Panther System and PC.
  5. Prepare the work surface:
    • Clean a flat and stable laboratory work surface with 2.5%-3.5% sodium hypochlorite solution.
    • Wait at least 1 minute and then clean the surface with DI water. Do not allow the sodium hypochlorite solution to dry on the work surface.
  6. Open the Mid-Bay Drawer
  7. Remove the Amplification Incubator.
  8. Place the Incubator module upside down on clean bench pads. The three RTF labels shown here on the Incubator represent the installation location of the three individual RTFs.
    Note—The HEX RTF location is closest to the PCB and the FAM RTF location is closest to the door.

  9. Remove the three or four foam inserts from the locations indicated in Step 8. For each location, visually verify there are two dowel pins, and the pins and mating surface are clean and clear of debris.
    Note—Save all four foam inserts onsite in case they are needed for future use. Also, refer to Securing Amplification Incubator Foam Inserts and verify the remaining foam inserts are secured with plastic rivets.

  10. Remove each RTF from its packaging and verify the DIP Switch settings on each RTF matches the settings in the table.

  11. Match the Serial number of each RTF to its packaging, and document the serial number in the Service Notes.
    Note—The table below is useful for RTF identification using the OTMI number:
      RTF Identification
    FAM (RTF1) OTMI-xxxx-BL_x (blue)
    677 (RTF2) OTMI-xxxx-RD_x (red)
    HEX (RTF3) OTMI-xxxx-GN_x (green)
    ROX (RTF5) OTMI-xxxx-AM Analytical Module_x (amber)

  12. Label each RTF with a Sharpie on the metal side as shown, with the specific RTF name, installer’s initials, and date.

  13. Check the lenses of all RTFs for any debris or dust. If dirt or dust is found, clean the lens with a lens cloth only.
  14. Verify the dowel pins are clean and there is no debris on the mating surface.
  15. Secure each individual RTF to the incubator using two M3x6 screws as shown.

    Note—The RTFs should require minimal effort to seat and should sit flush on the mounting surface.

    Forcing the RTFs into position can damage the PCB. RTFs that are not seated flush may have inaccurate channel readings.

     

  16. Verify the RTFs are installed in the correct location as shown.

  17. Connect the RTF’s using the RTF cable.

    Note—If the orientation is not correct on the cable, and the FSE forces the connector, the solder on the board can break and turn the RTF dead on arrival.
  18. First connect the RTF cable to the Incubator PCB.

  19. Connect the HEX RTF next with the first available connector.

  20. Connect the 677 RTF to the next available connector (Required for BV, CV/TV Assay).
    1. If NOT installing the 677 RTF, skip one connector.
  21. Connect the FAM RTF to the next available connector.
  22. Skip one connector.
  23. Connect the ROX RTF to the next available connector.
  24. Route the cables as shown below.

  25. Carefully turn the incubator over right side up.
  26. Open the Incubator door, inspect and ensure each magnet inside the AMP Incubator is flush with the magnet holder as shown. Adjust the magnets if necessary by re-positioning the magnet with a gloved finger, no tools required.

  27. Re-install the Amplification Incubator.
  28. The RTF hardware installation is complete.

Part B: RTF Software Configuration

  1. Power up the Panther System and PC, and login to the FSE Shield.
  2. Start Service Software.
  3. On the Incubator tab, click on Parameter tab.
  4. Select Amp Incubator ID 0x22 in the Device dropdown menu.
  5. Change the Authorization Code field to “1”
  6. Click on the Set button.

  7. Click on RTF.
  8. Under RTF Cfg, check the boxes next to 1, 3, and 5.
    1. Check the box next to 2 if installing 677 RTF (Required for BV, CV/TV Assay).
  9. Click the Set button.

  10. A Service Software window will display “This operation needs authorization to write teach parameter.”
  11. Click OK.
  12. Another Service Software window will then display “Write all Parameters to NVM?”
  13. Click OK.
  14. Click on Parameter and verify Amp Incubator ID 0x22 in the Device dropdown menu is still selected.
  15. Enter 154 in the Parameter field.
  16. Click the Read button.
  17. Verify the New Value is “21”.

    1. If 677 RTF (required for BV, CV/TV Assay) is installed the new value will be “23”.

  18. Close Panther Service Software.
  19. Power cycle the Panther System.
  20. Start Service Software.
  21. Click on the Incubator tab.
  22. Select the AMP incubator from the dropdown box, as shown below.
  23. Click Initialize.

  24. Go to the Parameter tab.
  25. Select Amp Incubator ID 0x22 in the Device dropdown menu.
  26. Input “154” into the Parameter field.
  27. Click on the Read button and ensure the parameter value is still “21”.
    1. This value will be “23” if 677 RTF is installed (Required for BV, CV/TV Assay).

  28. Click on the RTF tab and ensure that the 1, 3, and 5 are still checked in the RTF Cfg. section.
    1. Make sure the box next to 2 is checked if 677 RTF is installed (Required for BV, CV/TV Assay).

  29. Verify nominal channel values for each RTF.
    Note—The Amp Incubator temperature should be stabilized, and RTFs warmed up to get accurate channel values. This usually takes 20-30 minutes after initialization. (Temp. should be 42.4 – 43.0°C)
    1. Select the "1" in the Single RTF No. drop-down. Click on the Start button under Measure, no Move. Verify the values in the Result field are in range.

    2. Required For BV, CV/TV Assay: Select the "2" in the Single RTF No. drop-down. Click on the Start button under Measure, no Move. Verify the values in the Result field are in range.
    3. Select the "3" in the Single RTF No. drop-down. Click on the Start button under Measure, no Move. Verify the values in the Result field are in range.
    4. Select the "5" in the Single RTF No. drop-down. Click on the Start button under Measure, no Move. Verify the values in the Result field are in range.

      Note—If any RTF reports values out of range, the RTF must be replaced. Document and label the RTF for return.
  30. Exit Panther Service Software.
  31. Run Panther Instrument Firmware Setup.
    Note—This will load firmware onto the RTFs.
  32. Start Panther Service Software.
  33. Initialize the Distributor and AMP Incubator.
  34. Click on the Distributor tab.
  35. Click on Parameter.
  36. Set the Authorization Code to “1”.
  37. Re-Teach the Linear Distributor to the AMP incubator.
    1. Click on Teach.
    2. Select “Sledge” from the Select Drive drop-down.
    3. Select “AMP Incubator” from the Select Position drop-down.
    4. Click once (to highlight) the Execute Position Autoteach option in the Options for selected Drive and Device menu.
    5. Click on the Execute button.
    6. Click on the Yes button after process is complete, to save parameters to NVM.

  38. Click on the Incubator tab.
  39. Select the Main tab.
  40. Click on the Sensor tab.
  41. Select Amp Incubator ID 0x22 in the Select Device section.
  42. Click on the Read button.
    Note—Incubator temperature reaches nominal range within 20 minutes (42.4 – 43.0 °C).

    Step 43 is only for RTF installation on a NEW incubator.
    Slot Alignment is NOT necessary if upgrading an existing incubator.
    If upgrading an existing incubator, skip Step 43 and proceed to Step 44.

  43. Complete the Incubator Slot Alignment procedure.
    Note—This needs to be done before the distributor is taught to the incubator.
  44. Complete a one cycle System Level Operational Qualification (OQ) procedure for the AMP incubator only.
  45. Close Panther Service Software.
  46. Run the Panther RTF Aligner Program.
  47. The RTF software configuration is complete.

Verification

  1. Open the PANTHER Main Software and verify that the instrument starts with no errors.
  2. Click on the Help button.
  3. Click on the About button.
  4. Check the Module Information option.
  5. Verify there are three RTF modules listed as Rtf1, Rtf3, and Rtf5.
    1. Rtf2 will be listed if 677 RTF is installed (Required for BV, CV/TV Assay).
    Note—These modules should have the firmware version shown in the box below.

  6. Perform a real-time assay Performance Qualification (PQ).
