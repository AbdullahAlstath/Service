Incubator Parameter Verification Procedure

Purpose

This is an advisory notice to inform FSEs about an inconsistency in the parameter settings on some Incubators.

What is Affected

We have found an inconsistency in the parameter settings of some Incubator modules. These parameters affect the incubator carousel movement to position an MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station.. An incorrect parameter can cause an error (such as “carousel motor suffered step loss or stalled”) on ‘Start-up’, ‘Exiting Power Save’, or ‘Assay Procedures required to prepare and perform a specific test. In the context of this document, assay refers exclusively to a Hologic test, such as Aptima Combo or Ultrio. Processing’.

Three parameters need to be verified on each Incubator.

The Table below lists the correct values for each parameter.

Correct Parameter Settings

Parameter High Temp (INC1) Transition (INC2) Amp (INC3)
107 - Ramp Current 100 100 70
108 - Move Current 70 70 50
118 - Maximum Retires 3 3 3

Time Required

  • 30 Minutes

Procedure

  1. Put on proper PPE.
  1. Power on the Panther System.
  2. Start the Service Software.
  3. Click on the Incubator tab.
  4. Select the Main page.
  5. Initialize all 3 incubators.

  6. Click on Parameter.
  7. Check each parameter value listed in the Table above:
    1. Select the desired incubator in the Device drop-down.
    2. Type the Parameter number (107, 108, or 118) into the Parameter field.
    3. Click Read.
    4. Compare the value displayed in the Contents field to the value in the Table above.
    5. Repeat the steps above for each incubator.

    Note—If any value is incorrect and needs to be changed, proceed to Step 9.
    Note—If all values are correct, no changes need to be made. Exit the Service Software and exit the FSE Shield. Document in Oracle that this procedure has been performed.
  8. To change an incorrect Parameter:
    1. Display the Trace View Window.
      Note—The Trace View Window may be hidden behind the main Service Software window. If not open, click on the Show Trace View button on the Main & Com. tab.)
    2. Ensure the COM3 is selected in the communication port drop-down menu.

    3. Use the commands listed below for each incubator to correct any parameters that were found to be incorrect in Step 8.
      1. Enter the string (low-level command) to unlock NVM and click Send.
      2. Enter the string to change the desired parameter (107, 108, and 118) to the correct value and press Send.
      3. For each command sent, verify the expect return string is displayed.
      4. Enter the string to Save NVM and press Send.
