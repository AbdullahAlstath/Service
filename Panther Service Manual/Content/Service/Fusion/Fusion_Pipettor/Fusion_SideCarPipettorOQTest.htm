Sidecar Pipettor OQ Test

The pipettor picks a cap and vial from the cap and vial drawer and places the consumable through the centrifuge.
From there the cap and vial arm takes the consumable to the Thermocycler.
This process is repeated for the specified cap and vials in the drawer.

This procedure can be performed during Fusion Cap and Vial Drawer install, Pipettor installs, Thermocycler Bank or Thermocylcer module installs.

Procedure

For Service Software v4.0.7.0 with System SW v6.2.5.1

  1. If the DiTi pre-pierce option is enabled, it also pierces all 12 well of a cartridge where a FSE can visually verify that the well are properly pre-pierced.
  2. From the 15. SC-System tab, select OQ-Test.
  3. In the Side Car Pipettor OQ Test section, select the Report and Initialize check boxes

  4. Select the Cap & Vial or DiTi check box.
    Note—You can run both tests at the same time if desired.
  5. For Cap & Vial enter 56 Cycles; for DiTi enter 96 Cycles.
  6. Load one full Cap & Vial tray and one full DiTi tray.
    Select the rack locations where the trays have been loaded under Cycles. (Front left, Back right, etc.)
  7. Select Side Car Pipettor OQ Test to begin the OQ.
  8. Fill in all relevant information in the report submission screen before starting the OQ.
  9. Save the report when complete.

For Service Software v5.0.12.0 and above with System SW v7.1 and above

  1. From the F-SC-System tab, select Side Car Pipettor OQ-Test.

  2. The following notes outline the updates from the previous version of Service Software
    1. DiTi OQ removed.

      2. Note: Do not select Prepierce PCR or an error will generate.

    2. Shutter option no longer available. Shutter movement will now always be utilized in OQ.
    3. Cap and Vial options now are as follows:
      1. Full:
        Uses all 56 consumables from each of the four trays for a total of 224 consumables.
      2. Perimeter:
        Uses the perimeter 26 consumables from each of the four trays for a total of 104 consumables.
        This takes much less time than the 224 consumables used in the full OQ.
        This is useful for qualifying cap and vial drawer R&R/Teaching or instrument install and reducing time in half.
      3. One Tray:
        Uses all 56 consumables from one tray.
        This is useful for qualifying Thermocycler R&R.
      4. Single Bank:
        Uses the first 5 consumables from one tray.
        This is useful for qualifying a single Thermocycler bank R&R.
Note—
Replace USED trays.
SSW consumable usage is not tracked by the Panther Database.
