Thermocycler Manual Cleaning Procedure

Implementation

Perform this procedure when a well or wells of the Thermocycler module are suspected to be dirty. Panther Main can display the following startup messages that may indicate a dirty well:

Parts and Materials Required

  • Proper PPE
  • Panther Tool Kit
  • TC Manual Cleaning Kit
    • Case, Black Plastic
    • Cleaner, Precision Optical
    • Wipes, Lint-Free
    • Swabs, Polyurethane Foam
    • USB Microscope, 2MP, 8LED, 5 - 30 mm
    • USB Microscope Software

Procedure

If you are using the USB Scope for the first time, refer to the setup and operation instructions.

  1. Use the scope to inspect the Thermocycler well indicated in the Panther Main startup message (or suspected to be dirty).

  2. Clean the dirty Thermocycler well using a foam swab.
    1. Place a bag of foam swabs and the optical cleaner (spray can) on an absorbent bench pad.
    2. Hold the optical cleaner over the pad and wet the end of the swab.
    3. In a circular motion, gently clean the inside of the dirty well.
    4. Inspect the well using the scope, and clean again if necessary. (Change swabs before cleaning a second well.)

  3. Restart Panther Main to see if the message has cleared. If the same "Thermocycler Thermal block background RFU too high" message is displayed, continue to step 4.
  4. Shutdown the Panther System and PC.
  5. Remove the Thermocycler from the system.
  6. Remove the 6 hex screws that secure the metal cover to the Thermocycler with a 3mm hex key.
  7. Set the cover aside.
  8. Remove the bank with the dirty well. (Bank 12 is being removed in the example below)
    1. Remove the 2 hex screws that secure the Thermocycler bank with a 2mm hex key.
    2. Gently but firmly lift the bank up and out of the Thermocycler. (The PCB is inserted in a slot above the row of banks but will slide out with minimal pressure.)
  9. Use a Lint Free Wipe to gently clean the end of each plastic optical fiber.

  10. Re-insert the bank and metal cover.
  11. Reinstall the Thermocycler in the system.

Verification

  1. Complete a BackGround Scan and Peek Lid Thermocycler Scan.
    (Part A and Part B - Thermocycler Scanning and Automatic Cleaning Instructions)
    1. If a well still does not pass, complete Deep Cleaning.
    2. If a well still does not pass after Deep Cleaning, replace the Thermocycler.
  2. Start Panther Main and verify the Panther Main start up message clears.
    IMPORTANT—If the "background RFU too high (or low)" message does not clear after cleaning, replace the Thermocycler.

USB Scope Setup and Operation

Setup

To use the USB scope, you need to run a USB webcam/digital camera. There are two options:

Use a freeware application:

There are a number of options available in the internet, but the following program has been tested and recommended.

  • Go to this website - http://www.oasisscientific.com/downloads.html - and download the oasis.exe file.

Use the software provided with the Opti-Tek Scope:

  • Copy the application from the Instructions and Software CD to your desktop. If your computer does not have a CD-ROM drive, copy the file to a USB drive. (Use any available computer or workstation that does have a CD-ROM.)
  • If internet access is available, go to the Opti-TekScope website software download page, and run the ehe_v2.exe application. (You can download the file if you have administrative rights on your computer.)
  • http://opti-tekscope.com/software-download/

Operation

  1. Plug the scope into a USB port.
  2. Open the application.
  3. Hold the scope vertically over a well, with the scope gently resting on top of the well.
  4. To control the brightness of the LED, rotate the dial on the USB cable.
  5. To focus, rotate the ring on the end of the scope.

  6. To take and store photos:
    1. Select File > Set Photo Folder to choose a destination folder.
    2. Select Snap > Capture or press Enter to capture an image.
Note—Refer to the help or troubleshooting content available online or on the CD if you have any issues suing the software.
