Distributor to OQ MTU Handoff Position Adjustment

Parts and Materials Required

  • Proper PPE
  • Panther Service Software

Time Required

  • 1.5 hours for Service Procedure and Verification

Procedure

  1. Ensure that the Service Drawer is fully closed and latched.
  2. Check to be sure the Output Queue MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Presence Sensor is functioning correctly:
    1. Visually confirm that no MTU is present at the Output Queue load position.
    1. In Service Software, navigate to 2. Front and Loading Units, Output. In the Sensors section, select Read and check the MTU Sen field. Confirm that the MTU Sen field reads Absence.

    1. If the MTU Sen field reads Presence, clean the sensor before moving to the next step.
  3. In Service Software, initialize the Distributor and Output Queue.
  4. Prepare for manual teaching of the Distributor by setting the Distributor Authorization Code:

    1. In Service Software, navigate to the 1. Distributor tab.
    2. Navigate to the Parameter tab.
    3. Ensure that Distributor Z Theta ID 0x10 is selected in the Device drop-down menu.
    4. In the Authorization section, enter 1 in the Code box.
    5. Select Set.
  5. Retrieve the currently saved Distributor–Output Queue teach parameters:

    1. In Service Software, navigate to the 1. Distributor tab.
    2. Select the Teach tab.
    3. In the Select Drive section, select Sledge.
    4. In the Select Position section, select Output Queue.
    5. In the Move Axis to Position/Get Stored Teach Position section, select the Get All button.
    6. Note the stored Back/Forward (hook depth) teach position (1447 in this example).
  6. Manually adjust the Distributor teaching:

    1. Calculate the new hook teach position—Subtract 20 from the value found in step 5f (in this example: 1447 – 20 = 1427).
    2. Move the Distributor to the Output Queue by double-clicking Move Theta & Z & X to selected Position (!! fast move !!). This moves all axes except the Hook to the Output Queue.
    3. In the Move Axis to Position/Get Stored Teach Position section, enter the value from step 6a in the box next to Back/Forw., and select Move. This moves the Hook to the new position.
    4. In the Select Position section, select Output Queue.
    5. In the Move Axis to Position/Get Stored Teach Position section, select the Get All button.
    6. Note the stored Back/Forward (hook depth) teach position (1447 in this example).
  7. Note that the current hook position is now 20 steps less (1427 in this example). In the Save Current Axis Position/Get Current Pos. section, select the Save button next to Back/Forw. to save the current position to the Volatile Memory.

  8. Save the new teach position to the Non-Volatile Memory by double-clicking Overwrite NVM in the Options for selected Device and Drive section. This permanently saves the new Distributor teach parameters.

  9. Verify that the Output Queue is able to detect MTUs with more than 4 mL of fluid:
    1. Confirm that the Output queue Sensor reads Absence when no MTU is present:

    1. In Service Software, navigate to 2. Front and Loading Units, Output.
    2. In the Sensors section, select the Read button to check the Output Queue MTU presence sensor. If the sensor reads Present when no MTU is present, clean the sensor.
    1. Fill all tubes of an MTU with saline or DI water above the MTU guides/shoulders (at least 4 mL—this will be above the Output Queue MTU presence sensor), and place the MTU in the Service Queue.

    1. Using the Distributor, retrieve the MTU from the Service Queue and place the MTU at the Output Queue.
    2. In Service Software, navigate to 2. Front and Loading Units, Output. In the Sensors section, select the Read button to check the output Queue MTU presence sensor.

    1. The sensor should ready Presence. If the sensor reads Absence, the Distributor placement position of the MTU on the OQ needs to be further adjusted—repeat steps 5–9, but add 20 steps to the Distributor teach position (in step 5f) instead of subtracting 20 steps.
  10. Once the final Distributor hook teaching is completed, perform the following steps to make sure the Output Queue MTU Loader is able to grab the MTU from Tube 2 and load it to the rails without issues:
    1. Confirm that the MTU placed on the Output Queue in step 9 has been removed.
    2. Using the Distributor, place an empty MTU on the Output Queue.
    3. In Service Software, navigate to 2. Front and Loading Units, Output tab. Select the Prime Operation of pumping fluid through tubing to ensure proper and consistent fluid delivery (remove air from the tubing, etc.). & Disp. MTU button. This causes the Output Queue to grab the MTU and move it to the stack.

    1. As the Output Queue Load Hook grabs the MTU, confirm that the Hook fully snaps into place when it grabs the MTU. If the Hook does not fully snap in, or grabs the wrong tube (expected to grab tube #2), then the Distributor Hook teaching needs to be readjusted.
    2. Instead of changing the value by 20 steps as instructed in step 6, only change the teaching by 10 steps, and repeat steps 7–10.

Verification

  1. Cycle at least 25 MTUs through the Output Queue:

    1. Open Service Software.

    2. Initialize the Output Queue, Linear Distributor and Input Queue.

    3. On the 2. Front and Loading Units tab, select Output and then Empty Stack to ensure that the OQ stack is empty.

  2. In the System tab, perform a System OQ Test.

    1. Select 25 cycles.

    2. Deselect Initialize (all modules that will be used are already initialized).

    3. Deselect All Modules, and select Magnetic Parking.

    4. Select Report.

    5. Select System OQ Test.

    6. Completely fill the Input Queue with 25 MTUs when prompted.
  3. As the Distributor places MTUs on the Output Queue, observe the Output Queue, and confirm that the Output Queue Load Hook fully snaps into place each time it grabs an MTU. If the Hook does not fully snap in, or grabs the wrong tube (expected to grab tube #2), then the Distributor Hook teaching needs to be readjusted- see step 10e.
  4. Ensure that the Output Queue and system function properly during this unload process.

    1. Select the Tasks button from the top ribbon and select Perform Maintenance.

    2. Select the Force Full Prime button.

  5. Perform 2 Full Primes on the system using Panther System software:
