Distributor Alignment and Teaching Procedure

Parts and Materials Required

  • Allen wrench, 4 mm
  • Sharpie pen
  • 30 cm ruler

Time Required

  • 45 minutes

With the Input Queue Auto Teach Tool

Without the Input Queue Auto Teach Tool

Setting Up for Alignment

  1. Carefully open the Service Drawer.
    Note—Before opening the Service Drawer, carefully remove the luminometer injectors.
  2. Start up Service Software.
  3. Select the 1. Distributor tab.
  4. Select the Main tab.
  5. Select Distributor from the drop-down menu.
  6. Click Initialize.

Setting the Authorization Code 

  1. Navigate to the Distributor Parameter tab.
  2. Enter 1 in the Code field and select Set.

  3. This will allow manual teaching of the Distributor to the Input Queue.

Distributor Alignment to the MTU Input Queue

  Note—The Distributor has the following teachable parameters: Theta, X, Z, and extended hook positions.

  Note—The Distributor needs to be taught to the Input Queue first, before it is taught to any other module.
  1. In Service Software, navigate to the Distributor Teach tab.
  2. Select Input Queue from the Select Position list and double-click Move Theta & Z & X to Selected Position (!! fast move !!).
    (Or single-click "Move Theta & Z & X..." and click Execute.)

    The Distributor moves to the MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Input Queue position.

Note: Determine the appropriate Service Software version and follow the appropriate procedure below.

Theta Position Teaching for Service Software v2.4.7.0 and below

  1. On the Teach tab, under Select Drive, select Theta to display Theta teaching Options.
  2. Use a ruler and the Luminometer module as a reference to align the Distributor in the Theta direction. 
    1. Measure the distance between the Luminometer and the back end of the Distributor.
    2. Move the ruler to the front end of the Distributor and measure the distance.
    3. Use the Theta arrows on the Teach tab to move the Distributor until the Distributor is positioned parallel (same distance to front and back) to the Luminometer.

  3. Once the Distributor is parallel to the Luminometer, press Save (under Save Current Axis Position) to save the Theta position.
  4. Permanently write the new Theta values to the non volatile memory (NVM) by selecting the Overwrite NVM option and Execute.
    Note—Any values that are saved, but not written to the NVM will be erased on the next power cycle of the system.

  5. Next, you MUST calculate Theta for all other modules.
  6. Calculate Theta for all other modules by selecting Calculate and set other Positions then Execute.

  7. In the dialog window "Are you sure you want to overwrite all stored theta positions?", click Yes.
  8. In the dialog window "Do you want to save current Position as Home Position?", click Yes.
  9. Select Overwrite NVM and then Execute to save these calculated values.

Theta Position Teaching for Service Software v4.0.7.0 and above
The Calculate and Set other positions button has been removed in SSW v4.0.7.0.

  1. On the Teach tab, under Select Drive, select Theta to display Theta teaching options.
  2. Use a ruler and the Luminometer module as a reference to align the Distributor in the Theta direction. 
    1. Measure the distance between the Luminometer and the back end of the Distributor.
    2. Move the ruler to the front end of the Distributor and measure the distance.
    3. Use the Theta arrows on the Teach tab to move the Distributor until the Distributor is positioned parallel (same distance to front and back) to the Luminometer.

  3. Once the Distributor is parallel to the Luminometer, select Get All (under Get Current Pos.).
  4. Select Save All (under Save Current Axis Position) to save the Theta position (this will calculate Theta for all other modules).
  5. Permanently write the new Theta values to the non-volatile memory (NVM) by selecting Overwrite NVM then Execute.Continue to Steps 6-8 to calculate Theta for all other modules.
    Note—Any values that are saved, but not written to the NVM will be erased on the next power cycle of the system.

  6. Next, you MUST calculate Theta for all other modules.
  7. Select Theta under Select Drive,
  8. Then click “Get All” under “Save Current Axis Position/Get Current Pos.”,
  9. Then click “Save All”.
  10. When complete, select Overwrite NVM and then Execute

Hook-Extended Position Teaching

Note—If teaching Panther Plus, you must install a carrier in the MTU Queue before selecting Push MTU.
  1. Mark a straight line across an MTU tab, 7 mm from the bottom of the tab.
    Also mark the edges of the tab as shown in the picture. This will make it easier to align the hook to the MTU    .

  2. Click the Main tab.
  3. From the drop-down menu, select the + next to Front and Loading Units.
  4. Select MTU Input Queue.
  5. Select the Initialize button.
  6. In Service Software, select 1. Distributor > Move > Unlock Drawer to unlock the MTU Input Queue drawer.
  7. Remove all MTUs from the MTU Input Queue.
  8. Load the marked MTU first and an additional four or more MTUs behind it into the MTU Input Queue and close the drawer.

  9. Select Push MTU on the Distributor Move screen.
  10. With the Distributor still at the MTU Input Queue position:
    1. On the Teach tab, under Select Drive select Sledge.
    2. Under Select Position, select Input Queue.
    3. Under Options for Selected Device and Drive, double-click Move Hook to selected position (or single-click and select Execute.)

  11. Observe the hook extension and confirm that the hook does not push against the MTU and move the MTU out of position. If this occurs, teach the hook farther in (to the head of the distributor), reposition the MTU, and reconfirm the teaching, as detailed in the following step.
  12. Once the hook is at its extended position, use small steps to move the hook either out or in, until the hook just touches the MTU tab. (Move the hook using the indicated arrows under Incremental Positioning.) The step size can be adjusted by changing the Move Step value.

  13. Select Save to save the new hook extended position. To make the change permanent, double-click Overwrite NVM.

MTU Input Queue Adjustment in the Y-Axis

  1. Retract the hook into the Distributor head by selecting Distributor > Teach > Sledge, and double-clicking Move Theta & Z & X to Selected Position (!!fast move!!).
  2. Loosen the three screws that secure the MTU Input Queue to the Service Drawer.

    The first screw is located adjacent to the front left side of the MTU Input Queue.

    The second screw is located at the back left side of the MTU Input Queue, near the front of the Luminometer.

    Caution—When accessing the screw that is closest to the Luminometer, be very careful not to let the Allen wrench contact the PCB board, this can short out the board and damage it.
  3. Push down on the red button located on the MTU Input Queue to unlock the MTU drawer.
  4. Pull the drawer out and loosen the third screw.

  5. Close the MTU Input Queue drawer, and confirm that the Input Queue is packed with the marked MTU.
  6. Select Move Theta & Z & X to selected Position (!!fast move!!).
  7. Select Move Hook to selected Position.
  8. Gently slide the MTU Input Queue in the Y-axis until the marked MTU tab is centered in reference to the Distributor hook.

  9. Once the MTU Input Queue is aligned in the Y-axis, tighten the two accessible screws, making sure not to misalign the module in the process. The third screw will be tightened after the Z-Position teaching is complete.

Z-Position Teaching

  1. Once the MTU Input Queue is aligned in the Y-axis and with the hook still in the extended position, use the Up/Down arrows to move the Distributor in the Z-axis until the hook sits right below the MTU tab 7 mm mark. The step size can be adjusted by changing the Move Step Value.

  2. Confirm the hook extend position is still valid.
  3. Select Save All to save the new Distributor Z-axis position. To make the change permanent, select Overwrite NVM.
  4. Select Move Theta & Z & X to selected position (!!fast move!!) to retract the hook.
  5. Open the MTU Input Queue drawer and tighten the third MTU Input Queue screw.

Execute Full Autoteach

This procedure describes how to autoteach all modules, except the Input Queue and Service Queue.

  Note—Always clean teach pins, the hook, and grounding tab with alcohol before performing any autoteach procedure.
  1. Ensure the Input Queue has been properly aligned.
  2. Close the Service Drawer.
  3. Reinstall the Luminometer Injector.
  4. Double-click Execute Full Autoteach without InputQueue (or single-click and Execute).

  5. When the Execute Full Autoteach sequence completes, a Save Parameters to NVM? dialog appears. Select Yes.
     Note—If teaching issues persist, it is recommended to perform an Execute Full Autoteach twice, to ensure the most accurate teach parameters are saved. One autoteach sequence may not ensure the hook gets close enough to the teach pin.
  6. Continue to Alignment to the MTU Scanner.

Execute Position Autoteach

This procedure describes how to autoteach one individual module.

  Note—It is recommended to always clean teach pins, the hook, and grounding tab with alcohol before performing any autoteach procedure.
  Note—The Magnetic Wash Stations, Output Queue, and Service Queue can only be taught with the Service Drawer closed.
  1. Re-initialize the Distributor. (Always re-initialize before individually teaching a module. This prevents potential X-Axis positioning drifts that can occur between modules.)
  2. Ensure the Input Queue has been properly aligned.
  3. Close the Service Drawer (if necessary).
  4. From the Select Position List, select the module to autoteach.
  5. Double-click Execute Position Autoteach (or single-click and Execute).

  6. When the Execute Position Autoteach sequence completes, a Save Parameters to NVM? dialog appears. Select Yes.
    Note—If teaching issues persist, it is recommended to perform an Execute Full Autoteach twice, to ensure the most accurate teach parameters are saved. One autoteach sequence may not ensure the hook gets close enough to the teach pin.

Distributor Manual Teaching to Any Module

Distributor Alignment to the MTU Scanner

  1. Continue to Distributor Alignment to the Service Queue.

Distributor Alignment to the Service Queue

  1. The Distributor is manually taught to the service queue.

  2. Place a marked MTU (as described in the Input Queue teaching section) in the Service Queue, with the clip between tubes 2 and 3.

  3. On the Teach tab, select Service Queue in the Select Position box. Then double-click Move Theta & Z & X to selected Position (!!fast move!!) to move the Distributor to the Service Queue.
  4. Move the Distributor in the X-Direction so that the head is approximately 1 cm from the MTU.

  5. Select Save to save the new X-Axis position. To make the change permanent, double-click Overwrite NVM and click OK.
  6. With the Distributor still at the MTU Service Queue position, select Distributor > Teach > Sledge > double-click Move Hook to selected Position.
  7. Observe the hook extension and confirm that the hook does not push against the MTU and move the MTU out of position. If this occurs, teach the hook farther in (to the head of the distributor), reposition the MTU, and reconfirm the teaching, as detailed in the following step.
  8. Once the hook is at its extended position, use small steps to move the hook either out or in, until the hook just barely touches the MTU tab.
  9. Select Save to save the new hook extended position. To make the change permanent, double-click Overwrite NVM and click OK.
  10. Align the hook with the Up and Down buttons until the hook sits right below the MTU tab 7 mm mark. Select Save to save the new Up/Down position. To make the change permanent, double-click Overwrite NVM and click OK.
  11. Loosen the mounting screws on the MTU service queue to align the Service Queue to the Distributor hook in the Y-direction.
  12. Center the MTU to the Distributor hook, then tighten the mounting screws.
  13. Tighten the Service Queue mounting screws.
  14. If this is an Installation, continue to Filling the Cooling Module.
