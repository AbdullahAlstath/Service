Dashboard Procedures

The Dashboard displays Panther System information on a 4K TV or web client device such as a tablet or a laptop.

Dashboard Install Procedures

Accessing the Lab Automation Dashboard

There are two methods to access the Dashboard webpage.

  1. Inside Port

    1. Set the FSE's Computer in Control Panel to the following IP address:
      Static IP: 10.8.8.9
      Subnet Mask: 255.255.255.0

    2. Connect computer to Inside Port via ethernet cable.
    3. On a supported web browser (on a computer use Chrome, on an iPad us Safari), navigate to https://10.8.8.8.
  2. Outside Port
    1. On the customer's network, open a supported web browser.
    2. Type in the Dashboard IP address in the web address bar of the browser.
      You may need to add "https://" before the IP address.
      The browser doesn't always automatically do this, particularly on first access.

      3. Note: The Dashboard Server IP address is set during Firewall Configuration.

Log into the Lab Automation Dashboard as an Administrator

  1. Open a supported web browser.

  2. Click the login button at the top right corner of the homepage or in the bottom right corner of the menu page.

  3. Login with the following credentials:

    Username: admin
    Password: passw0rd

  4. You will be prompted to change the password. Input a password which meets the default complexity requirement.

Note: Write down the new password that you set.
This account is the customer's alternative Administrator credential, and the password cannot be reset to the default password.

Adjust the Dashboard Server Time

  1. Using the Time Zone/Date and Time procedure found on the Dashboard Administration page, set the proper time zone. The server will reboot.

  2. Using the same procedure, set the proper local time. The server will reboot.

Logging out of Lab Automation Dashboard

  1. Click the Logout button in the top right of the Dashboard homepage.
  2. Click the Logout button in the lower right of the menu pane.

Dashboard Server Application Installation

  1. Log in to the Dashboard Server as an administrator or FSE.
  2. Navigate to the Administration page using the side bar menu.
  3. Perform a backup if not already performed.
  4. Select Upload Application in the Update Application Tile.

Note: The FSE login step is used to verify Dashboard Server timezone and time are set correctly.
FSEs can use any admin level account.
The FSE login option allows any FSE to walk up to another other properly setup Lab Automation Dashboard Server and log in.

Log into the Lab Automation Dashboard as a Field Service Engineer

  1. Open a supported web browser. (On a computer, use Chrome. On an iPad, use Safari)
  2. Click the login button in the top right corner of the homepage or in the bottom right corner of the menu page
  3. Click on the Switch to Service Login in the bottom right corner of the Dashboard Login page.

  4. Using Time-Based One-Time (TOTP) Authentication, enter your username and designated 6-digit password.
    Refer to TB-01603 - Using Time-Based One-Time (TOTP) Authentication.

    Note: The password works on two things:
    1) An algorithm which both Dashboard and the FSEs Authenticator app both know.
    2) The current UTC time.

    If the time does not align (+/- 2 min) between the Dashboard Server and the Authenticator's time, Dashboard will expect a different 6-digit password and not allow an FSE to log in.

    If this is the case, use the following two procedures to adjust the time.

  5. Click the Login button.

Enabling Dashboard on the Panther

  1. Log in to the Panther Main as an Administrator.
  2. Navigate to Tasks > Perform Maintenance.
  3. Click the Service button.
  4. Click the Next button until you find the Panther Link Features button.
  5. Click the Panther Link Features button.
  6. A pop-up window will appear.
  7. Select the Enable LAS Dashboard checkbox.
  8. Click Save.

    9. Note: If the Panther Requires a restart, restart the PC as instructed.

Adding a Panther to Lab Automation Dashboard

  1. Log in to the Panther Main as an Administrator on the Panther.
  2. Ensure the LAS Dashboard feature is Enabled.
  3. Navigate to Admin.
  4. Click the Next button until you find the Manage Remote Data Access.
  5. Click the Manage Remote Data Access button.
  6. Click the Generate button.
  7. A Generate Access pop-up will appear with a text box for Owner.

    8. Note: WRITE THIS OWNER DOWN
    The owner will be inputted when adding the instrument to the Dashboard Server.

  8. Click the OK button.
  9. A pop-up window will appear with a unique, randomly generated access key to populate within the Dashboard Server.
    IMPORTANT—WRITE THIS KEY DOWN OR TAKE A PICTURE of THIS KEY
    This key will not be remembered by the system and will be lost after the window is closed.
  10. Log in to the Dashboard Server as an FSE.
  11. Select the Menu button in the top right of the Dashboard.
  12. Select Administration.
  13. Select the Paw icon for Instruments.
  14. Select Add Instrument on the Instrument Management Page.
  15. A pop-up window labeled Add Instrument will appear.
    1. Add the IP Address of the Panther that you generated the unique key from Step 9.
      This IP address is the address provided in the Instructions.txt file from the Firewall Wizard. It will be the PAT address for Dashboard to communicate with the Panther.
    2. Add the Dashboard Port number generated from the output.
      The Port Number is also provided in the Instructions.txt file from the Firewall Wizard.
    3. Populate the Alias Name with a generic name for the Panther you wish to add (20 character limit).
      1. This can be any name the customer may want to use to name their instrument.
        e.g. Bubbles or 2090002345
    4. Populate the Alias Short Name with a generic name for the Panther you wish to add (5 character limit).
      1. This Alias will be used in the card view layout.
        e.g. Bub or 2345
    5. Populate the Access Owner that you wrote into the Panther during the access key generation procedure.
    6. Populate the Generated Access Key with the key generated from the Panther during the access key generation procedure.
    7. Click the Add button.

Edit the Network Configuration of the Dashboard Server

The Dashboard server will sit within a DMZ on the Hologic Network.
The IP address, Subnet Mask, Default Gateway, and DNS servers can be found in the Instructions.txt file provided by the Firewall Wizard.

  1. Select the Plug icon for Network.
  2. Enter a Hostname chosen by the FSE.

    3. Note: We suggest using an acronym of the Customer Site Name.

    E.g. Customer Site Name: Rancho Human Society, Host Name: RHS

  3. Select the Use the Following IP Address radio button.
  4. Populate the IP Address provided from the instructions.txt file from the Firewall Wizard.
    Note—This IP Address is the internal IP Address for the Hologic Network DMZ. Generally, the IP Address will start with 172.15.1.100.
  5. Populate the Subnet Mask provided from the instructions.txt file from the Firewall Wizard.
    Note—This Subnet Mask Address is the internal Subnet Address for the Hologic Network DMZ. Generally, the Subnet will be 255.255.255.0.
  6. Populate the Default Gateway provided from the instructions.txt from the Firewall Wizard.

    Note—This Default Gateway is the internal gateway for the Hologic Network DMS. Generally, the default Gateway will be 172.15.1.1.

  7. Populate the DNS Server addresses from the Site Assessment Form.
    1. If specific DNS addresses are provided, select the use the following DNS server addresses button and input the addresses below.
    2. If the Dashboard is to obtain its own DNS servers automatically, select the Obtain DNS server address automatically.
  8. Click the Save button when the configuration is complete.

Creating a New Work Cell

  1. Select the Work Cell tab.
  2. Click Add Work Cell.
  3. A popup window will appear.
  4. Populate the name of the Work Cell you wish to create.
  5. Click the Add button.
  6. You will see the newly created Work Cell appear in the list below.

Editing a Previously Created Work Cell

  1. Select the Work Cell tab.
  2. Select the Pencil icon next to the Work Cell you wish to edit.
  3. Edit the name of the Work Cell in the popup window.
  4. Select Save.

Adding a Panther Into a Work Cell

  1. After the Panther has been linked to the Dashboard and a Work Cell has been created, Navigate to the Instrument > Instrument List page.
  2. Select the Pencil icon next to the Panther you wish to add to the Work Cell.
  3. Select the Work Cell drop-down menu and select the Work in which you wish to add the Panther to.
  4. Click the Save button.

Creating a Dashboard Work Cell View

  1. From the Home Page, click on the Pencil icon next to the Work Cell you would like to configure from the Dashboard Home page.
  2. Select the Check boxes of Panthers you would like to have on the selected Work Cell.
  3. Click the Apply button.
  4. Click the Save button.

System—Backup

  1. Login to the Dashboard as an FSE.
  2. From the Panther Dashboard >> Administration, select the Multiple Gears icon or System tab.
  3. Select the Request Backup button within the Backup Tile.
    1. A notification will appear demonstrating the backup was requested successfully in the upper right corner.
    2. The Backup Tile will indicate that a backup is being generated with a circling progress icon.
  4. The web browser will display that the Backup is completed when finished.
  5. Save the backup file to a USB flash drive.

System—Restore

  1. Log in to the Dashboard as an FSE.
  2. Select the Multiple Gears icon or the System tab.
  3. Select the Restore Backup button within the Backup Tile.
