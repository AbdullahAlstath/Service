Creating a Panther Image on a USB 

Parts and Materials Required

  • Panther System Image as per System Software Installation Technical Bulletin
  • Rufus USB Creation Software
  • Kanguru Lockable USB Drive

Time Required

  • 20 Minutes

Procedure

Create a Panther Image on USB Drive

Note— Screen shots below are for reference ONLY.
Note— When removing a USB Drive always remember to use the Safely Remove button.
Note— The FSE Laptop user MUST have Administrator privileges.
  1. Perform the following steps on an FSE laptop.
  2. Download (from Agile or BOX) a local copy of the Panther System Image as listed in the respective System Software Installation Technical Bulletin.
  3. Perform a SHA256 CRC on the downloaded file.
    1. Right click on the .iso file.
    2. Click on CRC SHA.
    3. Click on SHA-256.

    4. This will start the SHA-256 Checksum process.

    5. Verify the SHA256 matches the value listed in the applicable System Software Installation Technical Bulletin.
      Note—Screenshot below is for reference only.
  4. Set the Kanguru SS3 USB Flash Drive lock to the UNLOCKED position.

  5. Insert a blank Kanguru SS3 USB Flash drive into the FSE Laptop.
  6. Launch Rufus.
    Note—DO NOT update Rufus. Use version 3.5.1497.

  7. Clear USB Partitions (if any)
    1. For Device, select the desired USB to write to. Select the visible partition on the USB drive.
    2. For Boot selection, select Non bootable.
    3. For File system, select NTFS.
      4. Note—The Rufus configuration will look like the image below.
  8. Select START.
    1. Accept the warning message.
  9. Select Close.
  10. Launch Rufus.
    Note—DO NOT update Rufus. Use version 3.5.1497.

  11. From the Device drop-down menu, select the desired USB to write to.
    Rufus will auto-select removable drives.
  12. For Boot selection, select Disk or ISO image (Please select).
  13. Use the SELECT button to locate the .iso.

  14. Navigate to and select the local copy of the Panther Image .iso.
    Note—Image below is for reference only.

  15. Rufus will automatically select the partition scheme and target system.
    Note—Do not change these settings.
  16. Change the Volume label to PantherImage6_X_X.iso.
  17. Verify the File System is NTFS.
  18. The Rufus configuration should look like the image below.

  19. Select START.
    1. Accept the warning message.

  20. Rufus will begin writing the Image to the USB drive.
    A Status bar will indicate progress. Image writing can take up to 10 min.

  21. Once finished, accept the completion message and select Close to close Rufus.

  22. On the FSE Laptop, open Windows Explorer and navigate to This PC.
  23. Verify that two partitions were created on the USB Flash drive.
    You might have to remove the USB and re insert the USB to confirm all partitions.
    1. UEFI_NTFS
    2. PantherImageX_0_X
    Note—If you are using a Windows 7 Laptop, you will only see one partition.

  24. Open the PantherImageX_0_X and delete the two autorun files.

  25. Safely remove the USB drive.
  26. Move the drive's lock to the locked position.

  27. Cover the lock with a Do Not Tamper With sticker.
