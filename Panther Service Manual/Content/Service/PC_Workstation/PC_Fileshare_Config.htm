Network Fileshare Configuration Procedure
(For GRIFOLS USE ONLY)

Parts and Materials Required

  • N/A

Time Required

  • 1 Hour

Procedure

  1. Boot the Panther PC.
  2. Hit F10 at the Panther Shield.
  3. Log in as gpservice user.
  4. Run Windows Explorer.
  5. Select Computer.
  6. Click on Map Network Drive.

  7. Select a drive letter.
    Note—It is recommended to pick a letter above "I" as USB drives use letters below "I" and can possibly cause an issue. Recommendation: "N" for NatManager.
  8. Obtain the "IP Address" and "Share Folder Name" from the client. Type in the folder location as "\\IPaddress\ShareFolderName".

  9. Check "Reconnect at logon" and click on "Connect using a different user name."

  10. Type in the "User name" and "Password" supplied by the client that will be allowed on the share.
  11. Click OK.
  12. Click Finish.
  13. Launch the Panther Software via the Admin logon.
  14. Navigate to the Nat Manager screen. Tasks > Perform Maintenance > Service > More > Nat Configuration

  15. At the Nat Configuration screen enter the mapped network drive created in Step 7.

  16. Options for configuring the Nat Manager are listed below.

Verification

  1. Log in to the FSE Shield.
  2. Run Windows Explorer.
  3. Navigate to the drive created in Step 7 of the procedure.
  4. Right click on an open area in the Explorer window, and choose New > Text Document.
  5. Name the file test.txt.
  6. Ask the customer to check the network drive to ensure the file can be opened and viewed.

Appendix

Client Server Configuration Instructions

  1. Run Windows Explorer.
  2. Create a folder where the NAT Manager files are expected to be exported to.
  3. Right click on the folder and select Properties.
  4. Click the "Sharing" tab.

  5. Select Advance Sharing...

  6. Select permissions and either allow full control to everyone, or select Add...

    Note—Choose a user on the NatManager PC with a password that won't expire or type in the Panther-PC#\Panther as the user.
    Note—Panther-PC# is the computer name. The updating of the "Computer Name" is part of the overall Panther Installation Procedures.

  7. Obtain the static IP address (from the IS contact or via the IP config of the PC) and share name (created in Step 5) of the folder to be mapped.

Appendix

How to check the "Computer Name"

  1. Run Windows Explorer.
  2. Right click on My Computer.
  3. Select Properties.
  4. The computer name is located below "Computer name, domain, and workshop setting".
