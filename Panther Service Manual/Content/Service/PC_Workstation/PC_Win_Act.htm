Windows Vista Activation on the Panther System PC

Parts and Materials Required

  • Panther System PC
  • Windows Activation Key

Time Required

  • 5 minutes

Procedure

  1. Power on the Panther System.
  2. In the Windows Activation screen, select Activate Now.

  3. Select Type a different product key.

  4. Locate the Product Key sticker on the PC.

  5. Ensure that Num Lock is turned OFF.
  6. Enter the Product Key # from the PC sticker into the Product Key box.

  7. Select Next.
  8. Select Show me other ways to activate.

  9. Select Use the automated phone system option.

  10. Select the country in which the Panther System is located from the drop-down list and select Next.

    An Activate Windows screen appears.

  11. Call the telephone number listed for the selected country and follow the voice prompts:
    1. Press #2 for Business Customer, or request a text message activation link.
    2. Using your phone, key in the series of nine six-digit number groupings listed on the screen.
    3. The Windows Activation system will provide you with nine new six-digit number groupings. Enter these number groupings in the boxes labeled A through H.
  12. The system allows you to select an option to have these new numbers sent directly to your cell phone as a text message, as well (optional).
  13. Select Next.

    If all numbers were entered correctly, an Activation was Successful screen appears.

  14. If the activation was successful, select Close. If the activation was not successful, restart from step 1.
