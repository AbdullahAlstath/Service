Database Backup and Restore

Parts and Materials Required

  • Formatted USB Drive

Time Required

  • 15 minutes

Procedure

Backup Database

  1. Log in to the Panther FSE Shield.
  2. Click the Backup button.

  3. Insert a USB flash drive.
  4. Select the Browse button (The Magnifying Glass).

  1. Browse to “Removable Disk (E\:)”.
  2. Select OK.

  1. Select the Backup Dashboard data checkbox.
  2. Select Execute.

  1. Select OK when database backup has completed.

  1. In Windows Explorer, browse to the USB flash drive and verify the .bak file was created.

Restore Database

  Note—Only Administrators should perform this task.
  1. Login to the Panther FSE Shield.
  2. Click the Restore button.

  1. Enter the Username (admin) and Password (pantherx).
  2. Click OK.
  Note—The system does not require a User Name and Password if the database was corrupted.

  1. The Restore PANTHER Database screen opens.
  1. Insert the USB flash drive.
  2. Select the Browse button.

  1. Select the backup database file from “Removable Disk (E\:)". Select OK.

  1. Check the Restore dashboard data check box, and select Execute.

  1. If the Restore process is successful, skip to Step 13. If the Restore process is unsuccessful proceed to Step 11
  2. If the Restore process is unsuccessful, copy the Database backup from the USB drive to C:\Panther\Software\PC\Bin\DBBackup
  3. Then return to Step 7 and attempt a Restore from C:\Panther\Software\PC\Bin\DBBackup
  4. Click OK in the Confirm Restore window.

  1. When complete, click OK to return to the FSE Shield.
  2. After restoration the FSE should reconcile all consumable inventories, empty waste, and throw away any used reagents kits.
