Health Reports

Scope

The Panther Dashboard software contains new functionality for generating Health Reports for the Panther System. The three Health Reports that are part of the Panther Dashboard software are:

  • The One-Day Health Report
  • The Panther (System) Health Report
  • The System Health Report

Health Report Sections

Software Version(s)

System History with the software installation dates and software version numbers.

Firmware Version(s)

System History with the firmware installation dates and firmware version numbers.

Installed Assay(s)

The Installed Assay Procedures required to prepare and perform a specific test. In the context of this document, assay refers exclusively to a Hologic test, such as Aptima Combo or Ultrio.(s) version numbers and their installation dates.

System Statistics

Statistics of the System: Uptime, Number of Restarts, and Number of Fatal Errors that occurred since the previously generated report.

Assay Test Order Count

Assay types that ran on the system and the total number of assays executed over the duration of the report.

Rate of Invalids

Statistics of the System: Number of Tests, Number of Invalids, and Rate of Invalids that occurred since the previously generated report.

Total Test Orders with Flags

The number of test orders attempted on the system with the percentage of samples flagged during the interval of the report generated.

Test Orders with Single Flags

The number of test orders released with a single flag and the corresponding percentage.

Test Orders with Multiple Flags

The number of times this specific confirmation of flags occurred over the time interval of the report generated.

Flags By Module

The number of flags that occurred per system module.

Notable Events

A Subset of events that occurred during system activity and message log events filtered for system critical events: I.E. Prime Operation of pumping fluid through tubing to ensure proper and consistent fluid delivery (remove air from the tubing, etc.)., Hardware Failures, Non Fatal Hardware Events, and Issues.

Event Numbers for Modules, SubModules

Event Numbers per SubModule when:

  • Message—Green text
  • Warning—Orange text
  • Critical—Red text
  • Fatal—Red background with black text

Threshold Table—Lumo and Output Queue

Air/Liquid Threshold values determined during the Luminometer/Output OLV sensor calibration performed during prime.

MagWash Table

Flags

A subset of Assay Processing Codes "Flags" and generates the process control graphs of interest for particular flags.

Sensor Readings

Temperature and Vacuum measurements per module over the duration of the report.
