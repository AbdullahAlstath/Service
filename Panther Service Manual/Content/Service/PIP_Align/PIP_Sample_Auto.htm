Auto-Teaching—Sample Pipettor

  Note—To minimize contamination, perform the auto-teaching procedure in the following order.
  1. Endozime Holder.
  2. TCR Target capture reagent—An assay-specific reagent added as part of specimen pipetting. Carousel.
  3. Sample Bay Cover.
  4. Sample Dispense Slot.
  5. Right Tip Eject Chute.
  6. Press the Eject Tip Right button to dispose of the DiTi-cap.

Endozime Bottle

  1. Select the Endozime Bottle module icon.

    A Question dialog box appears.

  2. Click Yes.

    Auto-teaching begins.

  3. When auto-teaching has completed, proceed to the next module.

TCR Carousel

  1. Select the TCR Carousel module icon.

  2. At the prompt, insert the TCR alignment tool so that it lays across positions 1 and 3 with the teaching feature over position 1, as shown in the following photo.  

    Note—There are two TCR Alignment Tools available.

    903052 - TCR CAROUSEL, PIPETTOR TEACH TOOL

    MME-02076 - TCR TEACH TOOL, (For use with molded TCR Carousels Cut in on P827 and higher)

    A Question dialog box appears. 

  3. Select Yes.

    Auto-teaching begins.

Sample Bay Cover

  1. Remove the partition wall if not done so already.
  2. Select the Sample Bay Cover module icon.

    A Question dialog box appears.

  3. Click Yes.

    A prompt appears.

  4. Remove the partition wall.

    Auto-teaching begins.

Sample Dispense Slot

  1. Select the Sample Dispense Slot module icon.

    A Question dialog box appears.

  2. Click Yes.

    Auto-teaching begins.

Right Tip Eject Chute

  1. Select the Right Tip Eject Chute module icon.

    A Question dialog box appears.

  2. Click Yes.

    Auto-teaching begins.

  3. When auto-teaching has completed, click Eject Tip Right to dispose of the right Reagent Pipettor teach cap.
