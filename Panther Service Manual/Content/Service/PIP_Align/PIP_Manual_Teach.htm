Pipettor Teaching, Manual

Manual Teaching Tips

Previous Z Max - This button brings the pipettor to the last stored Z height.

  • At times this may be too far down causing a Z-axis stall.
  • A work around is using the Shift key.

Shift Key - The shift key on the keyboard drops the pipettor down half of the distance from the previous known Z and the current location. This allows for a much faster manual teach if the Z-Max position is too low and you cannot use the Z-Max button.

Manual Teaching to the Reagent Bay

  1. Remove the Reagent Bay cover prior to beginning the procedure.
  2. Insert the Reagent Bay teach tool into Lane 1.
  3. Select the Reagent Bay icon to start the teaching sequence.

    Note—The following points must be taught in the following order:

    1. Left Rear
    2. Left Front
    3. Right Front
  4. Select Prev Z.

    The Pipettor moves close to the first teaching point (Left Rear) of the Reagent Bay teach tool. The teaching points are holes in the base of the Reagent Rack in the first and last positions.

  5. Teach to the middle of the hole.
  6. Select OK.
  7. Select Prev Z.
  8. Teach to the next position (Left Front) to the center of the teach hole.
  9. Insert the Reagent Bay teach tool into Lane 4.

    The Pipettor moves to the right front hole.

  10. Select Prev Z.
  11. Teach to the middle of the hole.
  12. Select OK.
  13. Select Transfer to transfer and save the newly taught data.

Manual Teaching to the Sample Bay

  1. Insert 2 sample tubes (size 12/75) into positions 1 and 15 of a Sample Rack and insert the rack into Lane 1 of the Sample Module.
  2. Insert one sample tube (size 12/75) into position 15 of a Sample Rack and insert the rack into Lane 8 of the Sample Module.
  3. Ensure a Tip Tray is in the Tip Tray position of the rear tray drawer 1 (left drawer) and a tip is inserted in the left rear position of that tray.
  4. Select Pick Tip.
  5. If there is a tip, answer Yes to the following question. When a tip is missing, select No and restart the teaching sequence.
  6. Remove the Sample Bay cover.
  7. From the Main screen, select the Sample Bay icon to start the teaching sequence with a tip. The tip and the Adjust position window appear.

    Note—The following points must be taught in the following order:

    1. Left Rear
    2. Left Front
    3. Right Front
  8. The Sample Pipettor moves to the first teaching position.
  9. Teach the tip to the middle and bottom of the first position.
  10. The Pipettor is not allowed to touch the bottom surface at all, but the sample tube must have a clearance from 2 mm–3 mm. Test the clearance by lifting the sample tube up.
  11. Repeat steps 8 and 9 for the remaining two positions.
  12. When the teaching is complete, select Eject Tip.
  13. Select Transfer to transfer and save the newly taught data.

Manual Teaching to the Sample Dispense Slot

  1. If a teach cap is present, select the Eject Cap button. Sample Dispense is manually taught without a teach cap.
  2. Select the Sample Dispense Slot.

  3. When prompted "Shall the position be taught automatically?", select No.

  4. When prompted "Reference Position OK?", select OK.

  5. Follow manual teach procedures on the UI to position the Back Sample Dispense Slot location (MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. position 1):
    1. Using the manual controls, lower the pipettor until the DiTi tip is flush with the lower step of the Sample Dispense Slot over MTU tube 1 (or the back MTU location).
    2. Using the picture and measurements below align the pipettor in the x-axis. Approximately 7-8mm away from the left or right edge of the Sample Dispense Slot.

    3. Using the picture and measurement as guidance, position the y-axis approximately 5mm away from the back edge of the Sample Dispense Slot.

    4. After both the X and Y axis are in place, step up the Z direction approximately 240 steps (+/- 40 steps). Verify the height is approximately 12mm (+/- 2mm) above the top of the Sample Dispense Slot.

    5. Select the OK button.
  6. Position the Front Sample Dispense Slot location (MTU position 5):
    1. Using the manual controls, lower the pipettor until the DiTi tip is flush with the lower step of the Sample Dispense Slot over MTU tube 5 (or the back MTU location).
    2. Using the picture and measurements below align the DiTi in the x-axis, approximately 7-8mm away from the left or right edge of the Sample Dispense Slot.

    3. Raise the Z height up 80 steps. Using the picture and measurements as guidance, position the y-axis approximately 10mm away from the front edge of the Sample Dispense Slot.

    4. After both the X and Y axis are in place, step up in the Z direction approximately 160 steps (+/- 40 steps). Verify the height is approximately 12mm (+/- 2mm) above the top of the Sample Dispense Slot.

    5. Select the OK button and the Sample Dispense Slot is now manually taught.
  7. Transfer coordinates.
  8. Now that the pipettor is close, run Autoteach on the chute (with cap).
  9. Transfer and quit.

Manual Teaching to the TCR Carousel

  1. Select the TCR Target capture reagent—An assay-specific reagent added as part of specimen pipetting. Carousel icon to start the teaching sequence.

    The Adjust Position screen appears.

  2. Orient the TCR Carousel according to the following illustration.

    The right Pipettor arm moves close to the teaching point.

  3. The tip must be in the middle of the bore.
  4. After the teaching has completed, select OK in the Adjust Position screen.
  5. Select Transfer to transfer and save the newly taught data.

Manual Teaching to the Tip Eject Chute

  1. If a teach cap is present, select the Eject Cap button.
    Note—Eject Chutes are manually taught without a teach cap.
  2. Select the Reagent (left) or Sample (right) Tip Eject Chute.

  3. When prompted "Shall the Position be taught automatically?", select No.

  4. When prompted "Reference Position OK?", select OK.

  5. The Adjust Position window is used to manually position the pipettor at the rear chute location (back side). Use the keyboard to move the pipettor into the position shown below.
    1. To move in X, use the left/right arrow keys.
    2. To move in Y, use the up/down arrow keys.
    3. To move in Z, use the PageUp/PageDown keys. (Position the pipettor black box flush with the top of the Tip Chute.)
    4. Make adjustments to the Stepsize (increase or decrease steps) using the slider bar. Decrease the Stepsize as the pipettor nears the eject chute.
    5. Once in position, select OK.
  6. The Adjust Position window is displayed to position the pipettor at the front chute (front side). Use the keyboard to move the pipettor into position as shown below.
    1. To move in X, use the left/right arrow keys.
    2. To move in Y, use the up/down arrow keys.
    3. To move in Z, use the PageUp/PageDown keys. (Position the pipettor black box flush with the top of the Tip Chute.)
    4. Once in position, select OK.
  7. The Adjust Position window is used to set the Z-Start position. Use the keyboard and a ruler to move the pipettor into the position shown below.
    1. To move in Z, use the PageUp/PageDown keys.
    2. Using a ruler, position the pipettor up 12mm from the top of the front tip chute.
    3. Make adjustments to the Stepsize (increase or decrease steps) using the slider bar. Decrease the Stepsize as the pipettor nears the eject chute.
    4. Once in position, select OK.
    Note—Instead of steps a-d, usually just selecting the Previous Z button moves the pipettor to an acceptable position, then hit OK. Steps a-d can be used if this doesn't work.
  8. Transfer coordinates.
  9. Now that the pipettor is close, run Autoteach on the chute (with cap).
  10. Transfer coordinates.
