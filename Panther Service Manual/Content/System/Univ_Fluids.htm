Universal Fluids

Universal Fluids are loaded into the fluidics bay. The universal fluids consist of Auto Detect 1 and 2, oil, Magnetic Wash fluid, bleach, and Deactivation Buffer.

The A/B bottle method is used on all universal fluids. The A/B bottle method is defined by two identical bottles of each fluid type loaded on the system- so that each bottle can be used completely before replacement. The system will keep track of universal fluid volumes by tracking fluid volumes and tests available. When a bottle has 0 tests remaining, the user will be notified to replace the bottle during system setup. The system automatically scans all loaded bottles RFID tags. New bottles will be assumed to be full and the system will not allow the user to use bottles that were previously loaded on the system. The bottles and the connections to the bottles will be verified using liquid level sense, optical sense, and pressure sense methods during the system prime to insure proper system operation and to prevent contamination.

The universal fluid bottles are arranged in an A/B configuration. There are two of each bottle for Autodetect 1, Autodetect 2, oil, wash and buffer fluid. There is a single Bleach Bottle in addition to these. All the bottles except bleach have RFID tags on their labels for easy bottle identification.

  • The system primes universal fluid in 15 minutes.
  • Wash fluid bottle connections are checked by LLD.
  • Oil bottle connections are checked by an inline pressure sensor.
  • Deactivation buffer and bleach bottle connections are checked by an optical bubble sensor in the Output Queue.
  • AD1 and AD2 bottle connections are checked by optical bubble sensors in the Luminometer
