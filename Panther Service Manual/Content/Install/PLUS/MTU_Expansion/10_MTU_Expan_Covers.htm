Install the MTU Sidecar Covers

  1. Load all MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Carriers into the Sidecar.
    Note— You can move a carrier to the MTU Queue or loading position via service software.

  2. Locate the blue door cover.

  3. Secure the door cover to the MTU Sidecar using the 6 Philips screws included with the Kit.

  4. Secure the Hand-held bar code scanner bracket to the blue top cover with the 2 included screws.

  5. Attach the USB cable and USB hub power cable to the USB hub board on the top cover.

  6. Route these cable through the cable harness / cable guides.

  7. Connect the Status LED on the top cover to the PCB located on the back of the MTU Sidecar.

  8. Install the MTU Sidecar Top panel and align the top cover so that it is centered on the keyway of the sidecar.

  9. Adjust the top cover so that the face of the loading door and top cover are flush.
    If needed, adjust the hardstops to align the face of the loading door and top cover so they are flush.

  10. Secure the top cover with four screws and washers.

  11. Install the screw in the middle of the cover.

  12. Open the MTU Carrier Loading Door and loosen the two screws securing the hard stop guard.

  13. Remove the hard stop guard and install the provided screw and washer in the front of the cover.

  14. Re-install the hard-stop guard using the screws loosened in the previous step.
  15. Close the loading door.
  16. Locate the front cover.

  17. Insert the front cover at an angle to slide the front cover under the top cover.

  18. Push the bottom of the front cover to secure the cover in the snap clips.
      Note— You may have to adjust the marketing panel.

  19. Open the loading door and pull out the drawer to access the screw hole used to secure the front cover.

  20. Secure the front cover with the provided screw.

  21. Locate the side cover.

  22. Slide the side panel pins into the slots on the side of the MTU Sidecar.

  23. Slide the panel to the left and then push on the bottom of the panel to secure the snap clips.
  24. Locate the MTU Sidecar back.

  25. Install the Back Cover of the MTU Sidecar.
    1. Loosely Install the bottom two Screws.

    2. Slide the Back plate over the two bottom screws

    3. Loosely install 3 additional screws.
      Note—The middle screw location closest to the Panther is to be left empty.

    4. Loosely secure the Side Panel to the Back Plate using the included screw.

    5. Tighten all 6 screws to secure the backplate.
  26. Install the Side Panther Cover behind the MTU Sidecar.
    You may need to move the Hinge Plate Upwards for clearance to install the door.

  27. Install the side Panther Upper Cover.

  28. Route the monitor cables out of the Upper Cover and tighten the cable clamps.

  29. Secure the door in place using the screw located on the inside of the Panther chassis.

  30. Install the MTU Queue Cover.

  31. Plug in the handheld barcode scanner.

  32. Proceed to MTU Expansion Installation Verification
