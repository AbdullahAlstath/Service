MTU Expansion Autoteach

  1. Power on the Panther system and PC.
  2. Start Service Software.
  3. Verify that MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Expansion is a configured module on the Instrument Configuration page.

    Note—If needed, reset the Panther Configuration by navigating the Main & Com. tab and click Reset Configuration.

  4. Remove all MTU carriers from the system.
  5. Set Authorization Code.
    1. Click on the IC-MTU Expansion tab.

    2. Click on the Parameter tab.
    3. Set Authorization Code to 1.

  6. Select the Teach tab and verify MTU Lift is selected.

  7. Select Auto teach full (incl. MTU Queue).
  8. Click Execute. The Auto Teach will now begin.
    Note—A dialog box will appear asking if the carriers were removed from the MTU Expansion module. Verify to make sure there are no carriers in the module.
  9. After Auto Teach is complete, install ALL MTU Carriers in the MTU Expansion Module.
    1. Place MTU Carriers into any positions within the MTU Expansion module.

      2. Note: There must be a carrier in the loading position to properly teach the end of the travel.

    2. Orient all MTU Carriers as shown below:

  10. Under Select Drive, select MTU Pusher.
  11. Select AutoTeach End of Travel.
  12. Click Execute. The Auto Teach will now begin.
    Note—A dialog box will appear asking if the MTUs were removed from the carrier. Verify to make sure the carrier is empty.
  13. Continue to Install the MTU Sidecar Covers.
