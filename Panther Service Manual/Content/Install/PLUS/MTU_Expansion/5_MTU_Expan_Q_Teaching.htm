Teaching Linear Distributor to MTU Queue for Panther Plus

Auto Teach Linear Distributor to MTU Queue

  1. Move the Linear Distributor away from the MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. Queue (i.e. chiller slot 1)
  2. Insert the black MTU Queue Teach Tool into the MTU Queue.

  3. Remove the Retention Clip on the Input Queue Teach Tool.

  4. Insert the MTU Input Queue Teach Tool into the pick position of the MTU Queue.
  5. Firmly push the Input Queue Teach Tool into the MTU Queue until it is firmly up against the MTU Sidecar Alignment Tool.

  6. Manually align MTU Queue such that the tab of the Teach Tool and the Hook are centered.
    Note—See Using the Input Queue Autoteach Tool
  7. Select Position Teach MTU Input Queue or Auto Teach All.
    1. If Auto Teach All is selected for the Linear Distributor, ensure the service drawer is fully closed and latched.
  8. Allow the Linear Distributor to teach to the MTU Queue.
  9. Remove the Teach tools once teaching is complete.
  10. MTU Sidecar Installation

OR

Manual Teach Linear Distributor to MTU Queue

  1. Open Service Software.
  2. Loosen the 3 screws attaching the MTU Queue to the Panther Chassis
    1. One screw is located at the back of the MTU Queue.

    2. One screw is located at the front of the MTU Queue.

      aa

    3. One screw is located on the bottom plate of the MTU Queue

  3. Initialize the Linear Distributor and Input Queue in Service Software.
    Note—The MTU Queue is label Input Queue in Service Software.
  4. Perform the Theta Alignment procedure.
  5. Insert an MTU Carrier with a minimum of 2 MTUs into the MTU Queue.
  6. Click on the P-Front&Loading tab in Service Software.

  7. Click Push MTU.

  8. Click on the Linear Distributor tab.

  9. Click on Teach.

  10. Select Sledge in the Select Drive box.

  11. Select the Input Queue in the Select Position box.

  12. Select Move Theta & Z & X to selected Position (!! fast move!!) in the Options for selected Device and Drive.

  13. The Linear Distributor should be in position next to the MTU Queue.
  14. Select Move Hook to selected Position in the Options for selected Device and Drive.

  15. Click Execute.
  16. Physically position the MTU Queue so that the tab of the MTU and the Hook are centered.

  17. Tighten the 3 screws securing the MTU Queue loosened in the previous Step 2.
  18. MTU Sidecar Installation
