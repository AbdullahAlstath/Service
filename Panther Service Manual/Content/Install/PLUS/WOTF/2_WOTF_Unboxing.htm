Unboxing Waste on the Fly

  • Dimensions of Waste on the Fly packaging
    • (82cm x 122cm x 163cm @ 47kg)
    • (32in x 48in x 64in @ 105lbs)
  •   Note— Pictures below are for Reference ONLY. Your setup may differ.
    1. Locate the Panther Plus pallet.

    2. Cut the restraining straps and set the largest box aside.
    3. Open the larger box.
    4. Remove and set aside the smaller boxes.

    5. Locate the box labeled ASSY TIP CAROUSEL.

    6. Open the box and remove the top layer of foam.

    7. Remove and set aside the Tip Carousel and CAN cable.

    8. Locate the box labeled ASSY TIPLET CATCHER.

    9. Open the box and set the Stratec Test Protocol sheet aside for the Service Records.

    10. Remove the top layer of foam.
    11. Remove and set aside the Tiplet Disposable tip within an MTU. Catcher.

    12. Locate the box containing the waste bottle and tubing.

    13. Remove and set aside the contents of the box.

    14. Set the waste bottle aside for assembly.
    15. For Full Waste Drawer Assembly ONLY, open the box containing the Waste on the Fly entire waste drawer.

    16. For Waste Drawer Upgrade Kit ONLY, complete the following substeps:
      1. Open the bag containing the sensors and metal bracket.

      2. Set the contents aside for assembly.
      3. Open the other bag containing all of the tubing.
      4. Set tubing aside for assembly.

      5. Open the box containing the Vacuum Bottle.

      6. Set the Vacuum Bottle aside for assembly.
      7. Open the box containing the Filter Block, Pump Housing, and Waste Bottle Coupling Block.

      8. Set aside for assembly.
    17. Open the box containing the Vacuum Filter.

    18. Set aside for assembly.
    19. Continue to the Solid Waste on the Fly Installation procedure.
