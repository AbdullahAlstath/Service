Pipettor Pressure Integrity Test

Time Required

  • 15 Minutes

Procedure

Any test result equal to 0.33 or above is a successful test result for the Pressure Integrity Test.

Screenshots are for reference only. Your screen may vary.

  1. Start up Service Software.
  2. Navigate to the System tab.
  3. In the Pressure Integrity Test section, select the Report checkbox. This instructs the system to generate a report of the results.
  4. In the Pressure Integrity Test section, check Initialize. This initializes all modules.
  5. Check the box next to Left Arm.
  6. Click Pressure Integrity Test.

    The Report Setup screen appears.

  7. Enter your name for the login name and click OK.

    A Service Software dialog box appears.

  8. Insert a DiTi cone cap into Position 1, Tip Tray 1, Tip Drawer 1


  9. Click OK.
  10. Different versions of Service Software will display different ranges for the Pressure Integrity Test Ratios.
    Remember:
    Any test result greater than 0.33 is a successful test result for the Pressure Integrity Test. See Sample Test Results below for reference.
  11. Repeat Steps 3–10 for the right pipettor arm.
  12. If this is an installation, continue to System Level Operational Qualification (OQ).

Note—
In some versions of Service Software, Test results over 1.00 will display as a "fail"; however, results over 1.00 are acceptable as a passing value.
