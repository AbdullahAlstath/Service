Panther Installation

  1. Panther Site Assessment Form
    • Confirm the Site Assessment Form [AW-19118] has been accurately completed and any open items have been addressed.
  2. Panther System Installation Qualification and Operational Qualification Checklist
    • Download and perform the latest version of the IQ Input queue—Module used to load MTUs onto the Panther instrument. Installation qualification—Set of procedures to verify the proper installation of a Panther system./OQ Checklist [MTD-00902] from Agile.
    • The steps below follow [MTD-00902]
  3. Uncrating the Panther System
    1. Uncrating the Panther System
    2. Uncrating the Accessory Kit
    3. Uncrating the Marketing Kit
  4. Installation Qualification (IQ)
    1. Move and place the Instrument at the customer’s specified location as per the Site Assessment Form.
    2. UPS Installation
    3. Monitor Installation
    4. PC Hardware Setup
    5. Software Installation
    6. Initial Module Preparation/Extra HW Installation
    7. Run Instrument Setup (Firmware)
    8. Panels and Canopy Installation
    9. System Leveling
    10. Trims and Door Panel Assembly
    11. Install the Front Marketing Panel
    12. Installing New Hand-held Barcode Scanner (F560) and Bracket Install Procedure
    13. Verify Fittings are Hand Tight
    14. Pipettor Auto-Teaching
    15. Load Service Software Customer Parameters.
    16. Teach the Linear Distributor
      1. Distributor Teaching without the IQ Auto Teach Tool (for System SW v5.3 and below)
      2. Distributor Teaching with the IQ Auto Teach Tool (for System SW v6.2 and above)
    17. Fill the Cooling Module
    18. Configure the Reagent and Sample Bay Barcode Scanners
    19. Install the Pipettor Front Shield
    20. Printer Installation
  5. Firewall and Network Connections (if needed)
  6. Operational Qualification (OQ)
    1. Pipettor Pressure Integrity Test
    2. System Level Operational Qualification (OQ)
    3. System Bootup
    4. Panther GUI SW Configuration
    5. Software Verification
    6. System Prime
    7. Check Lumo Cal Factor
      1. To be within specifications, the Calibration Factor MUST read between 0.12–0.24
        If the Lumo Cal Factor is within specification, proceed to Step8.
      2. If Lumo Cal Factor is NOT within specification, (e.g. Cal Factor is set to 1), then run SysCheck.

      Note— If Lumo Cal Factor is already confirmed, skip to Step 8.
    8. Panther Luminometer Flashcheck Reagent Verification Procedure
  7. Panther System Performance Qualification (PQ) Procedure
  8. Post Qualification
    1. Dispose of universal fluids according to laboratory procedures.
    2. Empty solid and liquid waste according to laboratory procedures.
