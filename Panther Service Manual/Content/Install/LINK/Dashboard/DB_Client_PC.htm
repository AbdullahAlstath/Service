Dashboard Client PC Installation

Parts and Materials Required

  • Proper PPE
  • Panther Tool Kit
  • Completed Lab Automation Site Assessment Form (AW-19118)
  • Completed Dashboard Server Installation
  • Dashboard Client PC Image
    refer to the applicable Software Install TB for correct Part Number
  • Kanguru Lockable USB Drive - [CMP-01689]

  • Rufus Software v3.5 [SW-05850] - MUST use software from BOX or AGILE
    Do NOT use Rufus downloaded from the Interwebs
  • Logic Supply CL100 Mini PC [CMP-01662]

  • 4K TV Installed
    (A power plug near the 4K TV is also required)
  • HDMI Cable
  • Ethernet connection near the 4K TV
  •  

Time Required

  • 30 Minutes

Procedure

Part A: Creating a Bootable Drive for the Dashboard Client PC

Note— Screen shots below are for reference ONLY.
Note— When removing a USB Drive always remember to use the “Safely Remove” icon.
Note— The FSE Laptop user MUST have Administrator privileges.
  1. Download the Dashboard Client PC Image from Agile or Box to the FSE laptop.
  2. Insert the USB drive into the FSE Laptop.
  3. Open Rufus Version 3.5.
  4. Select the USB drive from the Device drop-down menu.
  5. Click SELECT to locate the image file.
  6. Navigate to and Select the Dashboard, Client PC Image .iso file in the file explorer window.
    Note—
    You may need to extract the downloaded Zip file to access the (.ISO) image.

    It may be necessary to select "All Files" types in the lower right-hand corner of the file explorer window to find the image file.
  7. Verify that the Rufus configuration matches the image below.

  8. Click Start to create the bootable USB drive.
  9. Select the "Write in DD Image mode" radio button in the pop-up window.

  10. Click OK.
  11. Close Rufus when the image writing process is complete.
  12. Safely remove the bootable USB drive from the computer.

Part B: Panther Link Dashboard Client PC Install

  1. Open the Logic Supply CL100 Mini PC box.
  2. Connect the power cable and plug into an outlet near the 4K TV.
  3. Connect the HDMI cable to the Client PC and 4K TV.
  4. Connect the Client PC to the customers network with an ethernet cable (CAT5e or higher).
  5. Plug in a Keyboard and Mouse (can be borrowed from the Panther).
  6. Insert the Bootable USB Drive into the Client PC.
  7. Power on the Client PC and press F11 as the PC is booting.
  8. If a BIOS Password is requested, enter: !L@8@ut0
  9. Select USB: Storage Device or UEFI OS in the Boot selection menu.
  10. The Proteous Kiosk will now load. This may take up to a minute to start.
  11. Select the Network Configuration Type designated in the Lab Automation Site Assessment Form.
    Screenshot for reference ONLY

  12. Click OK on the Google Chrome EULA page
  13. Click Next on the Confirmation Page
  14. Follow the instructions below for each Network Configuration Type.
    1. Select Configure Using DHCP
      1. Click Next.
      2. Proceed to Step 16.
    2. Configure Manually (Static IP Address)
      1. Type the designated IP Address, Network Mask, Gateway, DNS Server 1, and DNS Server 2 (if necessary) from the Site Assessment Form for the Panther Link Dashboard Client PC.

      2. Click Next when completed.
      3. Review the network configuration and click Next.
      4. Proceed to Step 16.
  15. Click on Select under Browser Settings on the Wizard screen.

  16. Enter the Dashboard group home page.

    Note—This is the ONLY webpage that the Dashboard PC will display. Typing in the NAT'ed IP Address of the Dashboard Server will only allow you to access the Dashboard homepage and not the desired Dashboard.

    You MUST enter the address of the Dashboard View for the TV to display the correct information. Use the FSE laptop determine the full address of the view.

  17. Click Test homepage to ensure that the web address was entered correctly.
    The Dashboard will now display.
  18. Close Chrome.
  19. Click OK if the web address is correct.
  20. Click Change time zone under System Settings on the Wizard screen.

  21. Click Next
  22. Select the desired Time Zone for where the customer is located.
    If “pool.ntp.org” is unavailable or the customer has an alternate NTP server, enter it here.

  23. Click OK.
  24. Review the Setting report and click Next to proceed.
    Note—To Save or Load a configuration see instructions in Part D and Part E.

  25. The Kiosk ID page will display a unique hardware identifier specific to the kiosk software.
    Add this information to the Lab Automation Site Assessment Form if necessary.

  26. Click Next.
  27. Select the Quick Formatting radio button on the System Installation screen.
  28. Select the hard drive of the Client PC.
    Caution—Do NOT select the bootable USB flash drive.

  29. Click Install System. The Image Burn process will begin. Keep a note of the time.
  30. The Kiosk banner might display the following when complete.

  31. Remove the USB drive, keyboard and mouse.
  32. Restart the Client PC.
    Note—The USB hubs will be disabled after the OS has booted but not while the BIOS is still starting.

Part C: Verification Procedure

  1. Restart the Dashboard Client PC.
  2. Allow PC to boot and navigate to the desired webpage.
  3. Confirm the correct webpage and data is displayed

Part D: Saving a Configuration

  1. Insert a second USB drive to an open port on the Client PC.
  2. From the Setting report page of the Porteous Kiosk click Save Config.

Part E: Loading a Configuration

  1. Insert a USB storage device with the previously stored configuration.
  2. From the Setting report page of the Porteous Kiosk, click Load Config.
