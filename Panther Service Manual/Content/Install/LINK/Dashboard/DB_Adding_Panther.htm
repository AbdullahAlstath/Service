Adding a Panther to Lab Automation Dashboard

  1. Ensure that the Panther Link Dashboard Feature is Enabled.
  2. Log in to the Panther Main as an Administrator on the Panther.
  3. Navigate to Administrator.
  4. Click the Next button until Manage Remote Data Access and click the button.
  5. The Manage Remote Data Access page will appear.
  6. Click the Generate button.
  7. A generate access pop-up will appear with a text box for Owner.
    Note—Type in an owner that you can use as a key to remember in the following steps. WRITE THIS OWNER DOWN.
  8. Click the OK button.
  9. A pop-up window will appear with a unique randomly generated access key to populate within the Dashboard Server.
    IMPORTANT—WRITE THIS KEY DOWN OR TAKE A PICTURE. This key will not be remembered by the system and will be lost after the window is closed.
  10. Log in to the Dashboard Server as an FSE.
  11. Select the Menu button in the top right of the Dashboard.
  12. Select the Administration button.
  13. Select the Paw icon or Instrument Management tab.

  14. Select Add Instrument on the Instrument Management Page.

  15. A pop-up window labeled Add Instrument will appear.

    1. Populate the IP Address of the Panther that you generated the unique key from Step 9.
    2. Populate the designated Dashboard Port number generated from the output.
    3. Populate the Alias Name with a generic name fro the Panther you wish to add.
      1. This may be anything, the customer may want to name their instrument.
        1. i.e. Bubbles or 2090002345
    4. Populate the Alias Short Name with a generic name for the Panther you wish to add.
      1. This may be anything, the customer may want the name to appear shorter. This will be used in the card view layout.
        1. i.e. Bub or 2345
    5. Populate the Access Owner that you wrote into the Panther during the access key generation procedure.
    6. Populate the Generated Access Key with the key generated from the Panther during the access key generation procedure.
    7. Click the Add button.

 

Click the button at the top of the page to send feedback, comments, or change requests.
