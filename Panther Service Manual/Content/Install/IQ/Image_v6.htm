Installing Image v6.x.x.x (for Dell XE3)

Configure the BIOS

  1. Start the Panther PC and press F12 during bootup to enter the BIOS menu.
  2.  In the BIOS menu, Enable “UEFI Boot mode, Secure Boot OFF”:
    1. Use the arrow keys to highlight Change Boot Mode Settings and press ENTER.

    2. Verify which Boot mode is selected.
      1. IF set to: UEFI; Secure Boot: OFF, then exit Setup and proceed to Install / Deploy the Windows Image below.
      2. IF set to: UEFI; Secure Boot: ON, proceed to Step c below.
    3. Highlight UEFI Boot Mode, Secure Boot OFF.

    4. Press Enter.
    5. Select Yes when asked DO YOU WISH TO PROCEED?

    6. Press Enter.
    7. Select Apply the Changes.

    8. Press Enter. The PC will restart.

Install / Deploy the Windows Image

  1. Refer to the latest System v7 software TB to confirm what Image version must be installed.
  2. Insert the Bootable USB drive with the Panther Image into one of the PC's front USB ports.
  3. Restart the PC.
  4. Press F12 while the PC is booting to access the Boot Menu.
  5. Select UEFI: Kanguru SS3 under UEFI Boot.

  6. Press Enter.
  7. The Imaging Tool application will be displayed.
  8. Select the UEFI/GPT radio button.

  9. Click on Choose File.
  10. Double click on This PC.

  11. Open the USB device containing the Panther Image.
  12. Select the Panther Image .wim file and click Open.
  13. Click on Start Recovery Process.
  14. Once the Progress reaches 100% (less than 10min), Click Reboot and Remove the Bootable USB Flashdrive.

  15. Press F12 during bootup to enter the BIOS menu.
  16.  In the BIOS menu, Enable “UEFI Boot mode, Secure Boot ON”:
    1. Use the arrow keys to highlight Change Boot Mode Settings and press ENTER.

    2. Highlight UEFI Boot Mode, Secure Boot ON.
    3. Press Enter.
    4. Select Yes when asked DO YOU WISH TO PROCEED?
    5. Press Enter.
    6. Select Apply the Changes
    7. Press Enter. The PC will restart.
  17. After rebooting the PC boot will into Windows. Re-name the PC
    1. Right click on the Windows icon in the bottom left of the screen.
    2. Click System.

    3. Click Change Settings.

    4. From the System Properties Pop-Up, click on Change.

    5. In the Computer Name Field: enter the name of the Panther System in the following format: PANTHERXXXXX-PC.
      Where XXXXX is the Panther System serial number located below the main power switch. (Example full name: PANTHER00888-PC)

    6. Click OK and Click OK again.
  18. Affix the Win10 License sticker (Certificate of Authentication) onto the Panther PC (if not already present).
