RDxM and LIS Configuration Capture

Parts and Materials Required

  • Panther System PC
  • USB memory stick or USB external hard drive

Time Required

  • 10 minutes

Procedure

  1. Insert the USB external hard drive or USB memory stick into the Panther System PC.
  2. From the FSE Panther Shield software, launch the Panther Dashboard software.
  3. Navigate to the NIC Configuration tab on the right side of the Panther Dashboard software screen.

  4. Print or capture the Network Connectivity information.
  5. Launch the Panther System main assay software and log in as an Admin User.

  6. Select Admin.

  7. Select System Configuration.

RDxM Configuration Capture

  1. Select the User Interface drop-down menu.

  2. Print or capture the User Interface configuration by saving a screen shot of the User Interface fields to the USB memory stick. Name the image Screen Shot, User Interface-RDxM.

  Screen Shot, User Interface-RDxM will be used during the RDxM Configuration procedure.

LIS Configuration Capture

  1. Select the Results Management drop-down menu.

  2. Print or capture the Results Management configuration by saving a screen shot of the Results Management fields to the USB memory stick. Name the image Screen Shot, Results Management-LIS.

    Screen Shot, Results Management-LIS will be used during the LIS Configuration procedure.
  3. Select Admin.

  4. Select LIS Configuration.

  5. Print or capture the LIS Serial Configuration by saving a screen shot of this page to the USB memory stick. Name the image Screen Shot, LIS Serial-Screen1.

    Screen Shot, LIS Serial-Screen1 will be used during the LIS Configuration procedure.
  6. Scroll down the page to capture the second screen shot for LIS Serial Configuration. Print or capture the configuration by saving a screen shot of the fields to the USB memory stick. Name the image Screen Shot, LIS Serial-Screen2.

    Screen Shot, LIS Serial-Screen2 will be used during the LIS Configuration procedure.
  7. Scroll down the page to capture the third screen shot for LIS Serial Configuration. Print or capture the configuration by saving a screen shot of the fields to the USB memory stick. Name the image Screen Shot, LIS Serial-Screen3.

  8. Navigate to the TCP/IP section and capture the LIS TCP/IP Configuration by printing or saving a screen shot of this page to a USB memory stick. Name the image Screen Shot, LIS TCPIP-Screen1.

    Screen Shot, LIS TCPIP-Screen1 will be used during the LIS Configuration procedure.
  9. Scroll down the page to capture the second screen shot for LIS TCP/IP Configuration. Print or capture the configuration by saving a screen shot of the fields to the USB memory stick. Name the image Screen Shot, LIS TCPIP-Screen2.

    Screen Shot, LIS TCPIP-Screen2 will be used during the LIS Configuration procedure.
  10. Scroll down the page to capture the third screen shot for LIS TCP/IP Configuration. Print or capture the configuration by saving a screen shot of the fields to the USB memory stick. Name the image Screen Shot, LIS TCPIP-Screen3.

    Screen Shot, LIS TCPIP-Screen3 will be used during the LIS Configuration procedure.
  11. Close the Panther System main assay software.
