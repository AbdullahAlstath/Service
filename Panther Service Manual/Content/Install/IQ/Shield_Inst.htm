Installing the Panther Shield and CPU Software

Parts and Materials Required

  • DELL OPTIPLEX XE, XE2 or XE3 PC
  • Panther System Shield SW (Download or CD) - always refer to the applicable software TB for Part Numbers
  • Bios Software
  • USB Universal Driver Software

Time Required

  • 10 minutes

Procedure

Note—Screenshots listed below are for reference only.
  1. Insert a USB drive with the Panther Shield Software into a USB port on the PC (for XE3 computers, use the front, blue USB port).
    OR
    Insert the Panther Shield CD into the DVD-ROM drive.
  2. Open Windows Explorer and browse to C:\Panther and double-click on InstallPackageUI

  3. From the Install Package Window that opens, Click on Browse

  4. Navigate to the Panther Shield Setup folder and double-click the PantherShieldSetup.gpz file.

    Note: Refer to Panther Software System Installation TB for appropriate PantherShieldSetup.gpz version number. Image below is for reference only.


  5. You will be returned to the InstallPackageUI. Click Install Package to start the installation.
    NOTE—Installation may have a delay of about 30 seconds.
  6. The Installation Wizard will appear. Click Next
  7. Select the Correct Vendor and System and Click Next
  8. Click Next on the Confirm Installation window.

  9. As the installation proceeds, a progress window will be displayed.
  10. When finished The Installation Complete window will display.
    Click on Close
  11. For Panther Software 7.2 and above, install the following:
    1. Dell Optiplex XE3 Bios SW from the InstallPackage.

      1. Select Update.
      2. Select Restart.
  12. Press Close on the InstallPackageUI window
  13. Remove the Panther Shield software CD or USB.
  14. Restart and verify the Panther Shield version.
  15. For Panther SW 7.2 and above, confirm the Panther is on Com Port 3. If not, refer to the instructions below.
    1. From the FSE Shield, open Windows Explorer. 
    2. Right-click on This PC then select Properties.
    3. Select Device Manager.
    4. Select Ports (COM & LPT).
    5. Right-click on Panther (COM4) and select Properties.
    6. Select Advanced.
    7. Highlight COM3 (in use) and select OK.
    8. Select Yes.
    9. Select Yes.
    10. Verify COM3 shows Panther.
  16. Proceed to Install all Panther software.
