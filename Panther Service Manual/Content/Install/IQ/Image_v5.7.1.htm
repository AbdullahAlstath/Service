Image v5.7.1 (Windows 7) Installation Procedure

Note —
This Windows 7 Image can only be installed on Dell OptiPlex XE2 PCs.

Parts and Materials Required

  • Proper PPE
  • USB Flash Drive or USB External Hard Drive
  • Dell OptiPlex XE2
  • Microsoft License Key Label, Win Pro 7

Procedure

Part A: New Panther Install

  1. Install the image using Panther IMAGE v5.7.1.
    1. Refer to: Imaging the Panther System Workstation, Optiplex XE2.
    2. Proceed to Part C

Part B: Upgrade Existing Panther to Windows 7 Image

  1. From the FSE Shield start Panther Main.
  2. Purge Message Logs. Purge anything older than 30 days from the message logs.
  3. Gather Test Count Data.
  4. Generate a Configuration Report to capture all System Configuration settings listed in Panther Main under Admin > System Configuration.
  5. Screen Capture:
    • LIS configuration
    • RDxM,
    • NIC settings (if applicable).
  6. Screen Capture the currently installed assay menu.
  7. Shutdown Panther Main.
  8. Backup the database on an external drive.
  9. Save a copy of the data folder: C:\Panther\Software\PC\Data.
  10. Save previous Syscheck, Flashcheck and Performance Qualification reports from: C:\Panther\Software\PC\Bin\Utils\PantherDashboard\Reports (If required).
  11. Save previous OQ Data from: C:\Panther\Panther Service Software\Log\Reports (If required).
  12. Shutdown and Restart the PC.
  13. Install the image using Panther IMAGE v5.7.1.
  14. Proceed to Part C

Part C: Install System and Assay Software v5.3

Install System and Assay Procedures required to prepare and perform a specific test. In the context of this document, assay refers exclusively to a Hologic test, such as Aptima Combo or Ultrio. software as per region:

  • Refer to: TB-01153 v5.3.3.0 for US Only
  • Refer to: TB-01167 v5.3.2.9 for Canada ONLY
  • Refer to: TB-00999 v5.3.2.9 for ROW

Verification

Perform Image Version Verification

  1. Verify the image by navigating to C:/Panther.

  2. Refer to the appropriate software installation TB to verify firmware Module and Assay Software version (refer to Part C, above).
  3. Complete a Full System Prime Operation of pumping fluid through tubing to ensure proper and consistent fluid delivery (remove air from the tubing, etc.)..
  4. Every Windows 7 Image install requires a Proof of License sticker to be applied to the Dell Optiplex XE2 PC. If there is no sticker present on the PC, or if you are installing a new version of Windows on the PC, apply the supplied sticker as shown in the following image.
