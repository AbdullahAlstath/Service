BIOS Configuration Procedure

Parts and Materials Required

Time Required

  • 10 minutes

Procedure

On a Dell OptiPlex XE for Image v3.0.11 (Win Vista)

  1. Shut down and reboot the Panther System PC.
  2. Press F12.
  3. Scroll down to BIOS Setup.
  4. Press Enter.
  5. Scroll down to Boot Sequence.
  6. Press Enter.

    The Boot Device Menu screen appears.

    Note — If the Boot Device Menu is locked, complete the following steps to unlock it:
    1. Tab to highlight the Unlock button.
    2. Press Enter.
    3. Enter gpservice in the input field.
    4. Press Enter.
  7. Using the Tab key, navigate to the right screen and clear the following checkbox options by pressing the Enter key:
    • Onboard or USB floppy drive
    • Onboard or USB controller USB CD-ROM
    • Onboard network controller
    • Onboard USB device
  8. Tab to Apply and press Enter.
  9. Scroll down to Security.
  10. Press Enter.
  11. Scroll down to administrator password.
  12. Tab over to the New Password field.
  13. Press the Num Lock key and the Caps Lock key to turn them off.
    Note — Ensure LEDs on the keyboard over Num Lock and Caps Lock are off.
  14. Enter gpservice in the New Password and Confirm New Password fields.
  15. Tab over to OK and press Enter.
  16. Scroll down to Post Behavior.
  17. Press Enter.
  18. Scroll down to Numlock LED.
  19. Tab over to uncheck Enable Numlock LED.
  20. Tab to Apply.
  21. Press Enter.
  22. Tab to Exit and press Enter.

    The PC reboots.

  23. When prompted in the upper right corner of the Dell OptiPlex XE screen, press F12 to enter into BIOS.
  24. Confirm the Administration Password control access.

    The Boot Device Menu screen appears.

  25. Scroll down to System Setup and press Enter.
  26. Tab to highlight the Unlock button.
  27. Press Enter.
  28. Enter gpservice in the input field.
  29. Tab to OK and press Enter.
  30. Tab to Exit and press Enter.
  31. Shut down and reboot the PC and system.
  32. Continue to Resetting the PC Clock and Date.

On a Dell OptiPlex XE2 for Image v3.0.11 (Win Vista) and Image v5.7.1 / v5.8.3 (Win 7)

  1. Restart the Panther System PC.
  2. Press the F12 key when the boot process begins.
  3. On the Boot Screen, use the arrow keys to select BIOS Setup.

  4. Press Enter and the Dell OptiPlex XE2 BIOS Configuration window appears.
    Note — If the BIOS Menu is locked:
    1. Click the Unlock Button (at the bottom of the screen).
    2. Enter "gpservice" in the input field and click Enter.

    If "gpservice" is accepted, proceed to Step 5.

    If "gpservice" is NOT accepted as a password, you will have to reset the BIOS password. Refer to Resetting the BIOS password on an XE2

  5. Select Boot Sequencein the General section on the left of the BIOS Configuration window.
  6. Only the hard drive, shown in the following figure as ST500DM002-1BD142, should be checked.
    Note — The name of the hard drive will vary from system to system. Uncheck (clear) all other options under Boot Sequence.

  7. Expand the POST Behavior section in the left-hand pane.
  8. Select Numlock LED. Uncheck the Enable Numlock LED option in the right pane.

  9. Expand the Security section in the left-hand pane.
  10. Select Admin Password.
  11. Enter gpservice as the password in both the New password and Confirm password fields in the right pane.
    NOTE — ENSURE THAT NUM LOCK IS TURNED OFF when entering the new password.
  12. Click OK.
  13. Click Exit to reboot the Panther System PC.

  14. On initial boot up USB drivers will auto-install.
  15. After USB drive installation, reboot the PC.
  16. Continue to Resetting the PC Clock and Date.

On a Dell OptiPlex XE2 OR a Dell OptiPlex XE3 for Image v6.0.13 (Win 10)

  1. Restart the Panther System PC.
  2. Press the F12 key when the boot process begins.
  3. Set the Boot Mode to: UEFI; Secure Boot: OFF.
  4. Confirm the current Boot Mode Setting.
    (In the example below the Boot Mode is set to: UEFI; Secure Boot: ON, listed in yellow)
    1. If the UEFI; Secure Boot is ON, proceed to Step 5
    2. If UEFI; Secure Boot is OFF, this procedure is complete.
  5. Use the arrow keys to highlight Change Boot Mode Settings.

  6. Press Enter.
  7. When offered "CHANGE BOOT MODE TO:" select UEFI Boot Mode, Secure Boot OFF.

  8. Press Enter.
  9. Select Yes when asked DO YOU WISH TO PROCEED?

  10. Press Enter.
  11. Select Apply the Changes for Final Confirmation.

  12. Press Enter.
  13. Restart the PC.
