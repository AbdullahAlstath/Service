Installing Panther Remote Dashboard Software

Parts and Materials Required

  • Panther System PC
  • Panther Remote Dashboard Software (not to be confused with Panther Link Dashboard)

Time Required

  • 10 minutes
Read the entire procedure first before beginning the installation process.

Procedure

  1. Power down the system.
  2. Ensure that the Panther Remote Remote Dashboard software is not running.
  3. Insert the disk labeled Panther Remote Remote Dashboard Software into the CD drive.
  4. Log in to the Panther FSE Shield software.
  5. Select the Install Software icon.

    A Panther Software Installer dialog box appears.

  6. Select Browse.

  7. Navigate to the CD drive and select the .gpz file.
  8. Select Install Package.
    The CD-ROM will start flashing and reading the installation file.

    A Remote Remote Dashboard Patch Installer screen appears.

  9. Select Install.

A status bar at the bottom of the screen shows the progress of the installation.

If the installation is successful, the following messages appear:

  • Remote Remote Dashboard Version X.x.x.x is restored …
  • Remote Remote Dashboard Version X.x.x.x is installed …

Verification

  1. After running the installer, ensure that the new version number displays on the Remote Dashboard Patch Installer screen.
  2. Launch the Panther Remote Dashboard software and verify that it starts up correctly.
  3. Select the About menu on the left side of the Panther Remote Dashboard software screen and verify that the new version number displays.
  4. After verifying a successful installation, click the X located in the top right corner of the screen to close the Remote Dashboard Patch Installer.
  5. If the Panther Remote Dashboard software either freezes or displays an error message on start-up, then the installation failed. Repeat the installation procedure.
  6. If the Remote Dashboard software still does not start up, capture screen shots of any error messages and contact Technical Support.
Notes on the Remote Dashboard Patch Installer Screen
  • The Current Installed Version represents the version of the Panther Remote Dashboard software that is currently installed.
  • The Install button will install the version that displays in the list box next to it.
  • The Restore Backup button restores the backup version that shows up in the list box next to it.
  • If no back-ups are currently in the Panther Remote Dashboard software installation folder, the Restore Backup button and the list box next to it are disabled and grayed out.
  • If the Panther Remote Dashboard software is not installed, the Current Installation text does not display a version number.
