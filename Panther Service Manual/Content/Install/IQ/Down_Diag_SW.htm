Downloading Software from Agile

Parts and Materials Required

  • Hologic-issued computer with USB port
  • USB Thumb Drive, (16 GB minimum capacity)
  • CD/DVD writer (if not available on the Hologic-issued computer)
  • DiskVerify (P/N 104758-SWMF)
  • Writable CD or DVD

Time Required

  • Varies by file size and CRC check

Additional Information

  • Diagnostic Software is released in the Agile Product Lifecycle Management (PLM) system.
    • Software will be a group of files or bundled into a .zip file.
  • Software can be downloaded from Agile to sites such as a SharePoint, the Teams Drive, BOX-Cloud File Storage, or an EFT site.
    • It is the FSE's responsibility to download and install the correct SW as per the appropriate installation TB.
  • A Cyclic Redundancy Check (CRC) or Secure Hash Algorithm (SHA) MUST be performed on ALL downloaded SW.
    • A CRC/SHA will validate that the correct software has been downloaded prior to installation.
    • CRC/SHA numbers will be listed in the associated installation TB.
    • CRC/SHA numbers can also be found in the ECO package.
  • The DiskVerify tool MUST be used to confirm CRC accuracy.
    • The DiskVerify application only scans folders. It does not scan individual files.
  • A SHA 256 check MUST be performed to verify SHA values
    • The SHA 256 values will be listed in the applicable Software Install TB
  • SW that has a .gpz extension do NOT require a CRC by the DiskVerify application after downloading.
    • The system will check to make sure the .gpz file has not been corrupted.
  • Some .gpz files are embedded in .zip files. Not all of these .zip files will have a CRC number associated with it.

Procedure

Note—Screenshots are for reference only and may vary by software version.

Part A: Download Software from the Agile PLM System

  1. Navigate to Agile PLM from MyHologic.
  2. Log in to Agile
  3. Enter the appropriate software number in the search box. (Example SW-04021)
  4. Click the right arrow or press Enter.

  5. Click on the appropriate Software.

  6. Click on the Attachments tab.

  7. Highlight the appropriate .zip file by clicking the gray box to the left of the filename.

  8. Click Get.

  9. Click Save.

  10. Click Open folder.

  11. Right click on the .zip file and click Extract All...

  12. Click Browse... in the pop-up window.
  13. Select the USB flash drive, CD, or DVD for the .zip file and click Select Folder and then Extract.

  14. Verify the version of the file matches the appropriate TB.

Part B: Obtaining CRC # from the Agile PLM System

NOTE: The CRC Number and information can be found in the related TB.

  1. Log in to Agile PLM from MyHologic.
  2. Enter the appropriate search criteria. (Example ECO-41516)
  3. Click the right arrow to execute the search.

  4. Click the Attachments tab.

  5. Highlight the appropriate file by clicking the gray box to the left of the filename.

  6. Click Open.

  7. Search for the appropriate CRC #.

Part C: Perform CRC Verification

NOTE: Make sure the files are unzipped in a different location before performing CRC Verification.

  1. Download the DiskVerify Application in to your Laptop or PC as needed.
    1. Log in to Agile PLM from MyHologic.
    2. Search for 104758-SWMF
    3. Download 104758-SWMF.zip
    4. Extract the zip file to access DiskVerify.exe
  2. Run the DiskVerify application.

  3. Type in the CRC # into the Expected CRC field then click Set Drive.

  4. Select the folder on the USB Thumb Drive, CD, or DVD that contains the downloaded software and click OK.

  5. Click Compute CRC.

  6. Confirm that the CRC # matches the input CRC #.
    1. If the CRC # does not match you cannot use of install the software file on a system. Repeat the CRC check and/or download the software again.
    2. If the CRC # does match, then you can install the software per the systems normal software installation procedures.

  7. Using the standard Microsoft Windows method, eject the USB Thumb Drive, CD, or DVD from the computer. The USB Thumb Drive, CD, and DVD can now be used to install software on the applicable system.

Verification

  1. Once the CRC is check with the DiskVerify application, the USB Thumb Drive, CD, or DVD can be re-used to install the software on other systems.

    NOTE: The DiskVerify application must be used to verify the CRC on the USB Thumb Drive, CD, or DVD before installing the software again on another system.
