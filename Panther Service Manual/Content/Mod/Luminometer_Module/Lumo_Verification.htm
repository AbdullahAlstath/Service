Luminometer OLV Verification Procedure

Scope

Perform this procedure when any of the following elements are replaced:

  • Luminometer
  • OLV circuit board within the Luminometer
  • Luminometer Injector
  • Auto Detect 1 Pump
  • Auto Detect 2 Pump
  • Main Luminometer PCB

Procedure

I. Start Service Software

II. Prime the Luminometer

  1. Verify 1 MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. in the Input Queue.
  2. Move MTU to the Luminometer.
  3. Navigate to the 6. Luminometer tab.
  4. Select the Main > Sequence tab.
  5. Set the Full Strokes field to 4.
  6. Ensure all 5 tubes are checked in the Tube Select and Results area of the dialog.
  7. Press the Prime Operation of pumping fluid through tubing to ensure proper and consistent fluid delivery (remove air from the tubing, etc.). button.
  8. Remove the MTU from the Luminometer.

III. Calibrate both channels of the OLV Sensor

  1. Start up Service Software.
  2. Initialize Input Queue, Distributor, Luminometer, and Output Queue.
  3. Verify Auto Detect lines 1 and 2 are primed.
  4. Verify 1 MTU in the Input Queue.
  5. Move MTU to the Luminometer.
  6. In Service Software, navigate to the 6. Luminometer tab.
  7. Click Door Close.
  8. Move the MTU Drive to any of the five positions.
  9. Select Sensor.
  10. Click Calibrate & Test Channel 1 button.

    Prompt will appear to verify the MTU in the Luminometer and the lines are primed.

  11. Click OK.

    Message box will have “Succeed”.

  12. Click Yes to write Parameters to NVM.
  13. Repeat steps 9-13 for Channel 2.
  14. Ensure parameters 602 and 640 are non zero values.

    Note: If parameters are zero, a calibration warning message will generate when PantherGUI starts.

  15. Remove the MTU from the Luminometer.
    1. Navigate to the 6. Luminometer tab.
    2. Click Door Open.
    3. Navigate to the Move tab.
    4. Pick MTU
  16. Remove the MTU from the Luminometer.

IV. Run Luminometer OQ Test

  1. In Service Software, navigate to the 9. Systems tab.
  2. Click Report if necessary.
  3. Select the checkbox for initialization if necessary.
  4. Click Luminometer OQ Test.
  5. Verify that the Luminometer OQ Test passes.
  6. Remove the MTU from the Luminometer.
