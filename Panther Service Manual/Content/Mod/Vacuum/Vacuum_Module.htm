Vacuum System Modules

Configuration 1:
Two Dual Head Vacuum Pumps without the Noise Reduction Housing.

Configuration 2A and 2B:
Two Dual Head Vacuum Pumps with the Noise Reduction Housing.
New Speed Control PCB is mounted vertically inside the housing.

  • Configuration 2A- In Panther Systems with Serial # 0280 and lower with this configuration, the exhaust vents out the cover at the rear of the housing and shares the rear exhaust vent on the chassis frame with the chiller ramp via top-mounted duct (part of the Duct & Fan Kit).
  • Configuration 2B- In Panther Systems with Serial # 0281 and higher, the exhaust vents out of the cover installed on the top of the housing. These systems contain two rear exhaust vents on the chassis frame, one for the chiller ramp and one for the vacuum system via rear-vent duct.

A fuse is needed on the control cable from the cooling module PCB to the vacuum PCB. This contains a solid state, self-resetting fuse. Reference Vacuum Pump/Cooling Module Fuse Upgrade Procedure for installation instructions.

A fuse is needed for the power cable. Systems 818 and lower require M/N 903696 to be installed. This configuration uses a common 15A mini blade fuse. Systems 819 and higher have an in-line fuse on the power cable. This assembly uses a common 20mm 10A cylindrical fuse.

Configuration 3:
Single Quad Head Vacuum Pump with Noise Reduction Housing.
The PCB is mounted horizontally on top of the module.

The ported vacuum manifold cover should be adjusted per Configuring the Quad Head Vacuum Pump Speed to allow the pumps to run at a speed greater than 1650RPM with a vacuum level between -230mBar and -270mBAR. The ports allow extra airflow to force the pumps to run at a higher speed while keeping the pressure in the acceptable range. If the pump is not running at full speed excessive system vibration will occur.

No fuse is needed for the control cable from the cooling module PCB to the vacuum PCB as the fuses are located on the main vacuum PCB. These are solid state, self-resetting fuses.

A fuse is needed for the power cable. This is an inline fuse which is contained on all systems 819 and higher. This is a common 20mm 10A cylinder fuse.

NOTE—
Replacement pumps for Configuration 1 and 2A/B are no longer available as spares.
If a pump needs to be replaced, the Panther System must be upgraded to Configuration 3.
