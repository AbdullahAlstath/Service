SC-Thermocycler Tab

Refer to Common Features for features found on every tab (Common Control, Communication Status, Buttons).

Main (tab)

TC-States

  • Heatsink Sensors - Reads the temperature at each Thermistor. Thermistor 1 measures temperature under Banks 1-6, and Thermistor 2 measures temperature under Banks 7-12. Any differences in temperature readings can indicate a faulty thermistor.
  • Actors - Manually turn the fans inside the Thermocycler on and off.
  • TC States - Not used.

Bank Operations

  • Bank Operations - not currently in use.

Sequence

  • Select Bank - Runs a stress test on selected Banks.
  • Graph - Displays a graph of florescent data for selected fluorometers.

Cleaning (tab)

  • Reserved for future use.

Scan Results (tab)

This tab is used to evaluate all the banks for potentially "dirty/blocked" wells.

Scan Background (used with a PEEK lid up, or no PEEK lid present)

  1. Enter a value for BGMax. (BGMax is a limit that will flag a “dirty” well, some value above 1. The default is 1.8, meaning locations with an average reading of more than 80% of the median found from all wells will get flagged.)
  2. Click the Scan Background button.
  3. The “Well – Average values” and “Fluorometer – Median Values” tables will show results. "Dirty/blocked" locations will be highlighted in yellow.

Scan PEEK Lid (used only with a PEEK lid down and covering the banks)

  1. Scan the barcode on the PEEK lid, or manually enter PEEK lid values.
  2. Enter values for LEDMin and PEEKMin to set evaluation criteria. (0.7 and 0.6 are default – if locations have average readings less than these, the wells will be flagged or error notice will appear.)
  3. Click Scan PEEK Lid button.
  4. The “Well – Average values” and “Fluorometer – Median Values” tables will show results. "Dirty/blocked" locations will be highlighted. An error message, “LED Failure” is displayed if an LED has failed.

Parameter (tab)

  • Display any parameter value of the selected Device by entering a Parameter number and clicking the Read button.

Error Memory (tab)

  • Lists errors created by module movement.
