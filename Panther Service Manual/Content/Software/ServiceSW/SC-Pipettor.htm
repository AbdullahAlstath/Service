SC-Pipettor Tab

Refer to Common Features for features found on every tab (Common Control, Communication Status, Buttons).

Main (tab)

XY - Random Movement

  • Use when troubleshooting lost X or Y-axis steps, or after replacing X or Y-axis belts.

Sensors

  • Vial Robot (Read button checks voltages on PCB, voltages out of range can indicate defects.)
  • Reagent Pipettor (Read button checks voltages on PCB, voltages out of range can indicate defects. Also, LLD Frequency can indicate if wet. A value of 24000 Hz indicates wetness.)

Misc

  • Not currently used.

Pumps

  • Vial Robot (Initialize.)
  • Reagent Pipettor (Initialize.)

Module Info

  • Pipettor Main CU PCB (Displays info)

Move (tab)

  • Vial Robot (Select location to move Vial Robot)
  • Select Coordinate (Double-click from displayed list to send arm to selected Coordinates.)
  • Reagent Pipettor (Select location to move Vial Robot)
  • Move Sequence (Setup a pre-programmed move sequence)
    1. Check Record box.
    2. Single-click desired coordinate to add to list, double-click to add to list and preview the movement.
    3. Uncheck Record box.
    4. Edit the Sequence order if desired using Up, Down, Delete.
    5. Click Execute to start Sequence.
  Caution—DO NOT allow arms to cross as there is no verification performed by the software.

LLD Reagent (Fusion) Pipettor (tab)

  • Setup an LLD test on the Fusion Pipettor:
    • Initialize the Fusion Pipettor.
    • Double-click a location to add to Coord. List (PCR Recon Standard represents the Reconstitution Buffer positions 1-4 in the UFD, the PCR Recon LDT represents the PCR cartridge positions in the Reagent Aspiration Station, and Oil represents the A and B positions for Oil in the UFD.
    • Enter desired number of cycles.
    • Select Barometric (bar.) or Capacitive (cap.)
    • Choose a "pierce" option.
    • Check Log and click Execute to start test.

Parameter (tab)

  • Display any parameter value of the selected Device by entering a Parameter number and clicking the Read button.
  • Some parameters can be changed using file operations and saving to NVM.
