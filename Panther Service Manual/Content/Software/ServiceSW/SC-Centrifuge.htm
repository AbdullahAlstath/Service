SC-Centrifuge

Refer to Common Features for features found on every tab (Common Control, Communication Status, Buttons).

Main (tab)

Sensors / Actors

  • Sensors - Click Read to display the current state of the listed sensors.
  • Load/Unload Light Barrier - Initiates a short test (with instructional prompts) to test the functionality of the Light Barriers.

Move

  • Define Centrifuge Profile - Create a custom test profile to evaluate Centrifuge performance.
  • Move - Select a loaded profile and click Start Centrifugation to evaluate the Centrifuge under the specific parameters in the profile. This is helpful to troubleshoot when there are failures during assay processing.
  • Target Position dropdown - Move a selected centrifuge bucket to the Load or Unload position. This can help diagnose a Cap & Vial Presence failure.

Parameter (tab)

  • Display any parameter value of the selected Device by entering a Parameter number and clicking the Read button.

Teach (tab)

  • Not currently used for routine maintenance. Offsets are preloaded.

Error Memory (tab)

  • Lists errors created by module movement.
