SC-Front and Loading Units Tab

Refer to Common Features for features found on every tab (Common Control, Communication Status, Buttons).

Main (tab)

Drawer Interlocks

  • Drawer Sensor - Reads current sensor states.
  • Drawer Interlock - Reads current Drawer Interlock states (displays Locked/Unlocked).
  • Drawer Interlock - Manually Lock and Unlock each drawer to test the functionality of the interlocks.

Elution Track

  • Track Motor - Initialize the Elution Track Motor on the Universal Fluid Drawer, and move the Elution Arm over to the Panther side and back.
  • Voltages - Read voltages at various components of the Fluid Drawer.

Cap & Vial RFID

  • TAG Check - Test the sensors that read Cap & Vial tray information of trays inserted in positions 1,2,3,4.

Shutter

  • Init Shutters button - Initialize the shutters
  • Close All button - Closes the shutters.
  • Check Position button - Checks the current position of the shutters.
  • Select Column to Open - Opens the shutters over the selected Column and Tray (Left/Right).
  • Motor Sensors - Indicates the current position of the motor (Home or Out).

Fluid Drawer LED

  • LED - Tests LEDs to ensure lights are working properly.

Fluid Drawer RFID

  • TAG Check - Reads and displays all the information on each TAG label for the selected position (Elution 1&2, Oil 1&2, Recon 1-4).

Front Cover

  • Sensors - Reads current supply voltages/state/status of listed sensors.
  • LEDs - Turn on/off or test any of the LED lights on the Front Panel.
  • Waste - Manually Lock/Unlock the Waste Drawer. Can be used to calibrate a newly installed Drawer sensor.
  • Fan - Manually check operation of the cooling fan.

Module Info

  • Displays module information for displayed modules.

Teach Shutter (tab)

  • To perform Shutter Teaching, refer to the Reaction Tube Tray Shutter Teaching Procedure.

Parameter (tab)

  • Display any parameter value of the selected Device by entering a Parameter number and clicking the Read button.
  • To allow Shutter teaching (on the Teach Shutter tab) the Authorization Code must be set to 1. Enter 1 in the Authorization Code Field and click Set before teaching.

Error Memory (tab)

  • Lists errors created by module movement.
