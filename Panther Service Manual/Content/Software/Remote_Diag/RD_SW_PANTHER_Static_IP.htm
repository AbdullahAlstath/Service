Configuring the PC with a Static IP Address

Time Required

  • 15 minutes

Prerequisite

  • Programming the Firewall with Firewall Wizard v6.0.1.0

Procedure

  1. Upon PC boot up, touch the screen or press any key.

    The Panther Shield software screen appears.

    Note—If no key is pressed or the touch screen is not touched, the Panther System main assay software launches.
  2. Press Shift + F10.

    The FSE Password Login dialog box appears.

  3. Enter the following password:

    !G9x53rvic3y

    Where x = the last digit of the day and y = the last digit of the month.

  4. Click OK.

    The Panther FSE Shield software screen appears.

  5. Click the Command Prompt button.

  6. Enter control NCPA.CPL into the DOS Window and press Enter.
  7. Select the Local Area Connection that is currently enabled; the other connection should have a red X next to it.

  8. Position the mouse pointer over the enabled Local Area Connection, click the right mouse button, and select Properties.
  9. Select Internet Protocol Version 4 (TCR Target capture reagent—An assay-specific reagent added as part of specimen pipetting./IPv4) and click the Properties button.

    Note—At this point, a dialog box appears requesting the IP address, Subnet mask, Default gateway, Preferred DNS server, and Alternate DNS server values.
  10. Select the Use the following IP address option

    An Internet Protocol Version 4 (TCP/IPv4) properties dialog box appears..

  11. Enter the information from the Firewall Configuration Wizard Configuration Completed screen.

  12. After entering the information, click OK.
  13. Click Close.
  14. Close all open windows.
  15. Click the Start button in the lower left corner of the screen and select Restart.
  16. Checking PRO360° Remote Diagnostics Connectivity from the Panther Remote Dashboard
