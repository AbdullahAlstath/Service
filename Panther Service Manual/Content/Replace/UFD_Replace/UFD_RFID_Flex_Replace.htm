Universal Fluid Drawer RFID Display Flex Cable Removal and Replacement

Parts and Materials Required

  • Proper PPE
  • Allen wrench, 2.5 mm
  • Allen wrench, 3 mm
  • UFD, RFID DISPLAY FLEX CABLE

Time Required

  • 30 minutes

Removal Procedure

  1. Put on proper PPE.
  2. Disconnect the UFD Display flex cable from the right side of the Universal Fluid Drawer PCB by pulling straight down on the UFD Display flex cable.

  3. Obtain a piece of masking tape approximately 2 feet long.
  4. To aid in installing the new flex circuit cable, it is recommended to use masking tape to help thread the UFD Display flex cable through. Fold the masking tape in the middle, and attach both ends to either side of the UFD Display flex cable connector.

  5. Unpeel the UFD Display flex cable from the bin to remove the UFD Display flex cable. Be careful not to pull the masking tape all the way through the Universal Fluids Drawer. Once the UFD Display flex cable connector has been pulled to the top of the bin, remove the masking tape, and secure the tape to the new UFD Display flex cable connector.

Replacement Procedure

  1. Using the masking tape, pull the UFD Display flex cable back through the drawer.
  2. Stick the RFID display on the bin.

  3. Connect the UFD Display flex cable to the PCB connector.

Verification

  1. Start up the Panther System.
  2. Replace Universal Fluid bottles with new bottles.
  3. Verify that the system correctly reads bottle ID labels.
