Fusion Cartridge Carousel Removal and Replacement

Note—Remember to run Instrument Setup (Firmware) after replacing a module or PCB.

Parts and Materials Required

  • Bench Top Pads
  • Cartridge Carousel Module
  • FSE Tool Kit
  • Proper PPE

Time Required

  • 30 Minutes

Cartridge Carousel Removal Procedure

  1. Put on proper PPE.
  2. Clear ALL cartridges from the Carousel
    1. Start Service Software.
    2. From the 15. SC-System tab, select OQ-Test, then click Initialize SC-System.

    3. Click Clear PCRs.
      Allow the System to clear any cartridges from the Carousel.

  3. Close Service Software and power down the Panther System and PC.
  4. Open the left door on the Fusion to access the Assay Procedures required to prepare and perform a specific test. In the context of this document, assay refers exclusively to a Hologic test, such as Aptima Combo or Ultrio. Cartridge module.

  5. Disconnect the CAN cable from the Carousel PCB.

  6. Open the Panther Mid Bay Drawer.
  7. Using a 3 mm Allen wrench, remove the mounting screw on the left side that holds the Assay Cartridge module front cover.

  8. Remove the Cartridge module's front cover.
    Use the handle on the right to tilt the top of the cover forward, then pull up to remove.

  9. Visually verify that all PCR cartridges have been removed from the cartridge carousel.
    1. Open the cartridge loading drawer to confirm that the loading carousel is empty.
    2. Remove the Styrofoam panel from the front of the storage carousel to manually check for cartridges.
      Replace the Styrofoam panel when the check is complete.

  10. Using a 3 mm Allen wrench remove the side bracket screw on the right that holds the Assay Cartridge module.

  11. Using a 4 mm Allen wrench, remove the 2 screws holding the Assay Cartridge module to the base.

  12. Carefully slide the Cartridge module towards the front of the system to remove it from the system.
    Caution—The Cartridge module is very heavy.
  13. Place the module on a sterile bench top pad.
  14. Remove the Drawer cover
    Note— Remember to remove the drawer cover from the module being replaced and place it on the module being installed.
    1. Fully Open the Carousel Drawer.

    2. Remove the Four Screws underneath the drawer that hold the black insert in place.

    3. Remove the Black Insert

    4. Remove the 4 screws (2xPhilips, 2xHex) to remove the drawer cover

Cartridge Carousel Replacement Procedure

  1. Install the drawer cover (from the module being replaced) onto the module being installed, by reversing the drawer cover removal procedure.
  2. Install the Carousel on to the System, by reversing the Removal Procedure.
    Note—When placing the Assay Cartridge module back into the system,
    make sure that the rear of the module slides under the mounting pins.

 

Verification

  1. Power on the Panther System and PC.
  2. Load firmware to the new Cartridge Carousel module.
    Refer to Panther Fusion System Installation > Run Instrument Setup (Fusion).

  3. Cartridge Carousel Parameter Verification

    1. From Service Software
      Select 10. SC-Cartridge > Parameter tab.
      Ensure the Device dropdown is SC Cartridge Carousel ID 0x60,
      Enter 461 for the parameter, and select Read
    2. If the value of parameter 461 is 0, then go to Step 4, if the value is NOT 0, then proceed to Step 3c
    3. In the Trace View window, change the COM port to STCS.
    4. Send the commands listed below.
      After typing in each string, press <Enter> or select Send.
      Then verify the expected return string.

      1. Type in: 60 16 00 00 01 00
        Returns: 60 16 00 00 00 01 00

      2. Type in: 60 14 00 00 02 00 CD 01 00 00
        Returns: 60 14 00 00 00 02 00 CD 01 00 00

      3. Type in: 60 0D 00 00
        Returns: 60 0D 00 00 00

    5. Cycle power to the system, then repeat Step 3a to verify parameter 461 is 0.

  4. Teach the Rotary Distributor to the Cartridge Carousel module.
    Refer to Service Procedures > Teach Rotary Distributor to All Stations.
  5. Perform a Panther Fusion System OQ Test.
    Refer to Service Procedures > Panther Fusion System OQ Test.
    • 1 cycle
    • Check the Report, Initialize, and PCR Cartridges checkboxes only
