Communication and organization Processor (COP) Removal and Replacement

Parts and Materials Required

  • Proper PPE
  • Hex key, 3 mm
  • COP module

Time Required

  • 15 minutes plus instrument setup time

Removal Procedure

  1. Put on proper PPE.
  2. Locate the COP module inside the Panther System. The COP is located on the top left corner of the back wall inside the Panther System.
  3. Remove the top five screws that secure the COP module. Not all systems will have five screws.

  4. Release the COP module from the lip that secures the bottom of the board.
  5. Remove each cable, one by one, and connect it to the new COP PCB.
  6. After all cables have been transferred, remove the module.

Replacement Procedure

  1. Set the DIP switch settings on the replacement PCB so that they match the settings on the removed PCB.
  2. Reverse the removal procedure.
  3. The system may recognize the new COP on COM Port 5 but the correct setting is COM Port 3. To verify and/or change the COM Port setting, access the Com Port settings through Windows Explorer:
    1. From the Panther Shield, open Windows Explorer.
    2. Right-click on Computer.
    3. Select Manage.
    4. Select Device Manager.
    5. Expand Ports (COM & LPT).

      Panther Driver Set should be set to COM3. If it is not, continue with Step 3f to change the port setting.

    6. Right-click on the Panther Driver Set (Com X) and select Properties.
    7. Select the Port Settings tab.
    8. Select Advanced.
    9. Select the drop-down next to COM Port Number and select COM3.
    10. Select OK. If a message appears that says this COM Port is currently in use, change the COM Port anyway.
  4. Run Instrument Setup (Firmware).
  5. Open the Pipettor Teaching Software and Transfer Coordinates.

Verification

  1. Initialize the system.
