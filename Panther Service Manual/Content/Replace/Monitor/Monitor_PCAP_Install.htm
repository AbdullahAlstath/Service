PCAP Monitor Installation Procedure

Parts and Materials Required

  • Proper PPE
  • Panther Tool Kit
  • The following items are included to install the monitor:
    • PCAP Monitor
    • Monitor Arm
    • (2) M6x20 screws to install arm to frame (temporarily installed in place on bracket)
    • (4) M4x8 screws to install monitor to arm (temporarily installed in place on back of monitor)
    • (1) Cable Clip (already installed on the back on the bracket)
      Note—A second cable clip is recommended to secure the cables to the USB plate, but may not be included. Obtain a cable clip similar to the installed clip if possible before installation.
      Note—The right side canopy must be installed before installing the PCAP Monitor.

Time Required

  • 30 Minutes

Procedure

  1. Remove the ends of the monitor cables from the packaging inside the system. (Leave the plastic spiral wrap on the cables)
  2. Gently remove the USB Hub Cover (and disconnect the USB and power cables) from the USB plate and set aside (slowly pull out, it is a "press-fit" cover, no screws).
  3. Route the 3 monitor cables out through the opening in the USB plate as shown.

  4. Install the monitor arm to the bracket with the two M6x20 screws (5mm hex driver). The two screws are temporarily installed on the bracket. Ensure the plastic green arrow (on the inside of the monitor mounting plate) is pointing up. Remove the plastic arrow after install.

  5. Install the monitor to the monitor arm using the four M4x8 screws (3mm hex driver). The four screws temporarily installed on the back of the monitor. Hold the monitor in place and get two screws started and tightened, then you can safely install the rest.

  6. Plug in all 3 cables to the monitor, and route the cables through the channels on the monitor arm. Run the VGA cable through the bottom channel, and the other two cables through the top channel. Snap the channel covers back into place.
    Caution— When routing the cables through the cable channels in the arm, keep the slack in the cables to a minimum. Do NOT put too much stress on the cables at any point. The monitor arm must be able to swing all the way from one side to the other without any strain on the cables.

  7. Attach a second cable clip (optional but recommended) on the USB Plate as shown, then secure the cables in the clips.

  8. Reinstall the USB Hub Cover and ensure the side door can still open and close. Readjust the cable routing through the cable clips if necessary.

  9. Snap the new monitor arm plastic covers that hide the attachment screws.

  10. Power on the system and start the PC.
  11. Proceed to the Monitor Configuration section below.

Monitor Configuration

  Note—If the Panther Image is v5.8.2 or above, this section is NOT required.
  1. Login to the FSE Shield.
  2. Click the Command Prompt button.
  3. Type in services.msc and press Enter.
  4. From the list of Services, right click the "Tablet PC Input Service".
  5. Select Properties.
  6. From "Tablet PC Input Service Properties" window, use the "Startup Type" dropdown menu to set the Startup Type to Automatic.
  7. Select the Apply button.
  8. Restart the PC.
  9. Login to the FSE Shield.
  10. Click the Command Prompt button.
  11. Type in "control" and press Enter.
  12. From the Control Panel window, select "Programs and Features".
  13. From the "Programs and Features" left pane, select "Turn Windows features on or off".
  14. When the Features list populates, scroll down to "Tablet PC Optional Components" and check the box to enable the feature. (If already checked, DO NOT uncheck. Leave the feature checked and proceed.)
  15. Select OK.
  16. Wait for the "Tablet PC Optional Components" feature to be configured. (This process can take up to 10 minutes if previously uncheck.)
  17. Restart the PC.
  18. Login to the FSE Shield.
  19. Click the Command Prompt button.
  20. Type in tabletPC.cpl and press Enter.
  21. From the "Pen and Input Devices" window, select the Touch tab.
  22. Uncheck the "Show the pointer when I'm interacting with items on the screen" checkbox.
  23. Select OK.
  24. Restart the PC.

Verification

  1. After reboot, verify the display and touchscreen functionality works correctly.
