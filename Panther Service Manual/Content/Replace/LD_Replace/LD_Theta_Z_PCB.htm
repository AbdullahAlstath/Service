Distributor Z/Theta-Axis PCB Removal and Replacement

Parts and Materials Required

  • Proper PPE
  • Ball driver or Allen key, 2.5 mm
  • 5.5 mm hex driver or wrench
  • DISTRIBUTOR, Z/THETA PCB

Time Required

  • 30 minutes

Removal Procedure

  1. Put on proper PPE.
  1. Launch Panther FSE Shield software.
  2. Install Panther System firmware to the module.
    • Run the Panther System Firmware Installation script to save the teach parameters so they do not have to be taught again after the PCB is replaced.
  3. Shutdown the Panther System and PC.
  4. Remove the Luminometer Injector.
  5. Carefully open the Service Drawer.
  6. Manually move the Distributor head into position next to the Service Queue.
    Note—The Transition Incubator can be removed for extra space to access the Distributor Theta Board.
  7. Using a 5.5 mm hex driver, unscrew the two nuts securing the Z/Theta PCB cover, and set it aside.

  8. Unplug all cables from the Z/Theta-axis PCB.
  9. Using a 2.5 mm ball driver or Allen key, unscrew the three bolts and remove the Z/Theta-axis PCB.

Replacement Procedure

  1. Insert the new Z/Theta PCB and fasten by screwing in three bolts.
  2. Plug in all cables to the Z/Theta-axis PCB, note that the correct location for each cable is written on the PCB.
  3. Refasten the Z/Theta PCB cover. The placement of the theta flex cable is important. Refer to the following picture. Make sure the fold is not sandwiched behind the cover.

  4. Confirm that all wires are tucked behind the PCB cover, and will not get snagged during normal movement.
  5. Close the Service Drawer.
  6. Reinstall the Luminometer Injector.
  7. Install Panther System firmware to the module.
    Note—If Firmware Installation script was not run prior to replacement of the PCB, then auto-teach the distributor to all locations, starting with the Input Queue.
  8. Start up Service Software.

Verification

  1. Perform a System Level Operational Qualification.
