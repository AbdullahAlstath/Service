Peristaltic Pump Assembly Removal and Replacement

Parts and Materials Required

  • Proper PPE
  • Minimum of 4 MTUs
  • PERISTALTIC PUMP

Time Required

  • 30 minutes

Removal Procedure

  1. Put on proper PPE.
  2. Power OFF the Instrument and PC
  3. Remove the Peristaltic Pump tubing assembly.
  4. Wait one minute to allow all fluids to drain into the bottles.
  5. Using a 2.5 mm hex key, loosen the 2 top screws and bottom screws that secure the pump.

  6. Slide out the pump module and disconnect the connector cable to the module.

  7. Remove the pump module.

Replacement Procedure

Change gloves.
  1. Reverse the removal procedure.
  2. Run Instrument Setup (Firmware)
  3. Install the 2 pump housing top covers.
  4. Verify DIP switch settings.
     DIP SwitchPeristaltic
     1OFF
     2OFF
     3OFF
     4OFF

Prime the Pump, Output Queue Injector Tubing, and Output Queue Deactivation Fluid Tubing

Use the Prime Operation of pumping fluid through tubing to ensure proper and consistent fluid delivery (remove air from the tubing, etc.). and Dispose MTU Multi-tube unit—Container used to process tests in the instrument. An MTU contains five separate reaction tubes. The MTU is moved through the instrument by the linear distributor and includes five tiplets for pipettiing to be used in the mag wash station. function in Service Software to inject deactivation fluid into each tube of the MTU and then dispose of the MTU. This procedure primes the system.

  1. In Service Software, select Front and Loading Units > Main > Output.
  2. Initialize Input Queue, Output Queue, and Distributor.
  3. Open the MTU Input Queue drawer and load at least 4 MTUs.
  4. Close the MTU Input Queue drawer.
  5. Push the MTUs.
    1. In the service software, select Front and Loading Units > Main > Input > Sensors & Actors.
    2. Press Push MTU.
  6. Insert an MTU into the Output Queue in order to catch any deactivation fluid that might drip during the replacement of the peristaltic pump tubing.
    1. In Service Software, select Distributor > Move Distributor > Single Movement to.
    2. Double-click MTU Input Queue to grab an MTU.
    3. In Service Software, select Distributor > Move > Single Movement to.
    4. Double-click Output Queue to place an MTU.
  7. Click Prime & Disp. MTU.
  8. Select Front and Loading Units > Main > Input > Sensors & Actors.
  9. Click Push MTU.
  10. Select Distributor > Move > Distributor Single Movement.
  11. Double-click Input Queue.
  12. Select Distributor > Move > Distributor Single Movement.
  13. Double-click Output Queue.
  14. Repeat steps 1–8 at least two more times or until all fluid lines are primed.

Calibration

  1. Calibrate the Peristaltic Pump motor home sensor.

Verification

  1. Perform an Output Queue Visual Dispense Verification.
