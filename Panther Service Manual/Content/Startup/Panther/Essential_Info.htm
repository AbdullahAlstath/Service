Pipettor Module

Please refer to the most current Technical Bulletins for up to date implementation information.

All Panther PLUS instruments from manufacturing are built with BLDC pipetors.

The BLDC pipettors were cut in on production Panther (only) Systems P03499, 03510, 03511, P03542 and above.

Factory Installed on Panther ONLY Systems (Classic Panther)
P03499, P03510, P03511, P03542 and above
Note—
BLDC Pipettors can ONLY be installed with System Software v7.1 or higher.

For Panther Systems, the Sample and Reagent Pipettors MUST be of the same type.
For Fusions Systems, the Panther side (Sample and Reagent Pipettors) MUST be of the same type.
The Fusion Pipettor can be either an APP or BLDC Pipettor.

The table below represents the only viable pipettor configurations for standalone Panther or Panther Fusion systems:

SYSTEM Sample Pipettor Reagent Pipettor Fusion Pipettor
Panther APP APP APP or BLDC
Panther Fusion BLDC BLDC APP or BLDC
